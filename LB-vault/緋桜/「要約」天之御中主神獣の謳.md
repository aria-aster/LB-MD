# 登場人物

- 禍津姫迪子、妹の茂子、二人の母、将軍八条院零、安心院墨江、龍の巫女ラッチ、メガエラ先生（言及）。
- 惣角一戸部おいち、いりす、バサラ、怪呂（カエル）、カイネ、ナイン、天之御中主神獣（茂子を核とする巨大骸骨）。
- 王国艦隊の海兵たち、鬼傑衆、禍津姫から離反した者たち、泥土から生まれた鬼たち、東国の民。

# 登場組織、地名等

- 東国、海の向こうの王国、列強、帝国、王国の蒸気軍艦艦隊、将軍八条院零の勢力、鬼傑衆。
- 黒い霧に包まれた将軍の居城と天守閣、霊峰の山頂、国産みによって白い泥へ戻された大地。
- 天之御中主、人造の神、鬼道、国産み、白の剣／絶対聖剣オーロラ、大口縄、第一の再演「無限の咒い」、第二の再演「九層地獄」、第三の再演「国産み」、第四の再演。
- 黄金の国（ラッチの発言）、竜退治の英雄オフィーリアとドラゴンの昔話。

# 本文

- 妹を失った迪子は、人を不滅の鬼へ鋳直すため天之御中主に国産みを行わせ、世界を白い泥へ戻す。おいちの死を経て白の剣を継いだバサラが第四の再演を起こし、天之御中主を斬る。
- **神獣の登場：** あり。妹・茂子を核とする巨大骸骨の神獣、天之御中主。
- **推測される元ネタ：** 「古事記」の天之御中主神と天沼矛による国産みを、終末的な再創造へ反転している。
