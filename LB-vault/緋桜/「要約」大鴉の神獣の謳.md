# 登場人物

- 惣角一戸部おいち、いりす、大将軍・八条院太郎湊朝臣宗剛（太郎丸、後に八条院零）、禍津姫迪子、大鴉。
- おいちの侍の父と鬼の母、父を侮辱した道場の門下生たち、城の番所の兵と侍女、鬼傑衆の鬼たち、嘉多山道卓とその娘、娘と逃げる老婆、幕府の山狩り隊、隠れ里の住民、怪呂（大カエル）。

# 登場組織、地名等

- 将軍の城・天守閣・番所、おいちがいた道場、甘味処、霧深い山中、隠れ里、将軍の居城と牢、地獄。
- 幕府、幕府の山狩り隊、嘉多山の一族、鬼傑衆、将軍八条院零の勢力。
- おいちの愛刀・雷丸、大鴉の「剪定」、地獄忍法。

# 本文

- 鬼の侍おいちは、太平の裏に反対者を排除する大鴉の「剪定」があると知る。幽閉後にいりすに救われ、二人で大鴉を討ち、誰も見捨てない太平を目指す。
- **神獣の登場：** あり。存在を剪定する大鴉。
- **推測される元ネタ：** ポー「大鴉」、八咫烏、「一九八四年」型の監視・全体主義。
