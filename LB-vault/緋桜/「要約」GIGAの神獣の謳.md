# 登場人物

- カエル侍（記憶を失った「男」、スミエの掛け軸から生まれた存在）、画王（カエル侍が訪ねる老絵師）、スミエ（画王の弟子である鬼の娘）。
- 山奥の古寺の和尚、村人たち、屈強な無頼漢たち、都の貴族、山狩りの侍たち、鬼の里の住民（幼子を抱いた母など）。

# 登場組織、地名等

- 高台の屋敷、眼下の小さな村、山奥の古寺と本堂、都、都の貧民街、氾濫する川と堤防・水路の工事現場、鬼が暮らす山中の里。
- 村人、山狩りの侍、鬼の共同体。画王の屏風画、スミエの掛け軸、生きた虎の絵、生きた竜の絵。

# 本文

- 画王が描いたと思われるカエルは生命を得るが、異形として迫害される。画王はカエルとの再会を経て再び筆を取り、大地に描いた竜へ目を入れて生命を与える。
- **神獣の登場：** 明記なし。生命を得たカエルと巨大な生きた竜の絵が登場する。
- **推測される元ネタ：** 「画竜点睛」と「鳥獣人物戯画」。
