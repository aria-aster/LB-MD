# 本文
いりすは一度死に地獄で蘇った。 死人王と名乗る女によって。 （でも死んでいる）
[[sky/book/divines/謳：23.大口縄の神獣#Page 2-5]]

「話が早くて助かる」死人王が嬉しそうに嗤（わら）う。
死人王が嬉しそうに嗤う。「わたしたちの望みは神殺しの騎士を手に入れること」カイネが言った。
[[sky/book/divines/謳：23.大口縄の神獣#Page 2-10]]

カイネの導きで、いりすは死人王と共に小さな広場にやってきた。茅の輪が空中に浮かんでいる。
[[sky/book/divines/謳：23.大口縄の神獣#Page 2-13]]

「地獄忍者よ、餞別に、我が部下を供につけてやろう」
[[sky/book/divines/謳：23.大口縄の神獣#Page 2-14]]
