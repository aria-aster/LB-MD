# 登場人物

- リュセット（魔法戦車サンドリヨン）、黄金の魔術師バロウズ、魔術師アルブレヒト、巨人戦車ラプンツェル。
- リュセットの亡父、戦死した兄、継母、義姉、ローゼンブルクの領主、常備軍と伝令兵、魔王軍の伝令・兵士、城外へ差し出された女たち。
- アルブレヒトに集められ、巨人化実験の犠牲にされた子供たち、バロウズと共に囚われていた子供たち。

# 登場組織、地名等

- ユーファリア、七つの王国、薔薇の国、都ローゼンブルクと城壁・城門、バロウズの屋敷と薔薇の庭、アルブレヒトの実験施設・牢、戦場。
- ローゼンブルク常備軍、魔王軍、魔族の軍勢。
- オーパーツ「水晶の薔薇」、魔法戦車サンドリヨン、巨人戦車ラプンツェル、巨人化実験。

# 本文

- 虐げられていたリュセットは水晶の薔薇で魔法戦車サンドリヨンとなり、薔薇の国を守る。最後はバロウズの大切なものを守るため、アルブレヒトのラプンツェルと相討ちになる。
- **神獣の登場：** 明記なし。サンドリヨンとラプンツェルは巨人を利用した魔法戦車。
- **推測される元ネタ：** 「シンデレラ」「ラプンツェル」など複数の童話を戦争物へ再構成している。
