# 本文
火山の国。
質の良い鉱石に恵まれ、大勢の奴隷（カゲ）たちを使って大きな鉱山を運営する、豊かな国でした。
その都は、永遠の都と呼ばれていました。火の国の王が「不死」 だったからです。
[[sky/book/divines/謳：19.魔剣の神獣#Page 1-2]]

王が 「リーパー」 という魔法の剣を持っていた
[[sky/book/divines/謳：19.魔剣の神獣#Page 1-3]]

王と剣闘士アルコンが手合わせした際、アルコンのほうがイケてる感じだったので、リーパーはアルコンを主人とした。
[[sky/book/divines/謳：19.魔剣の神獣#Page 1-13]]

こうして、アルコンは火の国を手に入れ、王となりました
[[sky/book/divines/謳：19.魔剣の神獣#Page 1-17]]
