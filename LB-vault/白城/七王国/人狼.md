# 本文
人狼の呪いを受けているらしい？

少女たちの頭には獣の耳が生えている。
それは彼女たちの感情を表すかのように、ぴょこぴょこと動いている。
マジの狼少女じゃん。
[[sky/book/origin/謳：ロードオブウォー#Page 2-9]]

ひとりめはモリアという。ヒューマン・ウォリアー・女です。
言っていいかどうか分かんないですけど、 人狼の呪いを受けていて、
それを解くためにオーブを探しています。
