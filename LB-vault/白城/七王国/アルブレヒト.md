# 本文
魔術師アルブレヒト
術師アルブレヒト
術王アルブレヒト

石の国の王家から「永遠の宝珠」を奪い、地下迷宮へ逃げ込んだ。
[[sky/book/divines/謳：14.迷宮の神獣#Page 1-3]]

フィーと対峙時、スィを瀕死にする。フィーは宝珠の力でスィを助ける。
[[sky/book/divines/謳：14.迷宮の神獣#Page 3-13]]

何かしらの「再演」がなされた。迷宮が崩壊し、巨大な緑の星が輝いた。
[[sky/book/divines/謳：14.迷宮の神獣#Page 3-15]]

オーパーツ「水晶の薔薇」を利用して人間を巨人化する実験を行っていた。
後に魔術師となるバロウズも、この時の実験材料のひとりだった。
[[sky/book/divines/謳：08.戦車の神獣#Page 3-1]]

バロウズが逃亡した際にに「水晶の薔薇」を胸へ突き刺され、自らが巨人化させられている。
[[sky/book/divines/謳：08.戦車の神獣#Page 3-7]]

薔薇の国に魔王軍が攻め入った際に、巨人戦車「ラプンツェル」を製造、投入している。
[[sky/book/divines/謳：08.戦車の神獣#Page 3-14]]

魔王アズーラ・スィの部下になっており、下剋上している。
[[sky/book/origin/謳：アナテマ#Page 3-5]]

ゴーレム「エメス」の造物主でもある。
[[sky/book/origin/謳：エメス#Page 1-1]]

推測：アルヴェーンの森でモリーを騙し、怪物を解き放っている。
[[sky/book/origin/謳：ローズ#Page 1-4]]
