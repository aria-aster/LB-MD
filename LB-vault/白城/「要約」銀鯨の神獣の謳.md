# 登場人物

- フィー（オフィーリア／白騎士／スレイヤー）、アズーラ・スィ（魔王／黒騎士）、剣の国の女王キベーレ、魔剣リーパー、銀鯨の神獣。
- 老騎士エバンス、アルブレヒト、炎の騎士（いずれも回想・物語・言及）、フィーの父と母、キベーレの侍女、衛兵、決死隊、ヒトの兵士、魔王軍の兵士、迷宮で出会ったカゲの少女としてのスィ。

# 登場組織、地名等

- ユーファリア、剣の国、ヒトの軍、魔王軍、戦場、キベーレの天幕、燃え跡の図書館、荒野、フィーの故郷だった街、銀鯨の遺骸が眠る場所、迷宮（回想）。
- カゲ、黒い巨大剣／魔剣リーパー、緑の凶星、緑の彗星、銀鯨の神獣、フィーが自称・他称される怪物、白騎士と炎の騎士の再演物語。

# 本文

- ヒトとカゲの戦争でフィーは死と蘇生、スィとの殺し合いを再演させられ、自我を失っていく。白騎士であることを拒み、自らの生命を銀鯨の遺骸へ注いで新たな神獣となる。
- **神獣の登場：** あり。銀鯨の遺骸が復活し、フィーと融合して新たな神獣になる。
- **推測される元ネタ：** 「白鯨」。鯨を討つ者が最後には鯨と一体化する反転。
