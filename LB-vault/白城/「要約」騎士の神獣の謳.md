# 登場人物

- フィー（後のオフィーリア／スレイヤー）、老騎士エバンス（神獣殺しの騎士）、竜の国の守護者であり支配者である古き竜、銀鯨の神獣。
- フィーの父、母、祖母、老犬、エバンスの主君、エバンスの弟子たち、竜の国の兵隊、焼かれた街の住民。
- 白き女神アシュタル（神殿名および信仰として言及）。

# 登場組織、地名等

- ユーファリア、七つの王国、森のそばの小さな街、生命にあふれた森、竜の国、白き女神アシュタルの神殿、古き竜の宝物庫、神獣に焼かれた街。
- 竜の国の兵と騎士、神獣殺しの騎士（スレイヤー）。銀鯨の神獣、古き竜、神獣の力を使って生まれる怪物、死んだ神獣を形作るオーパーツ。

# 本文

- 銀鯨に故郷を焼かれたフィーは、竜の国の神獣殺し・エバンスに育てられる。エバンスは最後にフィーを守って古き竜と共に死に、オフィーリアとスレイヤーの名を託す。
- **神獣の登場：** あり。銀鯨の神獣と古き竜。
- **推測される元ネタ：** 聖ゲオルギウスなどの竜殺し説話と、騎士道物語の師弟継承型。
