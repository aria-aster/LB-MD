# 登場人物

- フィー（オフィーリア／白騎士／剣聖エバンスの継承者）、アズーラ・スィ、アルコン（剣闘士、炎の騎士、残虐王・黒の王・魔王）、剣の国の女王キベーレ、魔剣リーパー。
- 火の国の不死王、剣闘士奴隷だったアルコンの父母、火の国の剣闘士と観客、カゲの軍勢、ヒトの兵、キベーレ付きの兵、魔王軍とブラックブレードの兵たち、書の国の住民、森の国の民。
- 老騎士エバンス、魔術師アルブレヒト、物語中の炎の騎士、白き女神（物語・言及）。

# 登場組織、地名等

- ユーファリア、七つの王国から五つの王国へ減った世界、竜の国、石の国、火の国と永遠の都・鉱山・闘技場、剣の国、書の国と港・都・大図書館、森の国と大森林、楽園。
- 火の国の軍、アルコン率いるカゲの軍勢／魔王軍、黒い剣を掲げる兵（ブラックブレード）、剣の国の軍。
- 魔剣リーパーとその分身、黒の剣、炎の騎士、白騎士、緑の凶星、レガシーアームズ、再演の物語。

# 本文

- リーパーを得たアルコンがヒトへの復讐戦争を起こす。アルコンを倒した後、フィーを救うためリーパーと契約したスィは記憶から失われ、魔王軍の黒騎士としてフィーと激突する。
- **神獣の登場：** あり。悲嘆・復仇・渇望の神獣。リーパーと黒い巨大剣も神獣に近い魂の回収装置。
- **推測される元ネタ：** 「ストームブリンガー」などの呪われた魔剣譚と、白騎士・黒騎士の悲劇。
