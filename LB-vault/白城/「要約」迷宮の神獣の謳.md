# 登場人物

- オフィーリア（フィー／スレイヤー）、アズーラ・スィ（当初は名のない荷物持ちのカゲの娘）、魔術師アルブレヒト。
- 石の国の騎士バンホー、部下の女騎士メルセンヌ、バンホーが雇った冒険者たち、冒頭でスィを置き去りにする冒険者一団、石の国の王、剣の国の女王キベーレ（言及）、剣聖エバンス（言及）。
- 黄金の国を滅ぼしたエディナ姫のなれの果てとされる触手の怪物、地下神殿の門番、アルブレヒトが「かの者」と呼ぶ神獣。

# 登場組織、地名等

- ユーファリア、七つの王国から六つの王国へ減った世界、竜の国、剣の国、石の国、黄金の国。
- 石の国の都「迷宮の都」、地下に埋まった古代都市／地下迷宮、ベースキャンプ、カゲだけが知る道、地下神殿、白の女神を祀る祭壇、奈落。
- 石の国の王家と騎士、迷宮の冒険者たち、ヒトとカゲ。永遠の宝珠、怪物、門番、神話の再演。

# 本文

- 永遠の宝珠を奪ったアルブレヒトを追い、フィーはスィと地下迷宮へ入る。死んだスィを宝珠で蘇らせたことで災いの星が現れるが、二人は神獣とその物語を殺すと決意する。
- **神獣の登場：** あり。黄金の国を滅ぼした触手の怪物など。永遠の宝珠も神獣の力を宿す。
- **推測される元ネタ：** 「Wizardry」などのダンジョンRPG、「猿の手」型の願望譚、死者を取り戻す物語。
