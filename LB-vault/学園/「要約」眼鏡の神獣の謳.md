# 登場人物

- リリー、後輩のアイコとラッチ、風紀委員長ノエミ、ユーファリア学園の教師メガエラ、同学園を首席で卒業したクラウス。
- 惚れ薬のレシピを渡す天使エイプリル、レシピの考案者であるドルイドのタイフーン、海の家の店主、臨海学校の生徒たち。
- 人語を話し「魔王の力」を秘めるあざらし、惚れ薬で巨大化した植物と海の生物、巨大タコ、ヘルロブスター。

# 登場組織、地名等

- ユーファリア学園、伝説の樹、化学実験室、校庭と花壇、臨海学校の海岸、岩場、海の家。
- 謎の事故で消滅した帝国第九研究所、恋愛小説「恋空間」、タイフーンの自然派レシピ、惚れ薬。

# 本文

- 彼氏を欲しがるリリーは、エイプリルから得たレシピで惚れ薬を調合する。失敗作を花壇や川へ捨てたため、学園の植物に続いて海の生物まで巨大化し、臨海学校を混乱に陥れる。
- ノエミが巨大タコに食われたと思ったリリーたちは、クラウスに薬入り焼きそばを食べさせて海へ投げ込む。巨大な「眼鏡の巨人」となったクラウスは、初めて人々に期待される喜びを知り、巨大タコとヘルロブスターを倒す。ノエミはあざらしと共に生還し、事件後、リリーたちはメガエラに叱られる。
- **神獣の登場：** 明記なし。惚れ薬で巨大化した生物とクラウス、人語を話し魔王の力を持つあざらしが登場するが、本文ではいずれも神獣と呼ばれない。
- **推測される元ネタ：** 巨大ヒーロー／怪獣映画と、惚れ薬が騒動を起こす学園コメディ。
