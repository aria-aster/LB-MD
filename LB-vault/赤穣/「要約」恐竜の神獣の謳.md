# 登場人物

- アズ、セロン（後の闘女帝）、アリアニ、神竜アスタウロス。
- アリアニと暮らす翼竜、冒頭でアズを追う巨大な雌の肉食恐竜、野良恐竜たち、セロン配下の巨人格闘士たち（セロンのガールズ）、奴隷と解放奴隷たち、滅ぼされた村の住民。

# 登場組織、地名等

- 彗星衝突後の荒野、峡谷、アズの故郷、水晶洞窟、アリアニの秘密の場所と古代格闘術の石碑、闘女帝陵、滅ぼされた村々。
- 凶悪巨人格闘士軍団、セロンのガールズ、空の神獣、地上の恐竜、神竜アスタウロス。
- 支配者のベルト、生命結晶から作られたレガシーアームズ。

# 本文

- 彗星衝突後の荒野で、アズは巨人軍団を率いるセロンと戦う。二人はアスタウロスを倒してレガシーアームズを得ると、それを大地へ突き立てて緑を蘇らせる。
- **神獣の登場：** あり。空の神獣と神竜アスタウロス。
- **推測される元ネタ：** 「北斗の拳」「マッドマックス」系の終末世界、プロレス、大地再生の創世神話。
