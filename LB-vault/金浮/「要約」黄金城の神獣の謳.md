# 登場人物

- エディナ姫（後の怪物）、黄金王、白の女神、アイーダ、ゼノン。
- 黄金王の家来たち、姫を笑わせようと集まった者たち、城壁の街の住民、生贄に選ばれる娘たち、アイーダの親兄弟と召使いたち、怪物討伐に挑む騎士・力自慢・知恵者たち。

# 登場組織、地名等

- 黄金の国、黄金城、白の女神がいる古の神殿、女神の神殿、七つの山と七つの川、七つの廃城と七つの干上がった川、怪物を恐れて築かれた城壁の街。
- 白の女神の信仰、怪物を鎮める生贄の制度。女神の力を持つ怪物。

# 本文

- 黄金王の願いはエディナを死ねない怪物へ変え、黄金の国を滅ぼす。死ねない身となったゼノンはエディナと心を通わせるが、怪物は後に世界を食らい尽くして旅立つ。
- **神獣の登場：** あり。エディナから生まれた怪物は、女神の力を持つ神獣と明言される。
- **推測される元ネタ：** 「笑わない姫」、アンドロメダ型の生贄譚、「美女と野獣」の反転。
