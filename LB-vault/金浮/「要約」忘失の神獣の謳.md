# 登場人物

- アルフライラ（ライちゃん）、その親友アリス、本そのものを名乗るラミィ、黄金の球体として現れるピトス。
- 孤児院の子供たち、最初の犠牲者リアナ、年月が流れた後の町で死ぬ人々。

# 登場組織、地名等

- 花畑、孤児院、物置、アルフライラが孤児院を出た後に暮らす町、本の中の暗闇。
- 鍵のついた白紙の本、現実になる悲劇、生贄による悲劇の巻き戻し、アリスに関する記憶の消去、アリスを閉じ込めた透明な箱、黄金の球体ピトスと炎。

# 本文

- アリスが見つけた白紙の本には、現実になる死の物語が次々と浮かび上がる。本は生贄と引き換えに悲劇をなかったことにすると持ちかけ、孤児院の子供たちはアルフライラを差し出そうとするが、アリスは先に自分を捧げていた。死者は戻る一方、アリスの存在は皆の記憶から消える。
- 成長したアルフライラの町で同じ死が始まり、彼女はアリスの姿を使う本＝ラミィと再会する。ラミィの目的は悲劇に立ち向かう人間の物語を見ることで、生贄も忘却も、皆を救おうとしたアリスが提示した条件だったと明かされる。
- 本の中へ入ったアルフライラは、自己犠牲の物語を繰り返せというラミィの誘いを拒絶する。現れた黄金の球体をラミィは「ピトス」と呼び、その炎でアリスの箱が溶かされる。新たな犠牲者を出すという脅しにも屈せずアリスを連れ戻し、二人は今後の悲劇には共に立ち向かって生きることを選ぶ。
- **神獣の登場：** 明記なし。ラミィは本そのものを名乗り、ピトスはラミィを裏切ったらしい黄金の球体として現れる。作品名の「忘失の神獣」がどちらを指すかは本文では確定できない。
- **推測される元ネタ：** パンドラの箱と、最後に残る希望。ピトスは「箱」と訳される以前のパンドラの甕を指す語と考えられ、本の中へ入るアリスには「不思議の国のアリス」との重なりも考えられる。
- 「謳：ファタリタ」のアルフライラとは、同じVerse・同名で、生贄に選ばれた過去と炎の力も重なるため連続性が強く示唆される。ただし、「忘失の神獣」本文には同一人物だと明記されていない。
