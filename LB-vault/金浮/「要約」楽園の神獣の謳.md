# 登場人物

- イオナ（女神の御使い・救世主、アアルからアイオーンとも呼ばれる）、アアル（翼を持つ蛇）、蛮族の女戦士ギジェル、蛮族の王。
- イオナと同じ部族の若者、草原の部族の者たち、巡礼者たち、蛮族の兵たち、神人たち、白の女神（伝承・言及）、ギジェルの母（回想・言及）。
- 有翼の蛇たち、卑竜、すべての卑竜の母である怪物／真の龍。

# 登場組織、地名等

- 草原、イオナの遊牧部族、咒歌で生まれた泉、巡礼の道、毒の川、蛮族の勢力、楽園、方舟と呼ばれる遺跡。
- 白の女神の信仰、女神の民と巡礼団、神人（ネフィリム）。王蛇の指輪、咒歌、真の龍。

# 本文

- 奇蹟を起こすイオナは巡礼団を率いて楽園を目指すが、そこはアアルらの偽りの救済計画だった。咒歌へ組み込まれたイオナは言語を理解し、自ら楽園と千年の計画を破壊する。
- **神獣の登場：** 神獣相当の存在あり。「すべての卑竜の母」である巨大な肉塊が登場するが、本文では主に怪物・真の龍と呼ばれる。
- **推測される元ネタ：** イエスの奇蹟、「出エジプト記」、グノーシス主義の神名と偽りの造物主。
