# 登場人物

- リアド、姉のサリマ、MESの看護師105（ワン・オー・ファイブ）、MES専属運転手107（ベイビー）、傭兵アヴァランチ、養父タキツ、國耀会のカニムラ。
- 105たちの隊長／ボス、國耀会のサイヤクザたち、MES隊員、ライフライト研究員、タキツのサイボーグ護衛、リアド以前の養子たち、ホテル従業員、医学校の関係者。
- 軍用機械知性、音楽管理機構A*（エースター）の選曲・管理主体。

# 登場組織、地名等

- 巨大複合都市・新音市（ネイオンシティ）と最下層、ホテルと高級レストラン、ハイウェイ、シティ郊外、高級住宅街のタキツ邸、ヘリポート、医学校、ライフライト研究所「臓器牧場」。
- 武装救急隊MES、親会社ライフライト、國耀会、音楽管理機構A*（エースター）。
- ソーシャルランク、MES契約者制度、ライフライト製サイボーグ部品、人工血液、機械知性、特権階級ネフィリム。

# 本文

- 死の歌が広がり音楽と声まで統制された社会で、MESの兵士105たちは命を救いながら奪う。105は富裕層が貧者の生命を利用する仕組みに反発し、規則を逆手に悪党を始末する。
- **神獣の登場：** 明記なし。死を招く歌、生命売買、機械・生体技術が災厄の中心。
- **推測される元ネタ：** 「暗い日曜日」など呪いの楽曲と、臓器売買ディストピア／サイバーパンク。
