# 登場人物

- アアル、友人ハーラン、機械知性バルベロ、ジャスミンまゐ子、アアルの母。
- 二軍落ちした89番のアイドル、原種のアイドルたち、同僚の男性プロデューサーとプロデューサーたち、人間のオペレーター、警察官、A*の検閲官、番組の観客、MES隊員。
- 音楽を管理する機械知性たち、ネフィリム、原種（ナチュラル）。

# 登場組織、地名等

- 音楽管理機構A*（エースター）、アアル所属のプロデューサーユニット、警察と警察署、武装救命隊MES。
- 巨大複合都市ネイオン・シティ、裏路地のまゐ子のスナック、アイドル番組のスタジオとステージ・会場、病室、仮想空間「方舟」。
- ジレーネ617、違法音楽、アアルの母の子守歌、記憶結晶、機械知性、ネフィリム、原種。

# 本文

- アアルは亡き母の子守歌と「ジレーネ617」から、音楽統制とネフィリムだけを殺す歌の秘密へ迫る。死後に仮想空間で再構築され、音楽を解放する「裏切り者」となる道を選ぶ。
- **神獣の登場：** 明記なし。「方舟」は物語・計画を示す名称で、神獣と呼ばれる実体は確認できない。
- **推測される元ネタ：** 「創世記」の方舟、ネフィリム、洪水を告げる6章17節。
