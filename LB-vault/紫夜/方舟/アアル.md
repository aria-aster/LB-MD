# 本文
ネフィリムの音楽プロデューサー。  

母は生前、アアルに子守歌を歌っていた。 
アアルはその歌を何度も聞いていたにもかかわらず、 成長後には旋律を思い出すことができなくなっていた。 
[[sky/book/divines/謳：12.方舟の神獣#Page 1-1]] 

幼少期に母親を亡くしている。
[[sky/book/divines/謳：12.方舟の神獣#Page 1-2]]

人々から忘れられていた「アイドル」を復活させた
[[sky/book/divines/謳：12.方舟の神獣#Page 1-4]]

友人ハーランに母が歌っていた子守歌を教えた。
[[sky/book/divines/謳：12.方舟の神獣#Page 1-18]]

ハーランは子守歌を見つけ、聞いた。そして、おかしくなって自殺した。
アアルも音楽データを再生した、そして、倒れた。
[[sky/book/divines/謳：12.方舟の神獣#Page 2-24]]

アアルは命を落とした。機械知性バルベロによって仮想世界「方舟」の住人となる。
[[sky/book/divines/謳：12.方舟の神獣#Page 3-3]]

肉体か、音楽か。で、音楽を選ぶ　（もう肉体ないけど）
[[sky/book/divines/謳：12.方舟の神獣#Page 3-19]]
