# 登場人物

- 懐音、まりか、まいん、鈴木甘奈、寿司絵瑠（ことぶき・しえる／スシエル）、ピッピくん（武装イルカ軍団の総帥）。
- 懐音の義父、懐音の母に似た女（名を奪われた女神のなれの果て／無の女神）、咒いの歌を解き放った男、筋肉寿司の店員と板前、渋谷のマッチョたち、自衛隊員、武装イルカたち、ニュースの報道者。

# 登場組織、地名等

- 渋谷、渋谷スクランブル交差点、SKY GARDEN屋上、筋肉寿司、筋肉寿司渋谷店、高級住宅街、羽田空港。
- 武装イルカ軍団、自衛隊、米軍、筋肉寿司店員と渋谷のマッチョたち。
- アンブレイカブル、スシエルのグングニル、米軍から届いた世界改変のボタン、黒い妖精、彗星・緑の彗星、咒いの歌。

# 本文

- 「ちから」を失った懐音らが見守る渋谷で、武装したイルカ軍団が人類へ反旗を翻す。世界は救われるが、それもまいんの力による再度の現実改変かもしれないと懐音は疑う。
- **神獣の登場：** 明記なし。知性化・武装したイルカは登場するが、神獣とは呼ばれない。
- **推測される元ネタ：** 「イルカがせめてきたぞっ」のネットミームと、知性化イルカの反乱SF。
