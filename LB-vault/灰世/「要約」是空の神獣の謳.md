# 登場人物

- 尾頭懐音、柴まりか、咒いの歌を歌う男、トモロウ、妻のアスミ。
- SKY GARDENから交差点を見下ろす男女（ユミルを語る男と女）、懐音の母に似た女、懐音の義父、学校の生徒たち、米軍の軍人と研究機関の関係者、死の歌を聞いた通行人・感染者たち。
- 黒い妖精、ユミル（男女の会話で言及）、懐音の母（記憶・言及）。

# 登場組織、地名等

- 地球、米国首都近海、アメリカ宇宙コマンド、米軍傘下の研究機関、米軍。
- 雑居ビル屋上、夏休み初日の映画館、懐音とまりかの学校、渋谷スクランブル交差点、SKY GARDEN展望デッキ、懐音のペントハウス。
- ガブリエル彗星、緑の彗星、咒いの歌／死の歌、黒い妖精の時間移動装置、懐音とまりかのバンド。

# 本文

- 彗星衝突を回避した懐音とまりかは、死を招く歌による新たな世界滅亡を阻止する。その後、懐音は母に似た女に世界を繰り返す「ちから」を奪われ、普通の少女へ戻される。
- **神獣の登場：** 明記なし。彗星、咒いの歌、時間改変者が登場する。
- **推測される元ネタ：** 般若心経の「色即是空・空即是色」と、「咒いの神獣」の後日譚。
