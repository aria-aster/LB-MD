# 登場人物

- 神威谷熊五郎（クマゴロウ／クマックスくん）、ひよこ、やっちゃん、鈴木甘奈、まいん。
- スーパーホワイトの社長・上司・部長・社員たち、ピヨスタの社員たち、熊五郎の母、故郷の村長と村人たち、イベントの子供と客、メイドカフェの客、配信視聴者、ニュースの報道者。
- 渋谷に現れた本物の熊、北海道で熊五郎と戦う本物の熊。

# 登場組織、地名等

- 北海道の寒村、東京、渋谷、渋谷駅周辺、渋谷スクランブル交差点、道玄坂、北海道の原野。
- ゲーム会社スーパーホワイト（スパホワ）、広告代理店系ソシャゲ会社、ゲーム開発会社ピヨスタ、ピヨスタ階下のメイドカフェ／メイドカフェ兼ゲーム会社、コスプレ自警団、SkyTuber。
- スパホワの着ぐるみクマックスくん、ピヨスタ運営のゲーム「キリンと聖女」、ひよこの実家のカラアゲ。

# 本文

- 自負と挫折を抱える熊五郎は、クマの着ぐるみ姿で会社を追われ、自分の空虚さと向き合う。自分の意志で自分を満たすと悟り、母のザンギを求め北海道へ帰る。
- **神獣の登場：** 明記なし。本物の熊は登場するが神獣ではない。
- **推測される元ネタ：** 中島敦「山月記」。虎ではなく熊へ変わる、救済的な再演。
