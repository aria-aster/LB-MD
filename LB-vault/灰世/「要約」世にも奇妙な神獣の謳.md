# 登場人物

- トモロウ、恋人のアスミ、人生やりなおしマシーンを渡す黒い妖精。
- アスミの母と父、駅の通り魔、マンションに潜伏した国際テロリスト、某国の最高権力者、警察・CIA・自衛隊・在日米軍の関係者、小学生時代の二人と学校関係者。

# 登場組織、地名等

- 渋谷、渋谷交差点そばの高層ビル屋上の店／カフェ、JR渋谷駅と改札、アスミの自宅最寄り駅、病院、警察、CIA、自衛隊、在日米軍、某国、テロリストのマンション・アジト、小学校。
- 人生やりなおしマシーン、時間を戻すボタン、弾道ミサイル、地球へ衝突する彗星。

# 本文

- アスミを救うためトモロウは時間を戻し続けるが、死の規模は事故からミサイル、彗星衝突へ拡大する。二人は小学生時代まで戻り、長い準備期間を得て世界とアスミを救う道を選ぶ。
- **神獣の登場：** 明記なし。黒い妖精と時間改変装置が登場する。
- **推測される元ネタ：** 「世にも奇妙な物語」、死の運命を回避するタイムループ物。
