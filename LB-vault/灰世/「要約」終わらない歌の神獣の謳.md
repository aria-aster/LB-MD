# 登場人物

- 懐音（えおん）、柴まりか、尾頭俊太郎、トモロウ、モンゴル先輩。
- 懐音の母の姿を借りる無の女神ノア、黄金の巨人ユミル、超巨大彗星アスタル。

# 登場組織、地名等

- 渋谷、学園の文化祭、SKY GARDEN、雑居ビルの屋上、滅びた本物の地球、別世界フレストニア。
- ユミルの夢としての世界、創世のちから、世界の再創造、アルテマグナ、アスタル彗星、永遠（AEON）の咒い。

# 本文

- 「ちから」を失った懐音とまりかは、文化祭のライブへ向けて練習を重ねる。だがノアは、彗星ですでに滅んだ本物の地球と、渋谷が死にゆくユミルの夢／走馬灯であることを懐音に明かす。過去の「ループ」は時間を戻したものではなく、ユミルが世界の滅びごとに新しい世界を夢見た結果だった。
- 無の女神ノアはユミルを復活させるため、人間へ分け与えられた創世のちからを利用し、世界の破壊と再創造を繰り返してきた。だがユミルは人間を愛して夢の世界を支え続け、ノア自身も懐音の母の記憶と歌を通じて、懐音たちを愛するようになっていた。
- 惑星サイズのアスタルは、フレストニアの全生命を刈り取って魂の情報を凝縮した「究極生命の結晶」であり、地球へ落ちて新しい生命を始めるはずだった。しかしユミルとノアの力は尽き、文化祭当日に世界の終わりが迫る。
- 懐音とまりかは、ユミルをあきらめたノアの前で演奏し、世界を終わらせないと訴える。ユミルの心臓はそれに応え、まりかは歌を通じてユミルから創世の巨人の役目を受け継ぐ。まりかは「世界そのもの」になり、世界を支える終わらない歌を歌い続けるため、懐音の前から消える。
- まりかを失った懐音は、それでも彼女が守った世界を本物にすると決める。ノアは懐音へ永遠（AEON）の咒いを祝福として与え、消滅する。数十年後も姿の変わらない懐音は、別の何かに生まれ変わってもまりかを見つけると誓い、歌い続ける。
- **神獣の登場：** 明記なし。ユミルは世界を夢見て支える黄金の巨人、アスタルは生命情報を凝縮した巨大天体、ノアは無の女神として描かれるが、本文ではいずれも神獣とは呼ばれない。
- **推測される元ネタ：** 北欧神話のユミルと世界創造、終末後の再生、夢としての世界や反復する世界を扱うSF／ループ物。歌によって世界を支えるまりかの役目は、作中で確定した原典はない。
