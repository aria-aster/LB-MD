# The Elder Scrolls V: Skyrim

Bethesda Game Studiosが開発したオープンワールドRPG。世界を終わらせる竜アルドゥインの帰還と、竜の魂を吸収できる主人公ドラゴンボーンとの戦いが主筋となる。

## アルドゥイン

「世界を喰らう者（World-Eater）」と呼ばれる竜。ノルドの伝承では世界の終わりをもたらし、次の時代へ移る周期に関係する存在とされる。一方、ゲーム本編で帰還したアルドゥインは、人間を支配した過去を持ち、死者の国ソブンガルデで魂を食べて力を回復する。

名称上は世界を食べる存在だが、ゲーム画面で惑星を丸ごと捕食するわけではない。「生命の魂を食べて強くなること」と「現在の世界を終わらせ、次の周期をもたらすこと」が結び付いている。

# ANASでの対応候補

- **アルドゥイン：** [[金浮/怪物]]、[[sky/book/divines/謳：18.黄金城の神獣]]。生命を食らうほど強大化し、最後には世界を終わらせるという段階が近い。また、ひとつの世界の終わりが次の世界・周期への移行になる点でも比較できる。ANASの怪物が周期を管理する存在かどうかは未確定。
