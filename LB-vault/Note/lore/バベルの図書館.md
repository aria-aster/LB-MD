# バベルの図書館

ホルヘ・ルイス・ボルヘスの短編小説。宇宙そのものが、六角形の部屋を無限に連ねた図書館として描かれる。そこには一定の文字と形式で作れる、あらゆる本が存在する。

全真理を記した本も、自分の人生の完全な記録も存在するはずだが、意味のある本はほぼ無限の無意味な文字列に埋もれる。完全な情報が存在しても、それを見つけて解釈できなければ全知にはなれないという逆説を扱う。
