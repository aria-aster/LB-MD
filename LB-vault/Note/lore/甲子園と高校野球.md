# 甲子園と高校野球

一般に「甲子園」は、阪神甲子園球場で行われる春の選抜高等学校野球大会と、夏の全国高等学校野球選手権大会を指す。特に夏の大会は地方大会を勝ち抜いた代表校が全国制覇を争い、高校球児の夢の舞台として扱われる。

高校野球漫画では、廃部寸前の部、弱小校、因縁のライバル、才能ある問題児、負傷、最後の一球などが定番となる。個人競技でなく、仲間への信頼と継投・打順などの役割分担がドラマを作る。
