# エンドレスエイト

谷川流のライトノベル「涼宮ハルヒの憂鬱」シリーズの一編。夏休みを終わらせたくないという無意識の願いによって、同じ二週間あまりが一万回以上繰り返される。多くの人物は記憶を失って次の周回へ入るが、長門有希だけはすべてを記憶している。

アニメ版では、ほぼ同じ出来事を新規作画・演出で八話連続して描き、視聴者にも反復の停滞を体験させた。最後は未完了だった夏休みの宿題を皆で行うことで、ループが終わる。
