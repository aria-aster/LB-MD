# 白鯨

ハーマン・メルヴィルの長編小説。語り手イシュメールは捕鯨船ピークォド号へ乗り込み、片脚を奪った白いマッコウクジラ「モービィ・ディック」への復讐に取り憑かれた船長エイハブと航海する。

エイハブは自然や運命そのものへ挑むように白鯨を追い、三日間の死闘の末、自ら投げた銛の綱に巻き込まれて海へ消える。船も沈み、棺を浮き輪にしたイシュメールだけが生き残る。復讐する者が対象と切り離せなくなり、破滅へ呑まれる物語である。
