# 大鴉

エドガー・アラン・ポーの物語詩。亡き恋人レノーアを悼む語り手の部屋へ、夜中に一羽の大鴉が入り、胸像の上へとまる。鴉はどの問いにも「Nevermore（二度とない）」とだけ答える。

語り手は再会や救いの可能性を自ら問い続け、同じ返答によって絶望を深めていく。鴉が超自然的な使者なのか、ただ覚えた言葉を繰り返す鳥なのかは確定せず、喪失へ囚われた心が中心に置かれる。
