# 恋はデジャ・ブ

ハロルド・ライミス監督、ダニー・ルービンとライミス脚本による映画。気象予報士フィルが、取材先の町で同じ一日を何度も繰り返す。最初は混乱するが、翌日に結果が残らないことを利用して快楽や犯罪へ走り、やがて絶望して自殺を繰り返しても翌朝へ戻される。

脱出方法が見つからない中、フィルは他者を理解し、技能を学び、人を助ける生活へ変わっていく。時間を攻略するのでなく人格が変わったとき、初めて翌日が訪れる。タイムループによる自己変革物語の代表例。
