# 白鳥の湖

チャイコフスキー作曲のバレエ。王女オデットは悪魔ロットバルトの呪いによって白鳥へ変えられ、夜だけ人間の姿へ戻る。王子ジークフリートは彼女へ永遠の愛を誓おうとする。

しかし舞踏会でロットバルトの娘オディールがオデットに似た姿で王子を欺き、誓いを奪う。結末は上演版によって異なり、二人が死によって結ばれる悲劇、悪魔を倒して呪いを解く結末などがある。オデットとオディールを同じ踊り手が演じる演出が一般的で、白と黒、真実と偽装の対が強調される。
