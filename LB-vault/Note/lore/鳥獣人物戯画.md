# 鳥獣人物戯画

京都・高山寺に伝わる四巻の絵巻物。制作時期や作者は一人に定まらず、平安時代末から鎌倉時代にかけて複数の手で作られたと考えられている。

最も有名な甲巻では、兎・蛙・猿などが相撲、水遊び、法会といった人間の営みを演じる。詞書を持たず、流れるような線と連続する場面で動きを表すため、漫画の祖と紹介されることがある。ただし、現代漫画へ直接つながる単一の起源と断定するのは単純化が過ぎる。
