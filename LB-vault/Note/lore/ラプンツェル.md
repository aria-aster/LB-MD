# ラプンツェル

グリム童話で知られる物語。魔女に育てられた少女ラプンツェルは、出入口のない高い塔へ閉じ込められ、長い髪を垂らして魔女を出入りさせる。王子も髪を伝って彼女に会うが、二人の関係を知った魔女によって引き離される。

王子は茨へ落ちて視力を失い、長い放浪の末にラプンツェルと再会する。彼女の涙で目が治り、二人は王国へ帰る。長い髪は牢獄を維持する道具であると同時に、外界と結ぶ道でもある。
