# メソアメリカ神話

## トラルテクトリ（シパクトリ）

メシカ（アステカ）の創世神話に現れる、海に浮かぶ大地の怪物。ワニやヒキガエルに似た姿、大きな牙、関節にまで並ぶ無数の口、肉を求め続ける食欲を持つとされる。伝承によってはシパクトリという名でも語られる。

ケツァルコアトルとテスカトリポカが巨大な蛇となって怪物を引き裂き、その身体から天地を作る。皮膚から草花、髪から樹木、目から泉、肩から山、口から洞窟や川が生じたとされる。世界となった後も飢えは消えず、血と心臓を要求し続ける。

トラルテクトリは死者を呑んで変容させる大地であり、夕方には太陽もその大口へ呑み込み、翌朝に再び吐き出すと考えられた。したがって「世界の外から世界を食べる怪物」ではなく、「怪物の身体が世界となり、世界にある生命と天体を食べ続ける」という反転した世界喰らいである。

# ANASでの対応候補

- **トラルテクトリ：** [[金浮/怪物]]、[[金浮/真の龍]]、[[sky/book/divines/謳：18.黄金城の神獣]]、[[sky/book/ooparts/真の龍の肉]]。無数の口を持つ巨大な怪物、尽きない捕食、神々の力と肉体、死んでも世界や生命を支える物質へ変わるという組合せが近い。ANASの怪物は世界を食べて別世界へ渡るのに対し、トラルテクトリは殺されてその身体自体が世界になるため、方向は逆である。
