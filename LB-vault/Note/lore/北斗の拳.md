# 北斗の拳

武論尊・原哲夫による漫画。核戦争後、文明と秩序を失った荒野で、暗殺拳「北斗神拳」の伝承者ケンシロウが暴力的な支配者たちと戦う。水や食料を奪う略奪者、巨大な悪党、各地を支配する拳法家が登場する。

ケンシロウは弱者を守りながら、宿敵や兄弟弟子との因縁を決着させる。荒廃した世界、怪力の巨漢、拳法による一対一の戦い、力による支配と慈愛の対立が大きな特徴。
