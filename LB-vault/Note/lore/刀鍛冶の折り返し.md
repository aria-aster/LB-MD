# 刀鍛冶の折り返し

日本刀の製作では、鋼を加熱して打ち延ばし、折り返して再び鍛接する工程を繰り返す。炭素量や不純物の偏りをならし、素材を均質化するための工程で、折り返した回数だけ単純に強度が増すわけではない。

異なる性質の鋼を組み合わせ、焼き入れによって硬い刃と粘りのある芯を作る工程全体が重要である。物語上は、破壊と再結合、反復による精錬、素材から新しい性質を引き出す象徴として使われる。
