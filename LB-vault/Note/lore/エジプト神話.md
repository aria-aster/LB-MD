# エジプト神話

## アアル

アアル（葦の野、供物の野）は、死者が審判を通過した後に暮らす理想郷。現世のエジプトに似た豊かな土地で、死者は農耕を行い、神々と共に永続的な生を送ると考えられた。

死者の心臓は真理の女神マアトの羽根と秤にかけられ、正しい者だけがこの来世へ進める。アアルは単なる天国ではなく、現世の秩序と生活が完成された形で続く場所である。

## ネフェルトゥム

睡蓮から生まれた若い太陽神で、花の香り、美、癒やし、再生と結び付く。原初の水から開いた睡蓮から太陽が昇るという宇宙創成観を背景に持ち、プタハとセクメトの子としてメンフィスの神々の一柱にも数えられる。

## アポピス（アペプ）

闇と混沌を体現する巨大な蛇で、太陽神ラーと宇宙の秩序マアトに敵対する。太陽の舟が夜ごと冥界を進む際に襲いかかり、舟を止め、太陽の再生と翌朝の日の出を妨げようとする。ラーの一行やセトに退けられるが、翌夜には再び現れるため、戦いは反復される。

世界を直接丸ごと食べるというより、太陽を呑み、あるいはその運行を止めることで、光・時間・宇宙秩序を終わらせかねない存在である。「倒されても再び現れ、世界の成立を繰り返し脅かす」という点も重要となる。

# ANASでの対応候補

- **アアル：** [[sky/book/origin/謳：フォビドゥン]]。固有名が死後の楽園アアルと一致する。
- **ネフェルトゥム：** [[sky/book/origin/謳：ラプチュア]]。名称と、睡蓮・再生をめぐる神格。
- **アポピス：** [[金浮/怪物]]、[[sky/book/divines/謳：18.黄金城の神獣]]。生命や世界を食らう怪物と、太陽を呑んで世界秩序を終わらせようとする蛇の捕食像が対応候補。ただし、ANASの怪物にはアポピスのような「毎夜の敗北と再来」は明記されない。
