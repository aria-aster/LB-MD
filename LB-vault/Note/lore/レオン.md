# レオン

リュック・ベッソン監督の映画。孤独な殺し屋レオンは、家族を腐敗した麻薬捜査官に殺された少女マチルダを匿う。マチルダは弟の復讐のため殺しを教えてほしいと頼み、二人は不器用な共同生活を始める。

レオンは彼女を守るため組織と警察に立ち向かい、最後には自分を犠牲にして敵を倒す。マチルダは生き残り、レオンが大切にしていた鉢植えを土へ植える。孤独なプロが最後の仕事で子供を救い、人間性を取り戻す型として影響が大きい。
