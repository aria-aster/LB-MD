# ジャングル・ブック

ラドヤード・キプリングの短編集。最も有名な連作では、人間の子モーグリが狼の群れに育てられ、熊のバルーや黒豹バギーラからジャングルの掟を学ぶ。人食い虎シア・カーンとの対立を経て、自分が人間と動物のどちらに属するかに向き合う。

動物の共同体は自由な楽園ではなく、厳しい掟、教育、責任を持つ社会として描かれる。人間社会へ戻る結末も含め、異なる二つの世界に属する子供の成長が中心となる。
