# マッドマックス

ジョージ・ミラー監督を中心に作られた、文明崩壊へ向かう世界を舞台とする映画シリーズ。元警官マックスは家族を奪われた後、法と共同体の外をさまよいながら、燃料や水を独占する暴力集団と、生存を求める人々の争いへ巻き込まれる。

改造車による追跡、革や金属をまとった略奪者、荒野の砦、希少資源を握る支配者が終末世界の視覚的な型となった。マックスは救世主として定住するより、共同体を助けて再び去る放浪者として描かれることが多い。
