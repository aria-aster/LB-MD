# アカシックレコード

宇宙で起きたあらゆる出来事、思考、感情が非物質的な領域へ記録されているという近代神秘思想上の概念。サンスクリット語の「アーカーシャ（空間・虚空）」をもとに、神智学や人智学の思想家が発展させた。

霊的な訓練や透視によってその記録へ接続できるとされ、過去だけでなく未来の可能性まで読めるという説もある。古代から単一の教義として存在したものではなく、19世紀以降に形成された概念である。
