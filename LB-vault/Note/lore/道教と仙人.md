# 道教と仙人

道教は中国で形成された宗教・思想の複合体で、道との調和、養生、不老長生、祭祀、護符、錬丹など多様な実践を含む。老子・荘子の思想と関係するが、それだけで道教全体を説明することはできない。

仙人は修行や霊薬によって俗世の制約を超え、長寿や飛行、変化などの力を得た存在として語られる。山中の師への入門、呼吸法・内丹術、珍しい薬草や宝物の探索といった要素が、武侠・仙侠物語へ受け継がれた。
