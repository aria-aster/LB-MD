# 一九八四年

ジョージ・オーウェルのディストピア小説。全体主義国家オセアニアでは「ビッグ・ブラザー」が人々を監視し、真理省が過去の記録を書き換え、ニュースピークが反抗を考えるための言葉そのものを削っている。

主人公ウィンストンは密かに体制へ反発し、ジュリアと愛し合うが、思想警察に捕らえられる。拷問と恐怖によって互いを裏切り、最後には体制を愛するよう精神を作り替えられる。監視だけでなく、記憶・言語・事実を支配する権力の物語である。
