# もののけ姫

宮崎駿監督のアニメーション映画。呪いを受けた青年アシタカは治療法を求めて西へ旅し、森を守る山犬の神々と、人間の製鉄集落タタラ場の争いに遭遇する。山犬に育てられた少女サンは人間を憎み、エボシ御前は森を切り開きながら社会から疎外された人々を守る。

自然か人間かの一方だけを善とせず、双方の生存と暴力を描く。シシ神の首をめぐって森とタタラ場は破壊されるが、完全な元通りではない再生が始まり、アシタカとサンは別々の場所で生きながら会うことを選ぶ。
