# 眠れる森の美女／いばら姫

王女の誕生祝いに招かれなかった妖精が、王女は糸紡ぎの錘に刺されて死ぬと呪う。別の妖精が死を百年の眠りへ弱め、予言どおり王女と城全体が眠りにつく。城は茨に覆われ、百年後に王子が到達すると王女が目覚める。

ペロー版には結婚後、王子の人食いの母から王妃と子供たちが狙われる後半がある。グリム版「いばら姫」では百年の眠りと接吻までが中心。ブライア・ローズは「野ばら」を意味する英語名として用いられる。
