# ファウスト

知識と経験に飽き足らない学者ファウストが、悪魔メフィストフェレスと契約する伝説。魂を代価として、この世で望みや快楽を与えられる。歴史上の魔術師にまつわる伝承から民衆本、マーロウの戯曲、ゲーテの戯曲へ発展した。

ゲーテ版では、ファウストは恋人グレートヒェンを悲劇へ巻き込みながらも、満足せず行為と探求を続ける。最後は公共のための事業を夢見た瞬間に死ぬが、その絶えざる努力と神の恩寵によって魂は救われる。単純な「悪魔に魂を売って破滅する話」だけではない。
