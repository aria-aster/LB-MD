# 般若心経

大乗仏教の「空」の思想を非常に短くまとめた経典。観自在菩薩が、あらゆる存在には固定不変の実体がないと見抜き、苦しみを超えたと説く。

「色即是空・空即是色」は、形あるものが無意味・無存在だという単純な虚無ではない。現象は独立した実体を持たず、さまざまな条件によって成り立つからこそ「空」であり、空は現象から離れた別世界ではない、という相互関係を示す。

終盤の真言は、智慧の完成によって迷いを越え、覚りへ進むことを力強く表現する。
