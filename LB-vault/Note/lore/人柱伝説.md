# 人柱伝説

橋、堤防、城などの大規模建造物を安定させるため、人間を生きたまま、または死者として基礎へ埋めたと語る築造伝説。水害や工事の難航を、土地や水の神へ人命を捧げることで鎮めるという説明を伴うことが多い。

誰を犠牲にするかは、偶然その場を通った者、旅人、村人から選ばれた者、くじで当たった者など地域によって異なる。実際の人身供犠を伝える例も否定できないが、史実を裏付けられない伝説も多く、後世の慰霊・説明物語として扱う必要がある。
