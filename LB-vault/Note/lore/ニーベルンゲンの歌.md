# ニーベルンゲンの歌

中世ドイツの英雄叙事詩。英雄ジークフリートは竜を倒し、その血を浴びてほぼ不死身となり、ニーベルンゲンの財宝を得る。だが背中の一か所だけが弱点として残る。

ジークフリートは王妃ブリュンヒルトをめぐる欺きと宮廷の対立に巻き込まれ、弱点を知られた末に暗殺される。妻クリームヒルトは長い年月をかけて復讐を企て、それが一族と王国を巻き込む大量死へ至る。竜の宝、不死身の英雄、呪われた財宝、復讐の連鎖が結び付く。
