# イルカがせめてきたぞっ

小学館「なぜなに学習図鑑」第9巻「なぜなに からだのふしぎ」に掲載された、小松崎茂による未来予想図を元にしたネットミーム。海中都市らしき場所へ装備を付けたイルカが押し寄せ、人間が「イルカがせめてきたぞっ」と叫ぶ強烈な絵面で知られる。

本来の文脈は、未来にはイルカの知能が発達し、人間と戦う可能性もあるという空想的な予測だったとされる。切り抜かれた画像がインターネットで拡散し、武装イルカや人類への反乱を表す定型ネタになった。
