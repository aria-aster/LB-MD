# ピノキオの冒険

カルロ・コッローディの児童文学。大工ジェッペットが作った木の人形ピノキオは生命を持つが、誘惑に弱く、嘘や怠惰によって何度も危機へ陥る。良心役のコオロギ、青い髪の妖精、狐と猫、巨大な魚などが登場する。

失敗と罰を重ねたピノキオは、父を救い、働いて家族を支える責任を学ぶ。最後に「善い子」と認められ、人間の少年となる。人造物が人間性を獲得する代表的な成長譚。
