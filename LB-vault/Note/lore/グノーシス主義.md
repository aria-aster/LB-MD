# グノーシス主義

古代地中海世界で広がった複数の宗教思想をまとめた呼称。物質世界を不完全または悪しきものと見なし、人間の内に高次の神的な火花が閉じ込められていると考える体系が多い。救済は信仰だけでなく、自分の本来の由来を知る特別な認識「グノーシス」によってもたらされる。

多くの体系では、至高神とは別の下位の造物主デミウルゴスが物質世界を作ったとされる。デミウルゴスは無知ゆえに自分を唯一神だと思う場合も、明確に敵対的な支配者として描かれる場合もある。ソフィア、アイオーン、アルコーンなどの名と複雑な宇宙論を持つが、宗派ごとの差が大きい。
