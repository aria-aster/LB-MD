# 鉄の処女（アイアンメイデン）

内側に針を備えた人型または棺型の箱へ人を閉じ込める拷問・処刑具として知られる。とくに「ニュルンベルクの鉄の処女」が有名で、中世の残虐な刑罰というイメージを代表する。

ただし、中世に実用されたことを示す確かな証拠は乏しい。現在知られる器具の多くは、近世以降の部品を組み合わせ、18～19世紀に「中世の拷問具」として作られた可能性が高い。史実というより、後世が作った暗黒の中世像に属する伝承である。
