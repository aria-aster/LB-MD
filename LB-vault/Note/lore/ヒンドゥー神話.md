# ヒンドゥー神話

## シヴァ

ヒンドゥー教の主要な神の一柱。破壊だけでなく、再生、苦行、舞踊、恩寵など多面的な性格を持つ。ブラフマーを創造、ヴィシュヌを維持、シヴァを破壊に配する三神一体（トリムールティ）の説明では、宇宙の寿命が尽きたときに古い世界を終わらせ、次の創造が可能な状態へ戻す役を担う。

シヴァの舞踊、とりわけナタラージャの宇宙舞踊は、創造・維持・破壊・隠蔽・解脱という宇宙の働きを表すものとして解釈される。したがってシヴァの破壊は、飢えから世界を捕食する怪物の行為ではなく、循環する宇宙に必要な解体と更新である。

## ラーフ

乳海攪拌の際、神々に紛れて不死の霊薬アムリタを口にしたアスラ。太陽神と月神に正体を告げられ、ヴィシュヌの円盤によって首を切られるが、すでに霊薬を口にしていた頭部は不死となった。ラーフは告げ口をした太陽と月を追い、時おり呑み込む。そのために日食と月食が起こると説明される。

胴体を失っているので天体を完全には消化できず、太陽と月は再び現れる。世界そのものではなく、世界を照らす天体を一時的に食べる存在であり、アポピスやスコル、ハティと同じ「蝕を宇宙的捕食として語る」系統に属する。

# ANASでの対応候補

- **シヴァ：** [[金浮/怪物]]、[[sky/book/divines/謳：18.黄金城の神獣]]。ひとつの世界を終わらせた後、別の世界へ移る怪物に「世界の終端と次の始まり」という構造上の類似はある。ただし、怪物は生命を食らう存在、シヴァは次の創造へつなぐ宇宙的機能を担う神であり、捕食者としての直接的な元ネタ候補としては弱い。
- **ラーフ：** [[金浮/怪物]]、[[sky/book/divines/謳：18.黄金城の神獣]]。世界全体ではなく太陽と月を呑むが、宇宙規模の捕食を巨大な口で表す点が対応候補。飲み込んだ天体を保持できない点は異なる。
