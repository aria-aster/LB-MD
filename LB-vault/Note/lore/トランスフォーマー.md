# トランスフォーマー

変形するロボット生命体の戦争を描く、ハズブロとタカラ（現タカラトミー）の玩具・アニメ作品群。ユニクロンは1986年のアニメ映画「The Transformers: The Movie」で本格的に登場した。

## ユニクロン

惑星ほどの大きさを持ち、惑星形態から巨大なロボットへ変形する存在。「惑星を喰らう者（Planet Eater）」であり、巨大な口で惑星そのものを砕いて吸収する。作品世界によって起源や目的は異なるが、しばしば「混沌をもたらす者」として、宇宙を消費し続ける終末的存在となる。

惑星を食料にする点だけでなく、自身が惑星に見える姿を取り、食べた世界を自分の内部へ取り込む点が特徴となる。

# ANASでの対応候補

- **ユニクロン：** [[金浮/怪物]]、[[金浮/真の龍]]、[[sky/book/divines/謳：18.黄金城の神獣]]。ひとつの世界を丸ごと食べ、次の世界へ移動する点で直接性が高い。巨大な肉塊となったANASの怪物と、機械の惑星であるユニクロンでは外見と成立過程が異なる。
