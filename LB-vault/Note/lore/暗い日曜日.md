# 暗い日曜日

ハンガリーのシェレシュ・レジェーが作曲し、1930年代に発表された歌曲。原題は「Szomorú vasárnap」。広く知られる歌詞は詩人ヤーヴォル・ラースローによるもので、失われた恋人や死を思う陰鬱な内容を持ち、後に各国語で歌われた。

この曲を聴いた多数の人が自殺したため放送禁止になったという「自殺の聖歌」の都市伝説が広まった。個々の自殺と曲の直接的な因果関係を裏付ける確かな証拠はなく、不況・戦争前夜の社会状況、扇情的な報道、歌詞の暗さが結び付いて形成された伝説と考えられる。
