# 本文
前作「アンナマリー」の立ち位置かと思ったら、そこそこ違う様です。

アンナマリーは、聖母マリアとその母アンナが由来のよく使われる名前です。
慈悲深いとかそういうかんじですね。

創造主に近い人の呟きによると、アイノは「I know」で、ユノは「You know」だそうです。
直訳すると「私は知っている」「あなたは知っている」になるのですが、
話の切り出し方、締め方でも使われます。
アイノは「いい？聞いて？」
ユノは「ちょっと聞いてよぉ」
こんな感じのニュアンスというか、ベクトルの違いですね。
わたし→あなた　か　あなた→わたし　か。

アンナマリーとユノはともにフレストニア／ユーファリアを救おうと活動する立ち位置なのですが、
一方は超常的なちからを用いるのに対し、
一方はそういったものは無く、立ち回りで活動する対比になっているのでしょう。
