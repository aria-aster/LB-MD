# はじめに
・ユーファリアとはどういう世界なのか
・メイン作戦で進んでいたストーリーとは何だったのか
という考察のまとめになります。

>２度も打ち切りゴメンを食らったプレイヤーの戦いの記録でもあります。

単純に、こうだったらストーリーのロジックが通るかな？ぐらいです。
「こうしちゃうと、あれが変になるけどまぁ・・・ええか！」とか平気であります。
なので、妄想度は高いと思います。うへへ。

鏡の世界だとか、これは何々のオマージュだとか、そういう部分にはあまり触れていません。
考察するにあたってのヒントになるのとは思うのですが、それは別の楽しみ方です。

あと、ANGELICA ASTERのメインストーリーは「天使と神獣の戦い」のお話です。
オマケでいろいろなストーリーが存在しますが、
正直なところ、世界観とかをあまり深く考えなくても何も問題無いです。

ですので、この先を読もうとする方にご忠告します。

「この作品、打ち切り未完ですからね？」
