# ユーファリアの歴史（全体）
「色から考える世界の交わり」を元に、ユーファリアの歴史を組み立てみましょう。
[[Note/speculation/色から考える世界の交わり（その２）]]

まず、ゴールのVerseを決めます。
==🔵・黒鉄==
です。
何故かというと、「ユーファリアは暗黒時代から始まっている」からです。（そこそこ無理やり）
[[Note/speculation/＊04.History (Part 1)#暗黒時代（約２００年前）]]

で、黒鉄と同じ登場人物等が存在しているVerseがあります。
==🟠・緋桜==
です。
シティとか死人王とか両方のVerseで確認できます。

となると、
==🟠緋桜==→==🔵黒鉄==
でVerseが進んだと予想されます。

で、残りのVerseの色は「紫」「黄金／黄色」「赤」「白」です。
はい、考えて組み立てた順に書きました。

==🟣紫夜==→==🟡金浮==→==🔴赤穣==→==🟢白城==→==🟠緋桜==→==🔵黒鉄==
この順です。

残りは「==🔵灰世==」ですが、「終わらない歌の神獣の謳」で書かれています。

この星はとっくに、彗星の衝突で滅んでいる
衝撃で大気は吹き飛び、海は干上がり大規模な地殻変動が起こる
[[sky/book/divines/謳：29.終わらない歌の神獣#Page 1-11]]

>あれ...どこかに干上がった星がありましたよね…？
>[[干からびた星]]

「灰世」は色から考えた場合、「*赤緑青全てがちょっと減った*」状態になってしまいます。
各Verseではこのような状況は存在しないので、上の流れとは別軸であると思います。
なので、
「緋桜」で「灰世」が合流して真っ黒になった。
もしくは、
「灰世」で「緋桜」が合流して真っ黒になった。
のどちらかと考えるのが妥当かなと思います。

「緋桜」を構成していた光が消えた（奪われた）ので、真っ黒になった的な考え方もアリかもしれません。
一番やらかしそうなパイセンがいますからね、もうなんでもアリな気がします。
