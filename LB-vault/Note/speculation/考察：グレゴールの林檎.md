## 「グレゴール」

朝起きると巨大な虫（Ungeziefer）になっていたという話で、リンゴを投げつけられたりするそうです。

### 「グレゴール」に近い名前・単語

| 表記                  | 読みの目安  | 意味・由来                          |
| ------------------- | ------ | ------------------------------ |
| Gregorius           | グレゴリウス | ラテン語形の人名「グレゴリオス」               |
| Gregor              | グレゴール  | ドイツ語などで使われる人名。ラテン語形の短縮・対応形     |
| Gregorius ← grēgor- | —      | 元をたどるとギリシャ語の「目覚めている、注意深い」に関係する |
| vigil               | ウィギル   | 見張り、夜警、警戒。ラテン語の実在語             |
| vigilare            | ウィギラーレ | 目を覚ましている、警戒する、見張る              |

厳密には、Gregor と Gregorian が直接変化してできたということではなく、
どちらも Gregorius 系統の名前に由来する形なんだ。

つまり、
- グレゴール：人名の Gregor
- グレゴリウス：ラテン語の Gregorius
- グレゴリオ暦：グレゴリウス13世の名に由来する暦
- グレゴリアン・チャント（グレゴリオ聖歌）：伝統的にグレゴリウス1世と結び付けられてきた聖歌
これらは同じ名前の系統でつながっている。
ちなみに、グレゴリオ暦を導入したのはグレゴリウス13世で、グレゴリオ聖歌と結び付けられるのはグレゴリウス1世。別人だよ。
結論：グレゴールは、暦や宗教音楽にもつながる、ヨーロッパで長く使われてきた人名なんだね。
