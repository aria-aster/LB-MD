# 本文
ブラスフェミィに生えている、グレゴールの林檎のなる樹に埋まっている人です。
この人（アンナマリー）については、前作での話が全てと思うので、そんなに考察するポイントはありません。

# アンナマリー
前作のナビゲータ役であり、流火の巨神の登場人物です。
・名家のガフ家出身だが、没落してしまった。
・保育園で働いていた。
・男に騙されてガフ家は乗っ取られてしまい、ちょっと壊れ気味。
・子供たちと遠足に出かけた際に乗っていた列車が事故にあう。
・あの世？で「アンタレス行き≪自己犠牲号≫」の車掌を押し飛ばして盗む。（読み返したけど盗んでた…）
・フレストニアに途中下車して子供たちと別れる。
・フレストニアの終わりに際して、はみ出た物語（※）を載せてフレストニアを去っている。
※アスタル彗星とか以外の、物語で語られなかった人達などの事だと思われる。

ブラスフェミィはアンナマリーの神器「キンダーガーデン」の上に乗っています。
キンダーガーデンがいつブラスフェミィになったのかはわかりません。

# なんで林檎の樹になっとるの？
全くもってわかりません。書かれてないので。

エデンの園に「善悪の知識の木」があります。
アダムとイブが蛇に唆されて食べた果実がなるヤツですね。

アンナマリーは「自己犠牲」の激しい人です、エイプリルみたいに「アパー」言いながら暴れたりはしません。
なので、ユーファリアを救うには「林檎を食べさせて神の園から追い出されるのが良い」とか考えたのなら、たぶん実行する人なのでしょう。

# 6/17の日付で２回行われたイベント
１回目は「魂の循環」
２回目は「魂の帰還」です。

「帰還」でキンダーガーデンにあったオブジェクトが数個増えています。
例えば、左上は「モーリスがアンナマリーと別れる際に渡した、彼の黒いブリキのおもちゃ」です。
アンナマリーの思い出の品（人？）も「帰還」した、という事なんですかね？
３回目があったら何というタイトルになっていたのでしょうか。

「循環」→「帰還」は、別の考察と同じような流れになります。
死者が帰ってくる、世界へ。
[[Note/speculation/＊05.To a world where the dead return.#死者が帰ってくる、世界へ。]]

で、ブラスフェミィは「いつ」ユーファリアに来たのか？を考えます。
[[Note/speculation/＊06.History (Part 2)#ユーファリアの歴史（全体）]]

フレストニア→灰世の干からびた星→灰世のユミルを解放→灰世の魂をのせて地球へ
