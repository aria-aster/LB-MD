# 封印
具体的には、黙示録第6章に登場する「**小羊が第六の封印を解いた時の情景**」がベースとなっています。

| 封印の順番     | 現れるもの・出来事              | 地上にもたらされる具体的な意味                                                        |
| --------- | ---------------------- | ---------------------------------------------------------------------- |
| **第1の封印** | **白い馬** と騎士            | **征服・勝利**  <br>（他国を支配しようとする人間の「支配欲」や、偽りの平和の始まり）                        |
| **第2の封印** | **赤い馬** と騎士            | **戦争・殺し合い**  <br>（巨大な剣が与えられ、地上から平和が奪われて内乱や戦争が起きる）                      |
| **第3の封印** | **黒い馬** と騎士            | **飢饉（食糧難）とインフレ**  <br>（天秤を持った騎士が現れ、小麦などの食料の価格が暴騰する）                    |
| **第4の封印** | **青白い馬** と騎士           | **大量の死（病死・野獣の害）**  <br>（騎士の名は「死」。地上の4分の1の人間が、剣、飢餓、疫病で命を落とす）            |
| **第5の封印** | 祭壇の下の **殉教者たちの叫び**     | **天上のシーン**  <br>（信仰のために殺された人々の魂が「神様、いつ裁いてくれるのですか」と訴える）                 |
| **第6の封印** | **大地震と天変地異**           | **宇宙規模の崩壊とパニック**  <br>（太陽が暗くなり、月が血の赤になり、星が落ちる。全人類が恐怖で逃げ惑う）             |
| **第7の封印** | **静けさ**、そして **次の大災害へ** | **最終ステージへの移行**  <br>（天が30分ほど静まり返った後、7人の天使に「7つのラッパ」が与えられ、さらなる激しい災いが始まる） |
