# 本文
６１７という数字が妙に強調されます。
６月１７には謎のイベントがありますし、
オーパーツ：ジレーネ＃６１７や渋谷１０９が６１７になっているなど、拘りがあります。

単に、誰かの誕生日とかそういう感じなダケかもしれませんが。（某寺田的な）
６１７がどういう数字なの？というお話です。

## 創世記６章１７節
創世記６章１７節　神がノアに「洪水によって地上の生命を滅ぼす」と告げる

「ネフィリム」とか「方舟」とかありますので、あやしいですね。
楽園にある不死の食べものとか、創世記に限定せずども
神話の類は再演の元ネタになるので、色々と関連は考えられます。
