# 方針、前提など
まず、ゲーム内でVerseとつけられているものがあります。
直訳すると「節」とかになりますが、「舞台」と考えて貰ってもよいかもしれません。
種類等については「[[Note/speculation/＊01.Verse]]」を参照してください。

考察するにあたって、どのVerseなのかを把握する事は重要と思います。

特定できない等の例外はありますが、Verse毎に階層分けをしています。
同名のページ/項目でもあっても、別の「Verse」のページが存在している場合があります。
例をあげると、
	ページ名：鶏の揚げ物　Verse：一般　は　からあげの説明が書いてある
	ページ名：鶏の揚げ物　Verse：北の地　は　ザンギの説明が書いてある
このような感じになります。

本文等は「できるだけ、そのVerse範囲内のみの内容」を記載するようにしています。

例えば、天使に関してはほとんどの場合、
「本当の名前のページ（ほとんどはVerse:現在）」－「天使名」－「謳のVerseのとある登場人物」
の３つが繋がっている形になっているハズです。
[[Note/speculation/謳の種別（黄と青と彩）]]

「謳：テスパンチ」で語られる内容は、Verse：現在とVerse：紫夜の内容が含まれています。
Verse：現在の部分は「本当の名前のページ」に影響し、
Verse：紫夜の部分は「Verse：紫夜のとある登場人物名のページ」に影響しています。

ANGELICA ASTERの世界は、「神獣」が物語の「再演」を押し付けてきます。
世界が滅亡に至る物語も「再演」されたりしているので、
**おそらく同じモノであってもVerse毎に名称や見た目などが異なって場合があります。**
もしかしたら、同じ呼称であっても「役割」を表すものであって、人物名すら異なるかもしれません。

繰り返しになりますが、どのVerseでの情報なのかを意識してください、
鶏の揚げ物はからあげでもあり、ザンギでもあります。我々は戦争する必要はないのです。
