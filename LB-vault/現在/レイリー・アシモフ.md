# 別名

# 本文
軍需工場で働いていた整備士。
素直じゃないが、心配性で世話好き。頼られると放っておけない。
天使部隊の中でも屈指の常識人なため、よく周りに振り回され、問題ごとに巻き込まれる。

「別の工場に送られたら、この手紙を実家の工場へ届けてほしい。
一緒にいれた林檎は貴重なものだそうだ。売って手間賃にしてくれ」
