# フルネーム
セロン・パーシヴァル

# コールサイン
[[sky/book/arms/標：ハーキュリー]]

# 本文
女だけの盗賊団を率いて、軍列車を襲撃していた。
面倒見の良い姉御肌で、皆に頼りにされている。

隊長はさんざん悩んだあげく。 奇妙な林檎を、セロンに手渡した。
