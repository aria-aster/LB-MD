# フルネーム
イオナ

# コールサイン
[[sky/book/arms/標：メサイア]]

# 本文
はるか昔、世界を救った救世主と同じ名を持ち、「救世主」を自称する少女。
神獣と戦い、勝利し続けることが己の使命であると信じている。
救世主であることが彼女のアイデンティティであり、救世主であり続けるためなら、手段を選ばない。

（学園Ver.）
彼女自身は、学校生活を送ったことがないが、救世主として、すべての子供たちが教育を受けることができる世界になるべきだと考えている。
彼女は、メサイアという名の重さを知っている。学園Ver.と名乗るからには学園を救うつもりだ。

私は林檎を拾い上げる。
私が、 林檎を手に入れたという事実が意味することはただひとつ。
