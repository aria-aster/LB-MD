# フルネーム
柴まりか

# コールサイン
[[sky/book/arms/標：シヴァ]]

# 本文
空から落ちてきた林檎を永遠教会に売りつけた少女

明るく元気でうかつな少女。犬好きで、犬にも好かれる。  
無駄に行動力があるため、面倒ごとに巻き込まれがちではあるが、どこか憎めない。  
料理の美味しいお店に詳しく、休日は天使達を連れて食べ歩きをしている。

（1st Anniv.Ver.）
一周年おめでとう！　何のかわかんないけどめでたいね！
お祝いにはケーキかな、って思って作ろうとしたら、厨房爆発させちゃってさ。
見かねたセンパイが代わりにプリン買ってきてくれたんだ！　
お祝いにはやっぱりプリンだね！　ね、一緒に食べよう！

あたしの足下に、 ドサッと音を立てて何かが落ちる。 こわっ!
それは、虹色に輝く不思議な林檎だった
