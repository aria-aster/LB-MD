# フルネーム
ビリンダ・マブラ

# 別名
[[sky/book/arms/標：フロウレス]]

# 本文
元王国軍兵士。活発で勝ち気な愛され少女。
誰に対しても距離が近く、人の悩みに敏感で放っておけない世話焼きガール。それは、自分が寂しがり屋の裏返し。
幼い頃、イヌにかまれたので、断然ネコ派。

ビリンダは神獣がまき散らした遺物の中から 「林檎」を拾いあげた。
