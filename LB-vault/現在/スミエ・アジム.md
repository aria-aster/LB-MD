# フルネーム
スミエ・アジム

# コールサイン

# 本文
見事な肖像画で有名な画家。  
絵を描くのが好きで、艦の色々な場所で絵を描いている。  
最近は天使部隊の日常風景を切り取って、絵にするのがお気に入り。

気付くと、紙の上に林檎が乗っていた。
比喩ではない。虹色の林檎が、実際に目の前にあった。
