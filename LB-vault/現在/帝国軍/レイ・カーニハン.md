# フルネーム
レイ・カーニハン

# コールサイン
[[sky/book/arms/標：ショウグン]]

# 本文
カーラのご主人様

帝国の有力貴族のひとりで、古くから帝国を支えた軍人一族の出身。
彼女自身も指揮官として数多くの戦功をあげている。
その勇猛果敢な戦いぶりから、宴席での奔放な振る舞いまで、武勇伝には事欠かない。

レイが林檎を手に取り眺めていると、
「ご主人さま、食べちゃダメですぅ!」
メイドのカーラがびしっとはたき落とした。
「それは皇帝陛下からの賜りものです。後できちんと飾っておくです」
