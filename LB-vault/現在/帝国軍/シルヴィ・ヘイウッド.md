# フルネーム
シルヴィ・ヘイウッド

# コールサイン
[[sky/book/arms/標：シルバーバレット]]

# 本文
銃の名手で狩猟の達人。軍では部隊に数人しかいない選抜射手（マークスマン）に抜擢されている。
冷静沈着で感情があまり顔に出ない。
雪原出身のため寒さに強いが、暑さには弱いため、よく無言でバテている。

シルヴィは白い帽子の男に手を差し出すと、 渡された林檎にためらわずかじりついた
