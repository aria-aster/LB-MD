# フルネーム
プリヤンカ・シルバーバーグ

# コールサイン

# 本文
帝国兵　南部の少数民族出身
ディピカの友人

徴兵され、兵士として前線勤務をしていた少女。穏やかで誰にでも優しい。
ぼんやり空を眺めては、考え事をしていることが多い。
他者を否定せず、何事も受け容れる懐の広さがある。

ディピカが塵となって消えた場所にグレゴールの林檎が転がっていた。
