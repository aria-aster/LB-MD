# フルネーム
キャロライン・ベリー

# コールサイン
[[sky/book/arms/標：ブラッドベリー]]

# 本文
帝国軍の懲罰部隊。
軍医。複雑な人体をいじくりまわして元通りにすることを「おもしれー」と
思っているため怪我人から恐れられているが、腕は確か。
その言動のせいで軍上層部に疎まれている。

キャロラインは小さく片眉を上げ、
大口を開けて林檎にかじりついた。
