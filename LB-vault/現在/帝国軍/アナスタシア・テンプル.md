# 本文
甘やかされ、わがまま放題に育ったお嬢様。
悪役令嬢としてしたたかに生きているつもりだが、調子に乗りやすく愉快な言動を繰り返すため、周りからは面白カワイイヤツと愛されている。

お父様がバナナの皮で 滑って転んで頭を打って死ぬと、 
あっという間に没落してしまったのです。

と、いうわけで帝国軍に入隊しましたの。
