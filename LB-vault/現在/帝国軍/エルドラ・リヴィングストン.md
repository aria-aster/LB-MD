# フルネーム
エルドラ・リヴィングストン　（ほんとうの名前）
エルドラ・マイバッハ　（謳中）

# コールサイン
[[sky/book/arms/標：フレイム]]

# 本文
西方国境警備隊の隊長を定年まで務めあげた古参の軍人。
退役後の人生を神獣との戦いに捧げる。
思慮深く経験豊富なため、若い仲間たちにも慕われている。

帝国の西端。 荒野の向こうは連合王国の領土だ。
エルドラ・マイバッハが西方国境警備隊の一員となったのは十六の時だった。
[[sky/book/origin/謳：フレイム#Page 1-1]]

瓦礫と死体の間に、瑞々しく輝く林檎が落ちていた。
