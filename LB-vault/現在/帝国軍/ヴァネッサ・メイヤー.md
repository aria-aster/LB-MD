# フルネーム
ヴァネッサ・メイヤー

# コールサイン
[[sky/book/arms/標：ババヤガ]]

# 本文
王国兵から魔女と呼ばれた、帝国陸軍の叩き上げ軍曹。そのキャリアを生かし、新兵教育を担当していた。
鬼教官と恐れられていたが、面倒見が良く頼られることを喜ぶ。ぬいぐるみを戦闘隊形に整列させる癖がある。
