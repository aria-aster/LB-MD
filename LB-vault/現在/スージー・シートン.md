# フルネーム
スージー・シートン

# コールサイン
[[sky/book/arms/標：スシエル]]

# 本文
よくわからない　マッチョで寿司屋

天使の頂点に位置する寿司の大天使（自称）。
寿司は何よりも美味い。だから寿司の天使が一番偉い。
困った時は寿司を食え！それでもダメなら筋肉だ！パワー！

（新春Ver.）
今年の干支は広背筋！言祝き（ことぶき）を司る（つまり寿司の）大天使が言うからには間違いない。
悲しいときには寿司がキく！楽しくなったら筋トレだ！
スシとマッチョで人助け！お前がサンタになるんだよ。え？その話先週終わった？

ごろん、と死体をひっくり返すと、 荷物から果実が転がり出てきた。
それはきれいな林檎だった。
