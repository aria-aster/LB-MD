# フルネーム
リンファ・ヨウメイ

# コールサイン
[[sky/book/arms/標：ダークエンジェル]]

# 本文
帝国陸軍、 第十三研究所主任

ナルシストで独自の美学を持つ。
アーシュラ博士とは同期だが、常に二番手に甘んじており、一方的にライバル視している。
好きなファッションブランドはキャンディストライク。

その手には、もうひとつの グレゴールの林檎がある。
「見ていなさい。 スノ。 ・・・・・・あなたの愛した私が、 最高に美しい天使に なってみせますわ」
リンファは林檎を口に含み、噛み砕いた。
