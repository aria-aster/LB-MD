# フルネーム
イェニー・プレスタイン

# コールサイン
[[sky/book/arms/標：アルケイン]]

# 本文
冒険に憧れる名門貴族のお嬢様。
オーパーツが大好きで、自身による自身のための自身のオーパーツミュージアムを作るほど。
いつか自身の探検隊を率いて、まだ見ぬオーパーツを手にするのが夢。

(学園Ver.)
レリックハントが来る度にイキイキするオーパーツ大好き天使。学生時代はオーパーツと冒険のことしか考えていなかったが、今もそれは同じ。
ブラスフェミィの倉庫の一部を密かに私物化し、オーパーツミュージアムの再建をしている。

イェニーはガラスケースを開け、 グレゴールの林檎を手に取った。
「イェニー・プレスタイン　オーパーツに生き、オーパーツに死す」
