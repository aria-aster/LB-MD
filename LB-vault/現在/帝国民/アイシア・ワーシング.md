# フルネーム
アイシア・ワーシング

# コールサイン

# 本文
家族を殺され、神獣への復讐を誓った少女。
足が不自由だったが、天使化で得た強化装甲によって立って歩けるようになった。
聞き上手で面倒見が良いので、年下の子たちから好かれている。

男性はどこからか、虹色の林檎を取り出しました。
「ええ。この林檎を食べれば、天使となることができます運が良ければ」
