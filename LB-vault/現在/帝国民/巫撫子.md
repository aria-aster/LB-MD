# フルネーム
巫撫子

# コールサイン
[[sky/book/arms/標：フォーチュン]]

# 本文
由緒正しい家柄の箱入り娘だったが、親の言いなりだった自分と決別し、天使となった。
毎日が新鮮な刺激に満ちており、自分がいかに世間知らずだったかを思い知っている。

それは、宝石のようにきらめき、艶やかな光沢を放つ林檎でした。
人のものを、勝手に頂くのは、 もちろんよくないことです。
でも、私の目は、落ちた林檎から目が離せませんでした。
