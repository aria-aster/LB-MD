# フルネーム
キィラ・エアンド

# 別名

# 本文
帝都旧市街

ギャングの用心棒をしていた。「勝ち馬に乗る」が信条のため、敵が多い。
今のところ天使部隊は勝ち馬だと思っているらしい。

ガバルス組のボスを弾いたときにせしめた林檎だ。
聞いた話じゃ運が良ければ天使の力を授かるが、悪ければ死ぬらしい。
「いけるだろ。 あたしは最強だし」
