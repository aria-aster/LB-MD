# フルネーム
シドラ・ガーフィールド

# 別名
[[sky/book/arms/標：エンドレス]]

# 本文
帝都名家の娘だが、親から勘当されてしまった。
生意気で減らず口ばかり叩くが、最近は言いすぎたときにちゃんと謝れるようになった。
褒められた時、照れ隠しでキツイ言葉を吐いてしまうのを直したいと思っている。

「これは、やり直すための林檎さ」
あたしの胸元に、バアさんが林檎を押し込む。
