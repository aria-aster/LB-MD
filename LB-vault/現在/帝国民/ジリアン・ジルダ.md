# フルネーム
ジリアン・ジルダ

# 別名
[[sky/book/arms/標：ファング]]

# 本文
治安が劣悪な帝都旧市街の出身。ギャングの抗争に連なる復讐の連鎖の果てに、天使となることを選んだ。
近づきがたい雰囲気を放っているが、いつも周りを気にかけており、仲間への手助けを惜しまない。

妹をゴルギアス・ファミリーに殺された。

「もうひとつの道は、 林檎をかじること。あなたに資格があれば天使になれる。 
資格がなければ無様に死んでいく。 どう転ぶかは賭けですな」
