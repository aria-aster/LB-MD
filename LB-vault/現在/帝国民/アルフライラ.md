# フルネーム
アルフライラ

# コールサイン
[[sky/book/arms/標：ファタリタ]]

# 本文
踊ることと、人が喜ぶことが大好きな明るい少女。
帝都の踊り子小屋で踊り子のお姉さんたちと一緒に育つ。
彼女の名前は、踊り子小屋のおかみがつけてくれたもので、大変気に入っている。

永遠に燃え続けるアルフライラは、焼け落ちた眼で、炎の中に浮かぶ
奇妙な物を見た。不思議な色のあれは、林檎だ。
