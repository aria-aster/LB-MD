# フルネーム
クローディア・サッチェル

# コールサイン

# 本文
帝都の名門貴族出身のエリート。彼女の一族は裏工作により、帝国を影で支えていた。
礼儀正しく、落ち着きのある女性だが、実は悪戯好き。
度々、天使たちをからかって遊んでおり、そのせいで引き起こされた珍事件が数知れず存在する。

（チョコVer.）
昔、名家のお嬢様。今は、書類仕事に忙殺される限界軍曹。彼女の支えは推し活。
とある同僚天使を、無断かつ一方的に推しまくっている。
それってどうなの？と無粋なことを言う者にはカカオ99.99%のチョコをお見舞いする。

天使になるためのオーパーツ。 運が良ければ天使になれるが、悪ければ死ぬ。
過去の仕事で偶然手に入れた代物だ。いつか何かの役に立つのではと懐に忍ばせていた。
