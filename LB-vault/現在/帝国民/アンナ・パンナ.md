# フルネーム
アンナ・パンナ

# コールサイン
[[sky/book/arms/標：エクスカリパン]]

# 本文
帝都のパン屋

「パンに生き、パンに死す」が信条のパンを愛する天使。その名は「伝説の聖なるパン」に由来するが、彼女以外誰もその伝説を知らない。毎朝焼くパンは仲間の天使にも好評。焼いたパンで家具を作り、パンでできた部屋に住むという、パンライフを送っている。

（水着Ver.）
パンの天使は海でもパン！パンの浮き輪とパンのビーチボールは、いい匂いがするし、お腹が空いたら食べられるよ！とホクホクしていたが、防水性が足りなかった。
海水パンツを、最近までパンの一種だと思っていた。

この林檎を持ち帰ってから決めていた。
「ふーん、おいしそぉ~・・・・・・」
今夜の夕食はりんごパンだって。
