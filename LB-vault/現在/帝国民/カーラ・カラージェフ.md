# フルネーム
カーラ・カラージェフ

# コールサイン
[[sky/book/arms/標：ひよこ]]

# 本文
ショウグンの家に使用人として仕える一族の生まれ。
ノリと勢いで行動するため危なっかしい印象を受けるが、
炊事洗濯掃除はもちろん、戦闘訓練まで受けている優秀メイド。
得意料理はからあげ。

「生まれたときからカーニハン家にお仕えしてきた私が再就職なんて……。
うまくやれる気がしないです……」
私はもうひとつの林檎を手に取ります。
