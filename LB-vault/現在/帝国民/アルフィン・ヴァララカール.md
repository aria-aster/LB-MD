# フルネーム
アルフィン・ヴァララカール

# コールサイン
[[sky/book/arms/標：ナハティガル]]

# 本文
属性の玉手箱。情報過多の天使だが、盛りすぎた要素は彼女が13歳くらいの頃に好きだったものらしい。  
人付き合いが苦手なコミュ障で親しい友達がいなかったので、部隊の天使たちの優しさにまだ慣れていない。

（水着Ver.）
天使隊で1、2を争うインドア派だったが、海へ連れ出されてしまった。
いざ遊んでみると意外にも大満足。ちょっとだけアウトドアに目覚め、キャンプグッズを集め始める。
いつか夏祭りやキャンプにも行ってみたいと思っている。

「かじれ、願いを言え、 かじれ……」 耳を塞いでも林檎の声が聞こえてくる。
アルフィンは林檎を捨てた。 ゴミ箱に、トイレに、焼却炉に。それでも林檎は気づくと手元に戻っている。
