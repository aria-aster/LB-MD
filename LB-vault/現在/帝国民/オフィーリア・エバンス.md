# フルネーム
オフィーリア・エバンス

# コールサイン
[[sky/book/arms/標：スレイヤー]]

# 本文
銀鯨の神獣により、両親も、家も、街も、全部燃えた。 
オフィーリアは彷徨い、荒野に墜ちた艦たどり着き、甲板にある樹の林檎にかじりつく。

神獣が生み出す哀しみの連鎖を断ち切るため、神獣殺し《スレイヤー》として神獣を滅ぼす決意をした少女。
純真な心の持ち主で、常に踏みにじられる者たちに寄り添う。
武器は双剣の片割れで、どこかに対となる剣があるらしい。

（水着Ver.）
神獣殺しに、海は無縁のはずだった──神獣は空にいるのだから。
神獣殺しに、休息は無用のはずだった──まだ倒すべき神獣がいるのだから。
この夏、彼女が、海で出会うものは怪物か、怪獣か、それとも──

甲板の中央に青々と葉を茂らせて大樹が、
そびえていた。その枝には、林檎に似た虹色の実がなっている。
