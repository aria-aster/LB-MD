# フルネーム
シェリル・クリュソス

# コールサイン
[[sky/book/arms/標：ミラージュ]]

# 本文
ニッキーとコンビ

帝都のストリートで大道芸を披露していた国民的アイドルマジシャン（自称）。
お調子者で、大見得を切っては窮地に立たされるが、本番に強いため、今のところ何とかなってしまっている。

（水着Ver.）
来る日も来る日も食っちゃ寝を繰り返し、夏季休暇を満喫中のミラージュ。  
連れているゴーレムくんは、以前手品の小道具としてゴミ捨て場から拾ってきたもの。  
ミラージュに恩返しをするため、助手として頑張っている。
