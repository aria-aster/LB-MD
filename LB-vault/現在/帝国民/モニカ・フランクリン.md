# フルネーム
モニカ・フランクリン

# コールサイン
[[sky/book/arms/標：カノン]]

# 本文
帝立交響楽団員

クールで生真面目だが、音楽には熱い情熱を持っている。元楽団員で担当楽器はスーザフォン。
人づきあいは深く狭いタイプだが、友だちを増やしたくて、人目のある場所で練習している。

白い帽子の徴兵官はそう言うと、虹色に輝く林檎を見せた。
「あなたの言う年格好の女性がひとり天使隊に志願しました。
結果は、残念でしたが」
