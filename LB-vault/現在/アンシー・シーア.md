# フルネーム
アンシー・シーア

# コールサイン

# 本文
旅芸人
一座に生まれ、各地を巡業しながら育った。自身を育ててくれた占い師の師でもあるババを慕っている。
明るい性格でノリがいい。彼女の占いは評判がいいが、それは言ってほしいことを言ってくれるから。

「ふうむ……視力は戻らんようじゃの」 一座の占い師のババの声が聞こえる。
[[sky/book/origin/謳：オラクル#Page 1-4]]

「かわいそうに……そうじゃなぁ。ババの力をあげようか」
[[sky/book/origin/謳：オラクル#Page 1-5]]

翌朝、 わたしは目を開けすぐに飛び起きた。見えてる！ 視力が戻っている！
「いいかい、アンシー。ふたつ約束をして。
これから先、見えるはずないものが 視えたとしても、人に喋ってはいけないよ」
虹色の林檎をかじってはいけない」
