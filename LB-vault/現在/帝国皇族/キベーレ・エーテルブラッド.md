# フルネーム
キベーレ・エーテルブラッド

# コールサイン

# 本文
先代皇帝の血族、第一皇女殿下

プロメネス帝国先代皇帝の血を引いているため、現皇帝から疎まれ最前線へと送られた。
態度のせいで高慢に思われるが、実際は誰よりも仲間思い。
天使部隊全員の顔と名前を記憶しており、人望が厚い。

「皇帝陛下からの陣中見舞いです。
ぜひとも皇女殿下に 召し上がって頂くよう、言付かっております」
