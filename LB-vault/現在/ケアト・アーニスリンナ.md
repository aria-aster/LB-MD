# コールサイン

# 本文
歴史ある小国、アーニスリンナ大公国の王族。
メルニッツ少尉（おそらくイケメン）にベタ惚れしてしまった結果
議会で王家は追放された。

土いじりが得意で艦内でも植物の世話をしている。彼女の淹れるハーブティーは絶品。

（花嫁Ver）
過去に国を失ったこともあり、結婚にポジティブなイメージを持っていないが、ウェディングドレスはカワイイので好き。今年の4月もまだ表に出ていないだけで、やらかしたらしい。分厚い結婚情報誌を真っぷたつに引き裂くことができる。

「いいですか、 ケアト。どうしても耐えられないことがあったとき、この林檎をかじるのですよ」
私が大公位を継ぐ時、母はそう言いました。
