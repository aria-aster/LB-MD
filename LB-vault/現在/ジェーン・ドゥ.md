# フルネーム
ジェーン・ドゥ

# 別名
[[sky/book/arms/標：ナイトホーク]]

# 本文
家族から見捨てられた少女。引っ込み思案だが、誰かの役に立ちたいと切に願っている。
読書と夜の散歩が趣味。読書友達に憧れており、本好きの天使たちに話しかける機会をうかがっている。

私はひとりきりで手の中のものを見つめる。 輝く虹色の林檎だ。
「これは"慈悲”です」
そう言った運転手の声が耳から離れない。
