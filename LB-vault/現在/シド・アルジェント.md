# フルネーム
シド・アルジェント

# 別名
[[sky/book/arms/標：ロードオブウォー]]

# 本文
旅芸人の一座にいたギャル。
明るく好奇心旺盛で、おしゃれやかわいいものが大好き。
知らないことでも何でも知ろうとする勉強家でもあり、
空いた時間に他の天使たちから勉強を教わっている。

かすんだ視界の先に虹色の林檎を見つけた。いかにも体に悪そうな色だけど、
今さらどうなっても構わない。あーしはその林檎を拾って食った。
