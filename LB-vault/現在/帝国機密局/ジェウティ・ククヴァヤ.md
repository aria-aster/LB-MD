# フルネーム

# 本文
帝都機密局機密書庫司書

帝国機密局で禁断の知識を収集、管理していた。
落ち着いた女性を気取っているが、テンパりやすい。
視力が悪いが、見た目を気にして眼鏡をしていないので、しょっちゅう何かにぶつかっている。

帝国機密局職員という立場を利用し、 グレゴールの林檎を手に入れた。
