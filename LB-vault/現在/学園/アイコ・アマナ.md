# フルネーム
アイコ・アマナ

# コールサイン
[[sky/book/arms/標：アイコノクラスト]]

# 本文
友だち想いの頑張り屋。幼い頃からヒーローを目指していたが、
決めポーズの練習に明け暮れるなど、努力の方向性を間違っていた。
天使としては半人前だが、胸にたぎる正義の心は本物。
