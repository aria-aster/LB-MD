# フルネーム
イサカ・ハイライン

# コールサイン
[[sky/book/arms/標：ウェポンマスター]]

# 本文
旅商人をしながら、オーパーツで一攫千金を狙っていた。
儲けることが大好きだが、義理人情に厚く、困っている人にはつい安売りをしてしまう。
仲間が傷つくことを恐れており、いざという時のために、応急処置の勉強をしている。

ウィルが荷物から取り出したのは、ひとつの果実だった。
瓦礫に似合わぬ輝きを放つ、 林檎だった。
