# 登場人物

- バージル、スタン、ローランド（エラン）、オーガスト、ヨシュア、ヘルミナ、キャシー。
- 店を壊された偽占い師、ヨシュアの手下たち、顔を血まみれにされた男、スタンの両親、スタンの伯爵家の祖父、スタンの遺産を狙う者たち、船の乗員。
- 禁忌咒法で死んだローランドの「弟」と、その死体から生まれた同じ顔のホムンクルス（バージル）。

# 登場組織、地名等

- デーモンハンターギルド、デーモン狩り組織、旧伯爵家とその関係者。
- 疲れた街、偽占い師の店、ヨシュアの屋敷、旧伯爵家の邸宅、法学校、荒野を横断するフリーウェイ、港町ノースハーバー、埠頭、ヨシュアが船主の船と一等船室、脱出用ボート。
- デーモン、ホムンクルス、禁忌咒法に使われたオーパーツ、白い粘液状の生命、荒野に降った色とりどりのカエル。

# 本文

- デーモンハンターのバージルは、少年スタンを商品として扱うギルドを裏切る。船上でデーモン化したヨシュアらと戦いスタンを救うが、致命傷を負って白い粘液となり消える。
- **神獣の登場：** 明記なし。デーモン、ホムンクルス、白い粘液状の生命が登場する。
- **推測される元ネタ：** 「レオン」など、最後の仕事で子供を守り組織を裏切る犯罪映画の型。
