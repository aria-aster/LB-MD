# 登場人物

- アビー、兄カイン、メイベル、人狼狩りの女猟師シルヴィ、女神ハスタール。
- アビーの父、母、祖母、カインが密かに会っていた少女、孤児院の男性職員と子供たち・職員、アビーが食事にした男たち、監視に利用された浮浪者、古書店の主人・関係者。
- 父母と教会にいた人狼の仲間、各地に散った同族の人狼たち。

# 登場組織、地名等

- アビーたち人狼の家族、女神ハスタールの信仰、人狼狩り。
- 田舎の小さな街、隣町の教会、逃亡後の路地裏、孤児院、周辺で一番大きな都市、古書店、カインの名を使った「兄の部屋」、シルヴィとメイベルの部屋、各地の街、保養地の森とコテージ。
- 女神ハスタールのシンボル、「正しい食事」、ヒトから人狼の姿へ戻る父親。

# 本文

- 人を喰わなければ理性を失うアビーは、非常食として連れたメイベルを実の娘のように愛する。娘を襲う未来を恐れ、再会した兄カインに撃たれる道を選ぶ。
- **神獣の登場：** 明記なし。人狼の一族と女神ハスタールの信仰が登場する。
- **推測される元ネタ：** 「赤ずきん」。狼を母、少女を娘として役割を反転している。
