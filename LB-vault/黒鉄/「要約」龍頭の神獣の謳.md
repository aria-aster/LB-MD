# 登場人物

- 兄ジェラルド（赤龍会の構成員、後の龍頭／赤龍）、弟ニール、オディール、アイシア。
- 派手なスーツの赤龍会構成員、ニールを拘束する赤龍会の男たち、赤龍会の構成員、夜警公社の職員と装甲歩兵たち、夢煙街の住民、ニールのアイス店の客・情報提供者。
- 作中絵本「DRAGONSLAYER」の主人公オフィーリアと古龍（物語・言及）。

# 登場組織、地名等

- シティ、夢煙街、赤龍会の事務所、ニールのアイス店、シティ外れ、精肉加工工場／赤龍会のアジト。
- 赤龍会、夜警公社（表向きは警備会社、実態は対デーモン実働部隊）、夜警公社の装甲歩兵部隊。
- 龍頭（ドラゴンヘッド）、血のデーモン、龍頭の血、赤龍、七つの王国時代を描く絵本「DRAGONSLAYER」。

# 本文

- ニールは失踪した兄ジェラルドを追い、赤龍会の龍頭となった赤龍が兄だと知る。組織の血の支配から逃れられない兄の願いを受け、自ら引き金を引いて守る強さを継ぐ。
- **神獣の登場：** 言及のみ。過去の神獣は語られるが、中心となる赤龍は神獣と明記されない。
- **推測される元ネタ：** 香港ノワール・ヤクザ映画と、作中絵本 `DRAGONSLAYER` による竜殺しの再演。
