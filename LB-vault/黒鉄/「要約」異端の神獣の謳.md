# 登場人物

- イェニー・プレスタイン、アイシア、オデット（巨大化後はオディール）、メイヘム・メイソン、死人王。
- 病院でイェニーを制止する聖堂教会の修道女、病院の受付・警備員、カルト教団の信者たち、夜警公社の装甲歩兵たち、保護施設の関係者、シティの住民。

# 登場組織、地名等

- シティ、病院、オデットとアイシアが育った保護施設、イェニーの屋敷と美術品コレクション、カルト教団の倉庫アジト、シティを包む堤防。
- 聖堂教会（カテドラル）、破壊神を崇めるカルト教団、夜警公社。
- デーモン、破壊神メガデス、大失楽（グラン・フォール）。

# 本文

- 大失楽（グラン・フォール）後のシティで、探偵イェニーは失踪したオデットを捜し、彼女が破壊神メガデスに結びつくデーモンだと知る。オデットは巨大化して水没寸前のシティを救い、アイシアと和解する。
- **神獣の登場：** 明記なし。巨大化するデーモンと破壊神メガデスが中心。
- **推測される元ネタ：** 「白鳥の湖」「フランケンシュタイン」、怪獣映画の反転。
