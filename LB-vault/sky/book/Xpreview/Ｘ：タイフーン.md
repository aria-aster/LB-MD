# 我はモンドル
## Page 1-1
[フィルター：青]
「ほあっ！ あちょー！」
深い竹林の中、手刀で竹を真っ二つに割り、
土から立派なタケノコを引き抜く。
「ふむ。これは美味そうだ。今夜はタケノコラーメンだな」
私の名はホン・ロンラン。武術を極めたドルイド。
## Page 1-2
[フィルター：青]
答えをみつけるため、
私とは、何か。
何をすべきなのか。
方々を旅して賢人と会って議論を重ねた。
書の国を訪れ、何年もかけて
ものごころついた時から、
膨大な書物を読み込んだ。
ずっとそんなことを考え、生きてきた。
それでも、何も分からなかった。
## Page 1-3
[フィルター：青]
真理は人の中にあらず。
野山は人の暮らす場所ではない。
タフでなければ生きていけない。
私は自然の中にこそ真理がある
と考えた。
自然と調和し、一体になる修行を始めた。そんな私を、人々はドルイドと呼んだ。
深山幽谷にこもり鍛錬を続け、
ならず者たちをしばき続けた結果、
武術を極めてしまった。
そんな私を人々は武術家（モンク）と呼んだ。
## Page 1-4
[フィルター：青]
モンクなのか？ ドルイドなのか？
あるいはモンドルなのか？
どれも私であり、私ではない。
森に生き、真理と極上のラーメンスープを
追い求める日々だ。
タケノコラーメンをすすっていると、
風に混じり、焦げた匂いが漂ってきた。
## Page 1-5
[フィルター：青]
「この匂い……」
私の調理が失敗したためではない。
無惨に燃えた森。えぐり取られた地面。人々の痛ましい姿。
ラーメンを食べ終えた私は山を駆けた。
神獣の仕業だ。
## Page 1-6
[フィルター：青]
すべての事象は、
あるがままにあるべきだ。
だが、神獣は自然界の理屈を超越した、
ありうべからざる存在である。
真理にたどりつく前に、
自然がブッ壊されてはたまらない。
だが、私の武術は
神獣に通用しなかった。
## Page 1-7
[フィルター：青]
私は、私の限界を知っている。
己の力のみで自然を守り切れないならば、
超常（トンデモ）パワーに頼る他ない。
とある秘宝の噂を聞いた。
何でも願いを
叶えてくれるオーブが、
迷宮の奥に隠されているらしい。
私は心に従い旅に出ることにした。
秘宝を手に入れ、
「神獣から自然を守りたまえ」と願うのだ。
