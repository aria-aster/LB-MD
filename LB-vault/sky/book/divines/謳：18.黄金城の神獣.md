# Chapter 1
[フィルター：青]
幸福の章
## Page 1-1
[フィルター：青]
これはまだ、
人の願いが叶っていた頃のお話です。
## Page 1-2
[フィルター：青]
あるところに黄金の国がありました。どこよりも美しく、どこよりも豊かで、
建物はどこもかしこも金でできていました。
水は澄み、風かぐわしく、花咲き誇る。
自然と調和した、持続可能（サステナブル）な国です。
## Page 1-3
[フィルター：青]
黄金の国を治める黄金王は、
賢く公平でした。
国には飢える者も、凍える者もおらず、
人々は笑みを絶やさずに暮らしていました。
永遠の幸せが約束された黄金の国で、
たったひとりだけ、
幸せではない女の子がいました。
## Page 1-4
[フィルター：青]
不幸な女の子はエディナ姫といいました。黄金王の一粒種の娘です。
エディナ姫は物心がついてから
一度も笑ったことがありません。
姫は清潔で柔らかいベッドに縛り付けられ、誰とも言葉を交わさずに、一日中、しくしくと泣き続けていました。
縛っておかないとエディナ姫は
自分で自分を殺してしまうのです。
## Page 1-5
[フィルター：青]
王はエディナ姫が可哀想でなりませんでした。
エディナ姫の笑顔が見られるのなら国と引き換えにしたって構いません。
王は、エディナ姫を笑わせた者をその夫とし、黄金の国を譲ると
お触れを出しました。
## Page 1-6
[フィルター：青]
国中から大勢が集まり
姫を笑わせようとしましたが、
どんな冗談も音楽も、物語も、
ご馳走やお菓子でも、
姫を笑わせることはできませんでした。
人の力では、
エディナ姫を幸せにできぬのか。
王は落胆しました。
## Page 1-7
[フィルター：青]
女神ならば
ある時、黄金王は
「白の女神」の伝説を耳にしました。この世が生まれた時から存在するという
古の神殿には「白の女神」がいて、
心からの願いであれば
なんでも叶えてくれると言うのです。
エディナ姫を幸福にできるかもしれません。
黄金王は屈強な家来たちを連れて、
女神の神殿を目指しました。
七つの川と七つの山をこえ、七つの季節が
過ぎた後、ついに黄金王は女神の神殿に
たどりつきました。
## Page 1-8
[フィルター：青]
「白の女神さま。
どうか我が娘エディナを幸福にしてください……」
黄金王は一心に祈ります。
## Page 1-9
[フィルター：青]
すると女神がその姿を現しました。
王の心からの願いが、女神に通じたのです。
女神は言いました。
「エディナにとっての幸福とは
エディナの死である。それを望むか？」
女神の言葉に黄金王は仰天しました。
「女神さま、そんな事は望みません」
## Page 1-10
[フィルター：青]
「私はエディナに生きて欲しいのです。
娘は、娘にしか分からない何かに
苦しんでいます。
ですが、もっと自分の人生を楽しめるようになって欲しい。
エディナには普通の娘になって欲しい。
私はただ、娘の笑い声を聞きたいだけ
なのです」
涙ながらに訴える王に
女神は告げました。
「王よ、そなたが望んでいるのは
エディナの幸福ではない。
そなた自身の幸福だ」
## Page 1-11
[フィルター：青]
王は目を見開き、深く恥じ入りました。
「おっしゃるとおりです。
私は娘にとっての幸福が何か
考えた事も無かった……」
「私が叶えられる願いは、
心からの願いをひとつだけだ。
さあ、願え」
王は心の底からエディナの事を想い、
「どうか、エディナに生きる力を
与えてください」
そう願いました。
女神は目を閉じ……やがて告げました。
「王よ、そなたの願いは叶ったぞ」
## Page 1-12
[フィルター：青]
これで、エディナは幸福になれる。
黄金の国から不幸な者がいなくなる。
王は女神に深く感謝しました。
王と家来は七つの季節をかけて
七つの山と七つの川をこえ、
懐かしき故郷、黄金の国へ帰り着きました。
王は久しぶりの故郷を見て愕然としました。
美しい黄金の国は、見るも無惨に
荒れ果てていたからです。
## Page 1-13
[フィルター：青]
エディナ姫の苦しみには、
理由がありませんでした。
誰からもたっぷりの愛情を注がれ、欲しいものは何でも手に入ります。
それなのに、存在しているだけで、
己の内から姫を責め苛（さいな）む言葉が
浮かび上がり、
耐えがたい苦痛に襲われるのです。
姫にとって、姫を害する最大の敵は自分自身でした。
苦痛から逃れるためには
自分を滅ぼすしかありません。
## Page 1-14
[フィルター：青]
黄金王が古の神殿に向けて
旅立った後のことです。
見守る侍女の隙を突いて、
エディナ姫は部屋を抜けだし、
黄金の尖塔から身を投げました。
石畳に叩きつけられるまでの短い間
姫は幸せでした。
ようやく苦しみから
解放されると思ったのです。
## Page 1-15
[フィルター：青]
激痛と共に、
しかし、エディナ姫に
安息が訪れることはありませんでした。
砕け散った骨と引き裂かれた肉が寄り集まり
身体が形作られていきます。
再生した姫の身体は、
元よりも大きく強く強靭でした。
## Page 1-16
[フィルター：青]
エディナ姫は、
白の女神から生きる力――
「無限の生命」を授かっていたのです。
毒を飲んでも、首を絞めても、
姫は生きていました。
身体は取り込んだ毒の粘膜に覆われ、
呼吸を補うため、
口だけの首が新たに生えてきました。
## Page 1-17
[フィルター：青]
エディナ姫は、人の姿ではなくなりました。
死ぬこともできず、理由の無い恐怖と苦痛に
怯えながらただ生きるだけの存在、
「怪物」となりました。
## Page 1-18
[フィルター：青]
黄金の麦が実る畑は荒れ果て、
建物を覆っていた黄金は剥ぎとられました。
人々の瞳はどんよりと濁り、
幸福な人はどこにもいません。
黄金王は崩れた黄金城の跡地で
嘆き悲しみました。
愛する娘を、全ての民を
幸福にしたかっただけなのに。
その願いが姫を怪物にして、
怪物が黄金の国を滅ぼしたのですが、
黄金王は最期まで理解できませんでした。

# Chapter 2
[フィルター：青]
守護の章
## Page 2-1
[フィルター：青]
これもまだ、
人々の願いが叶っていた時代のお話です。
## Page 2-2
[フィルター：青]
どんな騎士も、力自慢も、知恵者も
黄金の国を滅ぼした「怪物」を
退治することはできませんでした。
「怪物」に怯える人々は、街を城壁で囲って、
その中で息をひそめて暮らしていました。
城壁の街では「怪物」を鎮めるために、
年に一度生け贄を捧げるようになりました。
## Page 2-3
[フィルター：青]
この年、生け贄に選ばれたのはアイーダという若い娘でした。
美しい声を持つアイーダは皆に優しく善良だったので、人々は嘆き悲しみました。
ですが誰からも愛される者でなければ、誰にも愛されない怪物を鎮めることは
できないのです。
## Page 2-4
[フィルター：青]
アイーダには七つの屋敷と七人の召使いを与えられ、
七種の果実酒が、毎食ふるまわれました。
全ての労働が免除され、
生け贄になるのを待つ一年間、
王様のような暮らしを送ることが出来ます。
でも、アイーダは
少しも嬉しくありませんでした。
## Page 2-5
[フィルター：青]
アイーダにはゼノンという
将来を誓った男性がいました。
ゼノンは月の無い夜に
アイーダを外へ連れ出し、
一緒に逃げようと誘いました。
しかし、アイーダは首を縦に振りません。
ここで逃げれば、親兄弟や
大勢の人に迷惑がかかりますし、
他の娘が生け贄に選ばれる。
自分のせいで誰かが死ぬことになるからです。
## Page 2-6
[フィルター：青]
アイーダにはひとつだけ
ささやかな願いがありました。
生け贄になるまでの日々をゼノンと一緒に過ごしたい。それだけで十分に幸せなのです。
しかし、ゼノンは旅立ちを決意しました。
どんな願いも叶えてくれる
「白の女神」の伝説を聞いたからです。
美しく強く若いゼノンには、
愛する者の死を黙って受け容れることなど
できなかったのです。
## Page 2-7
[フィルター：青]
ゼノンは七つの廃城と、
七つの干上がった川を越え、
誰も訪れることのなくなった古い神殿へと
たどり着きました。
「白の女神さま。
どうか我が願いを叶え、愛するアイーダを
お救いください……」
ゼノンは一心に祈ります。
すると女神がその姿を現しました。
ゼノンの心からの願いが、女神に通じたのです。
## Page 2-8
[フィルター：青]
「若者よ、心からの願いをひとつだけ叶えよう」
女神は言いました。
「怪物を消し去ってください。
そうすれば誰も生け贄にならずにすみます」
そうゼノンは願いました。
## Page 2-9
[フィルター：青]
「それは叶えられぬ」と
女神は言いました。
「怪物は、我が願いによって生まれた。
願いを取り消すことはできない」
ゼノンは驚きました。あの恐ろしい怪物が女神の力で生まれたとは
思わなかったからです。
「なぜ、女神さまは怪物を……」
ゼノンの言葉を女神が遮って言います。
「それを知るのが願いか？」
ゼノンは首を振り
「怪物を殺す力」を願いました。
「叶えられぬ。怪物は神の力を持った
「神獣」であるが故に。
人に神は殺せぬ」
「では……」と、
ゼノンは知恵を巡らせます。
## Page 2-10
[フィルター：青]
「私が叶えられる願いは、
心からの願いをひとつだけだ。
さあ、願え」
「愛するものを守る力をください」
ゼノンは心の底からアイーダの事を想い、
そう願いました。
女神は目を閉じ……やがて告げました。
「そなたの願いを叶えたぞ」
## Page 2-11
[フィルター：青]
七つの干上がった川と、七つの廃城をこえて、
ゼノンが城壁の街に帰ってきたのは、
ちょうど一年後。
間に合った、とゼノンは安堵しました。
大急ぎでアイーダのもとへ向かいます。
アイーダが生け贄に捧げられる日でした。
## Page 2-12
[フィルター：青]
アイーダは丘の上で
鎖につながれていました。
「なぜ私を見捨てたの」
痩せ細り、目だけがぎらぎらと輝く不気味な顔で
アイーダはゼノンをなじります。
「アイーダ、君を守るためなんだ。
僕は君を守る力を手に入れた」
ゼノンがそう説明しても、
アイーダは聞く耳持たずにゼノンをなじり続けます。
## Page 2-13
[フィルター：青]
アイーダは変わり果てた姿に
なっていました。
叫び、呻き続けたせいか
美しかった声はしわがれ、
優しさなど欠片も残っていない様子で、
ゼノンを、街を、世界を呪う言葉を
吐き続けました。
それでも、ゼノンはアイーダを
守る決意をしました。
怪物を退ければ、もとのアイーダに
戻ってくれるはずだ。
そう信じていました。
## Page 2-14
[フィルター：青]
やがて、怪物がその姿をあらわしました。
巨体をゆすりゆっくりと近づいてきます。
その恐ろしい姿にアイーダは絶叫し気を失いましたが、
ゼノンはかろうじて踏みとどまりました。
「アイーダは渡さない！
僕がアイーダを守る！」
怪物はゼノンとアイーダの前で歩みを止めると、無数にある目でゼノンを睨め付けます。
## Page 2-15
[フィルター：青]
怪物はそれ以上、ゼノンとアイーダに
近づこうとしませんでした。
日が昇り、沈んでも、
いいえ、女神の加護により
近づくことができないのです。
怪物はじっとゼノンとアイーダを
睨み続けたままです。
ゼノンはアイーダを怪物から護り続けます。
## Page 2-16
[フィルター：青]
また日が昇り、沈むと、
ゼノンはアイーダの悲鳴を聞きました。
いつの間にか眠りに落ちていたようです。
その隙に怪物はアイーダの
すぐそばに迫っていました。
ゼノンが目覚めると、
怪物は静かに離れていきました。
アイーダは怪物など
目に入らないかのようにゼノンを罵倒します。
半狂乱で泣き叫ぶアイーダを見て、
ゼノンの胸の内に
侮蔑の感情が浮かんできました。
アイーダは一方的な決めつけでゼノンの振る舞いをなじりました。
他の男と比較し、過去の美しい想い出さえ、
アイーダの中では
ゼノンに傷つけられた記憶
へと変わっていきます。
## Page 2-17
[フィルター：青]
怪物はゼノンを傷つけることができませんが、アイーダの言葉はゼノンの心を傷つけました。
「もういい！　たくさんだ！」
そう叫んだ途端。
あっさりと怪物がアイーダを呑み込みました。
どうして……。
女神の力が消えたのか？
ならば自分もここで喰われるのだろうか。
## Page 2-18
[フィルター：青]
怪物はゼノンのことなど気にも止めず
よろよろと動き始めました。
この場から去ろうというのです。
「女神よなぜ！
願いの力を取り上げるのです！」
ゼノンは天に向かって訴えます。
しかし、ゼノンは気づいていました。
ゼノンの願いは「愛する者を守る力」。
ゼノンはもう、アイーダを愛していなかったのです。

# Chapter 3
[フィルター：青]
怪物の章
## Page 3-1
[フィルター：青]
人々が願いを叶えることを
恐れ始めた時代のお話です。
## Page 3-2
[フィルター：青]
怪物を退けたゼノンを、
人々は英雄と讃えました。
愛する者のために戦い、
愛する者を奪われ、
それでも戦い抜いた英雄だと言うのです。
皆は誤解していました。
ゼノンが愛する者を失ったのは
怪物に出し抜かれたからだと。
ゼノンは自分を持てはやす人々とは
距離を置きました。
自分が英雄ではないことを
よく知っていたからです。
## Page 3-3
[フィルター：青]
白の女神から
「愛するものを守る力」を得ておきながら、
アイーダを愛し続けていれば
彼女を救えました。
そして、アイーダを救うことができませんでした。
ゼノンの自責の念を、
人々は謙虚さだと受け取りました。
そして慎み深い英雄として
ゼノンの名声は高まっていったのです。
## Page 3-4
[フィルター：青]
ゼノンの持つ「女神の力」が
怪物を退けたという噂は広く知れ渡り
ゼノンのもとに求婚者が押し寄せました。
ゼノンに愛して貰えれば、
怪物を恐れずにすみます。
## Page 3-5
[フィルター：青]
ゼノンは、その内のひとりを妻としましたが、妻は怪物に食べられてしまいました。
次の妻も、その次の妻も怪物の餌食となります。
女神の力など無いではないか。
人々は怒り狂いました。
ゼノンを嘘つきだと責め立て、
女神の力を謀（たばか）った罪で追放しました。
## Page 3-6
[フィルター：青]
ゼノンは、妻を守れない理由が
分かっていました。
ゼノンは最早、
誰も愛せなくなっていたのです。
誰も愛せない者は、誰も守れません。
世間から愛想をつかされたゼノンは人のいない場所を求めて
歩き続けました。
獣の血をすすり、木の根をかじり
七つの谷と、七つの沼をこえてひたすら遠くへ歩き続けました。
## Page 3-7
[フィルター：青]
七度の冬を耐え抜いた頃、
ゼノンは良いことを思いつきました。
いっそ怪物に喰われて死のう。
七つの沼と七つの谷をこえ、ゼノンは人々の生きる土地へ
帰ってきました。
それが自分の最期には相応しいだろうとゼノンには思えたのです。
## Page 3-8
[フィルター：青]
怪物はますます強く、大きく、恐ろしくなり、
人々が食い尽くされるのは時間の問題でした。
## Page 3-9
[フィルター：青]
ゼノンは探し求めていた怪物を
見つけると、その前に身体を投げ出します。
さあ、僕を殺せ！
なるべく無惨に殺してくれ！
それが僕の贖罪だ！
怪物は叫び声をあげ、
ゼノンに這い寄ります。
しかし、怪物は
ゼノンに触れようとしませんでした。
## Page 3-10
[フィルター：青]
怪物にすら見捨てられたのか、
ゼノンは自嘲すると、
自らの首をナイフで掻き切りました。鮮血が吹きだし、気が遠くなります。
しかし瞬く間に傷は塞がり、
意識もはっきりとしてきました。
何度自分を傷つけても
傷口は塞がってしまいます。
そうか、と
ようやくゼノンは理解しました。
ゼノンが愛していたのは自分自身。
女神から得た「愛するものを守る力」により
ゼノンは怪物から守られていたのです。
## Page 3-11
[フィルター：青]
アイーダと妻たち。
ゼノンの自己愛により、
大勢を不幸にしてきたにも関わらず
死ぬことすらできなくなっていました。
ゼノンはたったひとつの拠り所となった
自分を愛さずにはいられないのです。
そんなゼノンを
怪物の無数の目がみつめます。
その瞳に、ゼノンは
深い絶望を感じ取りました。
怪物よ、お前もか。
## Page 3-12
[フィルター：青]
自己愛ゆえに死ねないゼノンの絶望を、父の愛ゆえに死ねない怪物だけは
理解していました。
怪物とゼノンは
同じ悲しみを知っていました。
「怪物よ、話を聞かせてくれないか。
いや、まずは名前を教えて欲しい。」
ゼノンがたずねると、
怪物はエディナと名乗りました。
ゼノンとエディナは長い時間をかけて、
たくさんの話をしました。
## Page 3-13
[フィルター：青]
黄金王が、小さな姫の
「本当の望み」を聞いていれば
ゼノンが恋人であるアイーダの言葉に
耳を傾けていれば
この願いを他者に押しつけていなければ
何か違ったのかも知れませんし、
何も変わらなかったのかも知れません。
同じ苦しみをかかえた怪物とゼノン。
ふたりの話は尽きることがなく、
ずっと一緒にくらしました。
めでたしめでたし。
