# Chapter 1
[フィルター：青]
兄弟の血
## Page 1-1
[フィルター：青]
「シティ」 はすべてを受け容れる街だ。
どんな人種も、どんな過去を持つ者も、
人ならぬ者でさえも。
## Page 1-2
[フィルター：青]
俺は、歳の離れた弟のニールとふたりで
シティにやってきた。
身寄りはない。みんな神獣に殺された。
「シティ」 には可能性がある。
何も持たない、俺たちみたいな連中が、
底から這い上がり、成功するという夢が。
俺はニールとふたり、この街で幸せをつかむ――はずだった。
## Page 1-3
[フィルター：青]
「悪い話じゃないと思うんだがねぇ。
ジェラルドさん」
煙草の煙がたちこめる事務所の片隅で、
派手なスーツを着た男が俺の名前を呼んだ。
袖口から、赤い龍の刺青が覗く。
悪名高い赤龍会の一員だ。
「ジェラルドさんは顔が利く。そのツテで、
うちの商品を流してほしいんだ。
これだけ出すぜ」
男が指で示した金額はかなりのものだった。
## Page 1-4
[フィルター：青]
「そっかー。
問題は赤龍会の商品が「人間」ということだ。人身売買から臓器まで、
こいつらは平気で人間を売りさばく。
でもよ、これを見れば、気が変わるかもな」
男が立ち上がり、事務所の奥の扉を開けた。
「俺にはできない」
「ニール……」
これまでキレイな商売だけをしてきたとは
言わないが、俺にも良心はある。
そこに弟がいた。椅子に縛りつけられ、猿ぐつわを噛まされている。
両脇を赤龍会の男たちが囲んでいた。
## Page 1-5
[フィルター：青]
「あんたが断れば、 赤龍会は大損だ。
損失は弟クンの身体で、
払ってもらうことになるけど？」
派手スーツの言うことは滅茶苦茶だ。
ニールが不安そうな目で俺を見つめる。
俺は覚悟を決めた。
「分かった。手を組もう。俺のツテで
あんたたちの商品を売る。 だから弟を放せ」
## Page 1-6
[フィルター：青]
「もうひとつ。赤龍会とビジネスを
始めるには、出資金を出してもらうことに
なってるんだよな〜」
こいつは出資金の意味も知らないだろう。 難癖をつけて、カネをたかりたいだけ。
俺に借金を背負わせて、骨までしゃぶる
つもりだ。
## Page 1-7
[フィルター：青]
「嫌なら、弟さんの肝臓でもいいぜ?」
派手スーツがへらへら笑いながら、弟の脇腹をつつく。
「分かった。払う。払えばいいんだろ。
だが弟はもう無関係だ。解放してくれ」
## Page 1-8
[フィルター：青]
ニールはようやく、拘束を解かれた。
「兄さん……」
ニールは震えている。 当然だ。
「大丈夫だニール。
心配するな。俺がなんとかする」
俺の言葉に、ニールはようやく安堵の
表情を見せた。
俺はニールを連れて通りに出ると、
タクシーを呼び、ニールを車内に
押し込んだ。
車が走り去るのを見届けてから、赤龍会の事務所に戻り「商談」を再開する。
「出資金は、肝臓ひとつ分だったか？」
「ああ」
## Page 1-9
[フィルター：青]
俺はジャケットの下に隠し持っていた
拳銃を抜き、派手スーツ野郎の心臓に
銃弾を撃ち込んだ。
ニヤけた表情のまま、派手スーツが倒れる。
「こいつの肝臓で支払うぜ。
ほら、さっさと持っていけよ」
徹底的に戦う。それが俺の覚悟だ。
赤龍会の男たちは、目をまるくして、
倒れた派手スーツを見つめている。弱者を傷つけることには慣れているが
やられることには慣れていない。
## Page 1-10
[フィルター：青]
連中が銃を抜き、俺に向けるまでに、
俺はもうひとりを撃ち殺していた。
さらにひとり。
事務所にいた連中を全て撃ち殺すと、背後で何かが動く気配がした。
胸に大穴の空いた派手スーツが、
ゆっくりと立ち上がる。
「不意打ちとは汚い手を使うじゃねえか」
## Page 1-11
[フィルター：青]
赤龍会に、龍の血を得てデーモンに
なった連中が紛れてるという噂は
本当だったようだ。
一度脅しに屈せば、死ぬまで言いなりだ。
俺の次はニールを脅すだろう。
だが、そんなことでひるむ俺じゃない。
弟を守るため、デーモンだろうが何だろうが
ここでこいつを殺すしかない。
## Page 1-12
[フィルター：青]
派手スーツのデーモンに
銃弾を浴びせながら、俺は祈った。
ニールの人生に幸多からんことを。
俺はどうなっても構わない。
神様だろうが破壊神だろうが何でもいい。
ニールを、お守りください。

# Chapter 2
[フィルター：青]
血の決意
## Page 2-1
[フィルター：青]
ジェラルド兄さんは
帰ってこなかった。
兄さんが床下に隠していた箱を取り出す。「もしもの事があった時に開けろ」と言われていたものだ。
箱の中身は拳銃と札束、 そして手紙。
手紙には「夢煙街（むえんがい）でオディールを訪ねろ」と、書かれていた。
## Page 2-2
[フィルター：青]
夢煙街は、巨大な掃きだめだ。
シティを追われた者や、家を持たない者、
ワケ有りの連中がたむろする。
僕はそこでオディールを探し歩いた。
## Page 2-3
[フィルター：青]
「ニールだな？ 聞いてた通りチビなのだ」
僕より背の低い女が、高い所から僕を見おろして言った。
「あたしがオディールだ」
僕はこれまでのことをかいつまんで話した。ジェラルド兄さんからオディールを訪ねろと
言われたこと、 兄さんは多分、
もう生きてないこと……。
## Page 2-4
[フィルター：青]
「お前の兄貴にはアイスをゴチになった
恩がある。 逃げるなら、
いい運び屋を教えてやるぜ」
「兄さんの仇を取る」
オディールは神妙な顔でそう言った。
「逃げない」
僕はオディールの目を見て言った。
「は?」
ずっと考えていたことを口にした。
理不尽に兄さんを奪った赤龍会を
許してはおけない。
## Page 2-5
[フィルター：青]
「仇討ち？ だるぅー」
オディールは気の抜けた声を出した。
「そーゆー復讐の連鎖に巻き込まれるのは
クソ面倒くさいし、 御免なのだ」
「分かってます。
だから……僕に教えてください。
「教えるとか、ますますめんどくせーのだ。
そいつはアイス100個分なのだ」
オディールが、しっしと手をふる。
「たった100個でいいんですか？」
「は？」
オディールが食いついた。
強くなる方法を。
## Page 2-6
[フィルター：青]
「料理の腕には自信があります。
アイスなら毎日でもつくります」
「マジ？ イチゴ味？」
「チョコ味でも、ソーダ味でも」
「気に入った。弟子にしてやるのだ」
僕はオディールと固い握手を交わした。
「あたしの修行は厳しいぞ。
ビシバシ鍛えてやるから覚悟するのだ！」
## Page 2-7
[フィルター：青]
夢煙街に来てから、3年が過ぎた。身長は伸び、オディールからチビと
言われなくなった。
オディールは気まぐれで、癇癪持ちで、
ドタキャン常習者だったが、ムカつくやつの
ぶっ飛ばし方から始まり、 夢煙街で
生き抜く方法を教えてくれた。
## Page 2-8
[フィルター：青]
兄さんが遺してくれたカネで
小さな商売も始めた。アイスの移動販売だ。
オディールのために毎日つくっていた
アイスが評判になっていた。
商売を始めたのは、
赤龍会の情報を
集める目的もあった。
## Page 2-9
[フィルター：青]
夜警公社の職員を狙って
僕は、アイスの屋台をひろげていた。
夜警公社は、表向きは警備会社だが、
その実態は対デーモン戦の実働部隊だ。
僕の店では、夜警公社の関係者には無料でアイスをサービスしている。
防犯になるし、何より夜警公社の人間の
話が聞けるからだ。
## Page 2-10
[フィルター：青]
もちろん、アイスを食べながら公然と
仕事の機密情報を話す間抜けはいない。
夜警公社の敵――
それでも、人員の稼働状況や、隠語や符牒に紛れて語られる断片的な情報を
デーモンとつながっている
赤龍会の動きも。
つなぎ合わせれば夜警公社の動向が分かる。
## Page 2-11
[フィルター：青]
赤龍会のトップは、龍頭（ドラゴンヘッド）と呼ばれている。
用心深く、正体不明。
幹部以外には姿も見せない。
赤龍会からは裏切り者や内通者が出ない
出るのは死体だけだ。構成員が龍頭に
絶対服従なのは、デーモンの力だと
言われていた。
ならば、龍頭を潰せば、
赤龍会は自壊するはずだ。
僕は夜警公社が大量の弾薬を発注したこと、装甲歩兵部隊を移動させていることを知った。赤龍会への強制処分が近いのだろう。
## Page 2-12
[フィルター：青]
僕とオディールは、シティの外れ、
真夜中の工業地帯にいた。
夜警公社の動きから、 赤龍会のアジト
龍頭がいる場所の見当はついていた。精肉加工の工場だ。
夜警公社より先に龍頭を見つけ復讐する。
僕たちは、真っ暗な工場へ近づいた。
「動くな！」
僕の背後から女性の声が響いた。
## Page 2-13
[フィルター：青]
そこにいたのは夜警公社の強化装甲だった。
僕は両手をあげる。
「アイシアかよ。驚かすな」
オディールが気さくに声をかける。
「オディール？ まったく何を
やってるんですか」
どうやら、強化装甲の女性とオディールは
旧知の仲のようだ。
「赤龍会を潰しにきたんだ」
オディールが胸を張る。
## Page 2-14
[フィルター：青]
「それは我々の任務ですよ」
暗闇の中、ライトを消した車両が
静かに移動しているのが見えた。
夜警公社の車だ。
「邪魔は許しません」
そう言うとアイシアという女性は手早く
オディールと僕を手錠でつないだ。
「何するのだ!?」
オディールの抗議にも
アイシアは耳を貸さない。
「ここから絶対に動かないでください」
そう言うと、アイシアはこの場を立ち去り、夜の闇の中へ消えていった。
## Page 2-15
[フィルター：青]
「先をこされたのだ……」
オディールがつぶやいた。
夜警公社がいるということは、
この工場に龍頭がいる可能性が高い。
「ここであきらめるわけにはいかない」
「だよな」
キン、と音がしてオディールが見た目に
似合わない怪力で手錠を引きちぎった。
「あたしらも乗り込むのだ」

# Chapter 3
[フィルター：青]
赤龍の血
## Page 3-1
[フィルター：青]
深夜の精肉工場。赤龍会のアジトを、静かに夜警公社の装甲歩兵が取り囲む。
「まだ待つのだ」
声をひそめてオディールが言った。分かっている。夜警公社と赤龍会の
戦いに巻き込まれるのは避けたい。
僕の狙いは赤龍会のボス、 龍頭だ。
## Page 3-2
[フィルター：青]
やがて、夜警公社の作戦が始まった。
工場の正面、裏口、屋上から、
同時に装甲歩兵が突入していく。くぐもった銃声が断続的に聞こえる。
工場の中で明かりがついた。
しばらくすると、大きな爆発音が聞こえた。工場の壁が吹き飛ぶ。
## Page 3-3
[フィルター：青]
「行くぞニール。あたしらの出番なのだ！」
オディールと僕は駆け出す。
壁に空いた穴から工場の中に入ると、奥から何か大きなものが
吹っ飛んできた。
装甲歩兵だ。床に叩きつけられて転がり、
そのまま動かなくなる。
## Page 3-4
[フィルター：青]
工場内の明かりを背に、痩せた男が見えた。
装甲歩兵がその男に銃弾を浴びせる。
痩せた男は、銃弾をものともせず装甲歩兵に迫ると、その身体を抱え、頭上に持ち上げた。
人間離れした怪力だ。
## Page 3-5
[フィルター：青]
「アイシア！」
オディールが叫ぶ。
抱え上げられた装甲歩兵はアイシアだった。
オディールが男に突撃する。
痩せた男は、オディールに向かって
アイシアを放り投げた。
オディールは、アイシアを受け止め、
一緒に転がった。オディールも人間離れ
している。

[フィルター：青]
痩せた男が僕に近づいてくる。裸の上半身に赤い龍の刺青。
僕は兄さんの形見の銃を構える。
「えっ……」
男の顔を見て、銃を落としそうになった。
## Page 3-7
[フィルター：青]

男の顔は紛れもなく
兄さんだった。
痩せ細り、見たこともないほど
目をしているが、確かに兄さんだ。
「撃てニール！」
アイシアが叫ぶ。
「そいつが龍頭だ！」
## Page 3-8
[フィルター：青]
兄さんが龍頭!?
「久しぶりだなニール」
優しい声音で龍頭が喋った。
「きっと、見つけてくれると思ったよ」
「兄さん……」
「ニール。俺にできなかったことを
やってほしい。赤龍会を

「ニール。 俺を殺してくれ」
## Page 3-9
[フィルター：青]
銃を持つ手が震える。
「そいつはジェラルドじゃない、龍頭だ！」
オディールが叫ぶ。

スレイヤー。

この世界が七つの王国だった時代、
