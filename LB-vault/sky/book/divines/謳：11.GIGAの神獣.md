# Chapter 1
[フィルター：青]
奇々怪々の章

## Page 1-1
[フィルター：青]
「ぷえっくしゅん！」
「男」は全身がのたうつような
くしゃみと共に目を覚ました。
（ここは……どこだ？）
板張りの天井の隅に、
大きな蜘蛛の巣が張っている。
廃屋だ。
しかし、部屋の設えを見るに、
裕福な身分の主が住まう屋敷だろう。
軋む床には随分と土埃が溜まっていて、
足跡がくっきりと残った。

## Page 1-2
[フィルター：青]
屋敷には人の気配がない。
外で降る雨の気配がじっとりと
忍び込んでくるだけだ。
自分はこの屋敷の者だろうか。
「男」は自分の格好を見下ろした。
上等な着物に、立派な刀。侍の装いだ。
しかし、自分が誰か、なぜここにいるのか、
何ひとつ思い出せない。
「男」は床の間に飾られている
一幅（いっぷく）の掛け軸をしげしげと眺めた。

## Page 1-3
[フィルター：青]
屋敷にある金目の物は盗まれたようだが、
床の間の掛け軸だけは手つかずのまま
残されていた。
枝垂れる柳葉が描かれ、
その下には不自然な余白が空いている。
おそらく、そのせいで
価値ある画だとは思われず、
賊の盗難を免（まぬが）れたのだろう。
それにしても、何とも気になる画だ。

## Page 1-4
[フィルター：青]
屋敷の謎は残っていたものの、
「男」はひとまず屋敷から出ることにした。
自分の正体が分からないことほど
不気味なことはない。
ちょうど降っていた雨は止み、
屋敷の外は清澄な空気に包まれている。
屋敷は高台にあるようで、
眼下に小さな村が見えた。

## Page 1-5
[フィルター：青]
（……無礼者どもめ）
村の通りを行きながら「男」は憤慨した。
村人どもは、遠巻きに「男」を眺めていた。
声をかけると、何も言わず逃げ出していく。
いったい何なのだ。
「男」が苛立ちを露わにしたときだった。
「おい、カエル野郎」
屈強な無頼漢たちが行く手を遮った。

## Page 1-6
[フィルター：青]
カエル野郎とは聞き捨てならない。
武士に対する暴言だ。
この場で手打ちもやむなしと、
「男」はすらりと刀を抜いた。

## Page 1-7
[フィルター：青]
「け、ケロー!?」
刀は、竹光であった。
無頼漢たちがどっと笑い声をあげる。
「男」は竹の刀を投げ捨て身を翻す。
しかし、すぐに足がもつれて転んだ。
膝をついたすぐそばに水たまりがあった。
そこに映る己の顔を見て、
「男」は目を見開いた。

## Page 1-8
[フィルター：青]
カエルだ。
人の頭と同じ大きさのカエルの頭が
濁った水面で揺らめいている。
「ッ!?　たまげたケロ！」
「男」はカエルの首を持つカエル侍だった。
「化けガエルめ！」
「ふん捕まえて見世物にしてやる！」
村人たちの声に、
カエル侍は文字通り跳び上がった。

## Page 1-9
[フィルター：青]
カエル侍は逃げ出した。
背中を見せた「化けガエル」に、
村人たちは容赦しなかった。
追われて、追われて、追われて。
逃げて、逃げて、逃げて――
そうして辿り着いたのは、
山奥の鄙（ひな）びた古寺だった。
カエルが逃げ込むと、古寺の和尚は
目を丸くしながらも温かく迎えてくれた。

## Page 1-10
[フィルター：青]
「それはそれは、難儀でしたな」
和尚は、村人が諦めるまで
カエル侍を匿うと申し出てくれたが、
ひとつだけ約束をさせた。
「決して、奥の本堂には入らないように」
和尚の言葉をカエル侍は
「フリだな……」
と、受け取った。
「お邪魔しますケロ……」
その夜、カエル侍は我慢できず
人目を盗んで本堂へと忍び込んだ。
「け、ケロ!?　こ、これは……」

## Page 1-11
[フィルター：青]
屏風があった。大きな屏風だ。
生き生きとした筆致のウサギやカエルが
まるで人間のように相撲をしたり
追いかけっこをしたりしている。
「な、何だケロ……これは……」
カエルは自分の顔をペタペタと触った。
特にこのカエルの画――水たまりで見た、
自分の顔そっくりではないか。
「……いけないと申しましたのに」
和尚の声に、カエル侍は高く跳び上がった。

## Page 1-12
[フィルター：青]
「その屏風画は、画王と呼ばれた
稀代の絵師の描いたものです」
訥々（とつとつ）と、和尚は語る。
画王という絵師は、あまりにも
生き生きとした画を描く故に、
描かれた動物たちが生命を得て
画から抜け出し、動き出すほどだった。
カエル侍は和尚の話をじっと聞いていた。
脳裏に浮かび上がったのは、屋敷に残された
掛け軸だった。空白のある奇妙な掛け軸。
「もしや――あの掛け軸も、画王が？」

## Page 1-13
[フィルター：青]
カエルの話を聞いた和尚は頷いた。
「あちらのお屋敷の掛け軸でしょう？
ええ。屋敷の主の家宝と伺っております」
「その、画王は、今どこに……？」
呆然と尋ねたカエル侍に、和尚は答えた。
「都で隠居していると、風の噂で――」
カエルは居ても立ってもいられずに、
山寺を飛び出した。
（嘘だ、嘘だ、嘘だ――！）
我が身がただの画であるなど、
到底受け入れられなかった。

## Page 1-14
[フィルター：青]
画であるのならば、
胸を打つこの鼓動は何だ？
ぐちゃぐちゃと絡まったこの感情は？
何をもって生きているという。
何を指して命と呼ぶ。
分からない。分からない。
この「自分」は何なのだ！
画王に聞かねばならない。
なぜ、たかが画に、
徒に命を与えたのか――と。

# Chapter 2
[フィルター：青]
有名無実の章

## Page 2-1
[フィルター：青]
「おお！　ここが、都ケロ……」
カエル侍は感涙に咽（むせ）び泣いた。
町の賑わいのただ中に立ち尽くし、
カエルはぎゅっと頭を隠す頭巾を掴んだ。
追いかけられ、化け物と迫害され、
いつしか手放せなくなっていた頭巾だ。
ここに辿り着くまで、
どれだけの艱難辛苦（かんなんしんく）があったことか。
だが、自分をカエル侍として生み出した
画王に物申さねば気が済まない。
その一心で己を奮い立たせここまで来た。

## Page 2-2
[フィルター：青]
画王探しは難航した。
楽隠居でもしていて
すぐに見つかるだろうと思っていたが、
誰も画王の居場所を知らなかったのだ。
「……本当に、こんな場所にいるケロ？」
唯一、手に入った手掛かりを頼りに
やって来たのは貧民街だ。
こんな所にいるわけがない――
そんなカエル侍の思いに反し、
画王はそこにいた。
「……お主が画王かケロ？」

## Page 2-3
[フィルター：青]
画王は、くたびれていた。
髪も髭も、ボサボサと伸び放題で、ブンブンとハエが集っている。
白髪の散る、脂ぎった長い前髪の隙間から、
画王の目がカエル侍をにらんだ。
「何だ、お前は」
「お主に聞きたいことがあるケロ」
カエル侍が頭巾を取り払う。
画王はカエルの頭を見つめ、
やがてクックッと肩を揺らした。

## Page 2-4
[フィルター：青]
画王はフンと笑った。
「わしの描いた画だと？　お前が？
そんな不細工なカエルなぞ描くものか」
「ぶ、不細工とは無礼千万ケロ!!」
「お前を描いたのは「スミエ」だろうよ」
「スミエ？　何者ケロ？」
前髪の奥に瞳が沈む。
「彼女こそが、画の王。
いや……描くことが好きな娘だよ」

## Page 2-5
[フィルター：青]
あの娘は、ある日突然やって来た。
画王のウワサを
どこかから聞きつけたんだろうな。
弟子になりたいと、
それはもう真っ直ぐな目をしていたよ。
弟子を取る気はなかったが、
スミエも強情でな。
諦めさせようと一枚描かせてみたが、
とんでもない物を、あの子は描いた。
あの画は、人間の業（わざ）じゃあない。
すぐに、スミエが人でないと気付いたさ。

## Page 2-6
[フィルター：青]
スミエは鬼だ。気付いたが、黙っていた。
その画に魅せられたんだ。
かつての栄光を取り戻せると思った。
来る日も来る日も、スミエに画を描かせた。
わしはその画を売った。
わしの名で売った。
スミエは文句ひとつ言わなかったさ。
むしろ幸せそうに描き続けたよ。
あの子は功名なんて求めなかった。
名声など、あの子にとっては
何の価値もなかったんだ。

## Page 2-7
[フィルター：青]
あの子の腕は、
ますます上がっていくばかりだった。
ある日のことさ。
スミエの描いた虎が画から逃げ出した。
都は混乱に陥ったよ。誰も捕まえられん。
雨が降ってようやく
虎は溶けて消えた。虎とは言え画だからな。
わしはスミエに言った。
決して、画に目を入れてはならない。
完成させてはならないと――

## Page 2-8
[フィルター：青]
やがて、あの虎の画は誰が描いたのかと
犯人捜しが始まった。
都の貴族への献上品だったのも
問題だった。
画からは鬼の気配を感じると看破され、
わしの描いた画ではない、
鬼を匿っているのかと責められた。
――わしは、あの子を破門して追い出した。
我が身可愛さに、捨てたんだ。

## Page 2-9
[フィルター：青]
「それからは見ての通りさ」
画王は髭に埋もれる口の端を
皮肉に持ち上げた。
「わしにはスミエほどの画は描けなんだ。
弟子の画を自分の画だと偽って
売っていたのだから、落ちぶれて当然だ」
画王は死んだのさ――と、男は自嘲した。

## Page 2-10
[フィルター：青]
「わしが知る限り、
あの子はわしとの約束を守って
画に目を入れることはなかった」
なぜかは分からんが……と、
画王は目を伏せ、小さく首を振った。
「だがお前がこうして
わしに会いに来たということは、
スミエが画に目を入れたんだろう」
「今になって、わしを責める気に
なったのかもしれんな」

## Page 2-11
[フィルター：青]
「――拙者はそうは思わんケロ」
カエルは自分の胸に手を当てた。
なぜ掛け軸のカエルに命を吹き込んだのか。
そう問いたい気持ちに突き動かされて
この都までやって来た。
けれど、よくよく思い返してみれば、
掛け軸の前で目覚めたときには、
誰かに対する負の感情など、
何ひとつ感じていなかったのだ。
「もしや、スミエ殿は」

## Page 2-12
[フィルター：青]
「スミエ殿は、拙者に何か託したくて
目を入れたのでは？」
何を託したかったかは分からない。
だが、言葉にすると、
それが正しいような気がした。
「ハッ。当てつけだろうさ。
あいつが、わしを許すわけがねえんだ」
カエルは、違う、と言いかけてやめた。
うなだれる画王はもう疲れ切っていて、
どんな言葉も聞き入れる余裕など
ないようだったから――
To Be Continued...

# Chapter 3
[フィルター：青]
画竜点睛の章

## Page 3-1
[フィルター：青]
ゴウゴウと強い風が吹いている。
まだ雨こそ降っていないが、外は嵐だ。
台風が近づいていた。
「気ぃ付けろよ。お前は画なんだから、
雨に濡れたら溶けちまうぞ」
「ケロ。まだ降ってないから大丈夫ケロ」
走るように流れていく黒雲を見上げ、
カエルは掘っ立て小屋の中へと
引っ込んだ。
「画王殿、大丈夫ケロ？」
「さあ。屋根くらい飛んじまうかもな」

## Page 3-2
[フィルター：青]
そうではなくて、とカエル侍は首を振った。
心配なのは川のことだ。
竜のように蛇行した川の氾濫だ。
都から遠く離れた治水工事の現場。
ここで画王とカエル侍は働いていた。
台風で増水し、蛇行した川が決壊すれば、
下流の村までもが濁流に呑み込まれてしまう
恐れがあった。
「手は打った。
あとは祈るしかなかろうよ」

## Page 3-3
[フィルター：青]
台風の接近に備え、堤防の設計図に
手を加えたのは画王だ。
これまでは雨が降る度に堤防が切れ、
それを直す工事の最中にも工事の男たちに
被害が出ていたが、画王が図面を引いて以来、
目に見えて被害は減ったのだという。
命の危険が減り、皆は画王に感謝したが、
画王は自分の功績を
頑なに認めようとしなかった。
「別に褒められることなんかしてないさ。
気付けば誰でも、同じことをしたはずだ」
――そう言って。

## Page 3-4
[フィルター：青]
ガタガタと揺れる小屋の戸が唐突に開いた。
暴風と共に入ってきたのは、
堤防を確認してきた仲間だ。
「どうだったケロ？」
「大丈夫だとは思うがね……
それよりも、オレァ見ちまったよ」
「見ちまった？　何をケロ？」
カエル侍が聞けば、男は渋面で頷いた。
「山狩りの侍たちさ。大勢いた。
都から来たんだろうよ。
とうとう、山ん中の
鬼どもを狩るつもりだ」

## Page 3-5
[フィルター：青]
「山狩り……鬼が何か悪さをしたケロ？」
凶悪な鬼のアジトが山にあるとは
聞いていた。だから、山には入るな、とも。
「さあて、分からんね。だが、鬼だ。
退治してくれたほうがこっちは助かる」
腹が減った、と板間に座った男とは逆に、
岩のように黙り込んでいた画王が
立ち上がった。
「堤防を確かめてくる」

## Page 3-6
[フィルター：青]
「画王殿！　どこへ行くケロ!?」
堤防を確かめると言いながら、
画王は川ではなく山へと分け入った。
ゴウゴウと吹き荒（すさ）ぶ風の中、
今にも雨が降り出すのではないかと
カエル侍は気が気ではなかった。
迷いない足取りの画王の背中には、
話しかけるのもはばかられるほど
鬼気迫るものがある。
「画王殿……ここは……？」

## Page 3-7
[フィルター：青]
カエル侍は我が目を疑った。
山中に、小さな里がある。
鬼のアジトがあるという山になぜ……？
その疑問はすぐに晴れた。
「今すぐ里を捨てて逃げろ！」
画王が声を張り上げた。
「山狩りだ！　侍たちが来るぞ!!」
すると民家からぞろぞろと人影が現れた。
鬼だ。ここが鬼のアジトなのだ。
カエルは竹光の柄を握り、身構えた。

## Page 3-8
[フィルター：青]
「逃げろって言ったって、
どこに逃げるってんだ？」
鬼のひとりが不安げに言う。
カエルは続々と現れる鬼の顔ぶれを
見回した。血気盛んな年頃の鬼はわずかで、
子供、老人ばかりの里だった。
（ああ……そうか――）
ここは、ただの里だ。
凶暴な鬼のアジトではない。
人間に追われた鬼たちの隠れ家なのだ。

## Page 3-9
[フィルター：青]
「私たちはここに残ります。
抵抗しなければきっと、お侍さんたちも
分かってくれます。でしょう？」
幼子を腕に抱いた母が言った。
鬼たちは、そうだ、そうに違いないと
頷いて、画王に背を向ける。
「それでも駄目ならば……仕方なかろうて」
杖をついた老人が、
最後によろよろと去って行った。

## Page 3-10
[フィルター：青]
ゴウゴウと吹く強風に身体を揺らしながら、
画王は両手を見下ろした。
「見殺しにするしかないのか……？」

## Page 3-11
[フィルター：青]
「結局わしは何をやっても駄目なんだ」
画王は両手に顔を埋め、うめいた。
「鬼たちを逃がそうとしたのは、
スミエ殿への罪滅ぼしのつもりか？」
びくりと画王の肩が震える。
「ああ、そうだ。鬼たちを救うことが、
わしにできるスミエへの唯一の償（つぐな）いだ。
だが……結局何もできなかった」
「まだ終わってないケロ！」
カエル侍は画王の肩を掴んだ。

## Page 3-12
[フィルター：青]
「お主には画があるケロ！
今こそ、画に命を吹き込むときケロ!!」
「何を言って……わしにはそんな力……」
「できるケロ！
お主はスミエの師匠ケロ！」
「画に命を吹き込むなど、
鬼ならぬ人には無理な話……」
「お主の引いた図面を見たケロ！
意がこもった立派な画だったケロ！
画王殿！　拙者を信じるでござるケロ！」

## Page 3-13
[フィルター：青]
都の侍たちはじっとその里を見つめていた。
吹き付ける風と叩きつける雨に
溺れそうになりながら。
鬼を皆殺しにせよ。
侍たちに下された命令はそれだけだ。
男たちを率いる侍頭が手を上げる。
ピンと張るような緊張と共に、
侍たちは息を詰め、
その手が振り下ろされるのを待った。
そのときだ。

## Page 3-14
[フィルター：青]
目を焼く稲光（いなびかり）と共に、
耳を劈（つんざ）く雷鳴が轟（とどろ）いた。
ゴウゴウと吹き荒れる風はなお強く、
降りしきる雨はなお激しく、
侍たちは導かれるように天を仰いだ。
「な、何だあれは!?」
誰かが叫ぶ。ヒィ、と情けない悲鳴が
方々から上がった。

## Page 3-15
[フィルター：青]
竜だ。
巨大な竜が、首をもたげ唸り声をあげて
侍たちを睨（ね）めつけていた。

## Page 3-16
[フィルター：青]
「さあ、さあ、画王殿！
最後の仕上げケロ。この水路に
命を吹き込むケロ!!」
強風ふきすさぶ中、カエル侍は画王を伴い、
堤防沿いの川から水を引き込む水路の
入り口に立っていた。

## Page 3-17
[フィルター：青]
カエル侍は、治水工事の図面に竜を見た。
カエル侍や男たちが土を盛り、
画王の流麗な線で描かれた水路は、
まさしく天へ昇る竜のごとき迫力だった。
水をせき止め、堤を築き上げたことで、
今や、図面の竜は大地に描かれた
巨大な竜となっている。

## Page 3-18
[フィルター：青]
「画王殿！」
「――っ、ええい、ままよ!!!」
画王は筆の代わりに荷運びの天秤棒を掴み、
大地に竜の目を描き入れた。

## Page 3-19
[フィルター：青]
「竜だ！　逃げろ！　逃げろーッ！」
侍たちは突然現れた竜に恐れを成して、
這々（ほうほう）の体で逃げていく。
「本当にできた……わしがやった！　見たか！
わしの画が生命を生み出した！」
歓喜の声と共に画王は振り返る。
そこにカエル侍の姿はなかった。

## Page 3-20

「ああ、そうか」

わしへの恨みでも憎しみでもなく――
ただ、描けと。
それを伝えるためにあの侍を
寄越したのだ。

## Page 3-21
[フィルター：青]
画王が生み出した竜は台風と共に一晩中
暴れ回り、夜明けと共に消えた。
台風一過の朝は、清々しいまでに晴れ渡り、
朝日に目映（まばゆ）く輝いている。
竜になってしまったあとの工事現場は
無残な有様だったが、
あとには大きな池が現れていた。
――ケロケロ。
カエルだらけの、大きな池が。

## Page 3-22

「いったいどこまでついてくるつもりだ？」
画王が苦笑交じりにカエルを小突くと、

どこまでもケロ!!
