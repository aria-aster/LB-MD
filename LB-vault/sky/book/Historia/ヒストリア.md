# 名画ヒストリア
「ヒストリア(歴史)」は、宮廷画家ディディエ家が母娘三代の生涯を捧げ、完成させた超大作である。
初代フルーメが、碩学の魔術師から伝え聞いたユーファリアの歴史を絵画化する構想を抱いた。
魔王城の大広間を飾っていた本作は、その壮大さゆえに長らく未完の象徴であったが、孫フルルの代でついに完成した。
画中には過去の歴史のみならず、未来に起こる出来事までもが緻密に描き込まれており、正しく解読すれば未来を予見できると伝えられる。

# 神聖皇帝イル・カーン
戦乱と疫病で文明が退行した暗黒時代、南方の海洋民族出身のイル王はユーファリアを史上初めて統一、神聖帝国を建国した。
神聖皇帝イル・カーンを名乗った彼は、暦・単位・街道を整備し最大の功績とされる言語統一によって帝国の発展の礎を築いた。
暗黒時代を終わらせ「ドーンブリンガー(黎明をもたらす者)」と称される一方、その支配は苛烈を極め、反抗勢力は徹底的に弾圧された。
彼の急逝後、神聖帝国は後継者争いで分裂し、ユーファリアは再び戦乱の時代へと突入した。

# 巨人の骨発見か?

【カルゴーチェ発】大砂海北部のカルゴーチェ遺跡群で、巨大な人骨が発見され、調査団を驚かせている。人骨には激しい戦闘の痕跡が残り、当時の過酷な社会状況がうかがえる。

同時に出土した石版には格闘者を讃える記述があるとみられ、格闘者は女神への奉納儀式にも参加していたと推測される。

しかし、この文明は10を超える数の概念が曖昧だったらしく、石版の解読は難航している。専門家は「古代文明の謎を解く重要な手がかりだ」としており、今後の調査が注目される。

# ユーファリアの女神信仰
ユーファリアの多様な文化圏には、共通の精神的基盤として
女神信仰が存在する。各地に女神による創世神話が残り、
その消失が暗黒時代を招いたとする伝承は広く共有されている。女神の再臨による救済を待望する思想も根強く見られる。永遠教会では聖女を女神の化身とし、荒野の遊牧民は世界を浄化する破壊神として再臨を待つ。また、神聖皇帝は自らの血統から女神が生まれると喧伝し、権威の強化に利用した。これらは、唯一の女神が多様に解釈され、人々の暮らしや政治に深く根差してきたことを示している。

# 創世神話
はじまりは、ただ空だった。
そこに、歌があった。
女神が謳うと、歌を支え広げるために大地ができた。
大地を歌が巡ると、昼と夜ができた。
女神が謳うと、女神の歌を聴くために生命が芽吹いた。
生命の中に、女神と共に謳うものができた。
人である。人と女神は響き合ったが、
人の歌が女神の歌をかき消して、女神は謳うのをやめた。

# ユーファリアの地勢
ユーファリアは、東西の二大国による戦火が絶えない世界である。
東部を支配するのはプロメネス帝国。強固な地盤と広大な領土を背景に覇を唱える。対する西部は、大小の島々と複雑な入り江が特徴的なアヌーヴン連合王国の領域だ。
両勢力が対峙する大陸中央部には「ユラン平原」が広がり、
ここが長きにわたる衝突の主戦場となっている。
北方の限界線には峻厳な山脈「大氷壁」がそびえる。
大陸的な東と海洋的な西、要衝となる中央平原という地勢が、
この終わりの見えない戦争の構図を決定づけている。
