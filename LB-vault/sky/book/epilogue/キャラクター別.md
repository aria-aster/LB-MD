天才と名高い私が一緒で、あなたも嬉しかったんじゃない?

あなたの隣だったから、最高のショーができたんですよ。
種も仕掛けもない感謝を、あなたに!」

国民的アイドルマジシャンより、やりたいことができたので、カテドラルと共に、新しい世界へ向かう。

# メサイア
(イオナ)
「神獣は消え去り、私は名実共に救世主
(メサイア)となりました。
この私と共に戦えたことを誇りなさい。
あなたには世話になりましたね。
特別に私の第一使徒と名乗ることを赦しましょう。
良かったですね、指揮官。」

神獣は消えたが、ユーファリアは真の救済からほど遠い状態にある。
救世主である彼女の戦いは終わらない。

# モノクローム
(スミエ・アジム)
「色を失った世界で、きみや天使たちと共に
戦った日々は不思議と鮮やかに焼き付いている。
戦いを終えて、
本当に描きたいものの輪郭が、少しだけ見えた気がするよ。
ありがとう指揮官。」

神獣との戦いを終え、彼女の瞳は色を取りもどした。
それでも彼女はモノクロームの画を描き続けている。

# ユノ
「神殺しの戦いが終わりましたね。
最後まで戦い抜くことが出来たのは、指揮官の見事な指揮があってのものです。
任務中は色々と失礼なことも言いましたが・・・・・・あなたの副官であったことは、私の生涯の誇りです。」

ヒューム中将のもとでタスクフォースを率いて、王国との停戦交渉団に参加。和平の成立に大きく貢献した。

# ライデン
(惣角おいち)
「腰抜けのおいちを、あんたは立派なサムライにしてくれた。
神獣を倒して、みんなの笑顔を守れて本当によかったよ。
あんたと食べた飯、最高にうまかったなあ!......今まで本当にありがとな、指揮官!」

軍には戻らず、困った人々のためにちからを振るう。ナラクの忍びの里の開墾を手伝いながら、カミナッチャの美味しいお米を山盛り食べている。ただ、食べる量が多すぎて里の米びつはいつもピンチだ。

# ラヴレス
(エイダ・キーンズ)
誰ひとり失うことなく、神獣との戦いを終わらせることができた。
指揮官の指揮は本当に見事だった。
おかげで生き残り、もう一度ビリンダと歩むことができる。
ありがとう。」

フロウレスの故郷の村へ移住。彼女の家族や村人に温かく迎えられる。
不器用ながら畑仕事を手伝い、フロウレスと共に穏やかに暮らしている。

# ラッチバム
(ミリア・ノヴァク)
「ラッチは当然、大活躍でしたケド、指揮官はアレな先輩たちを使いこなしてすごいですね～。
ラッチが特別に褒めてあげますよ。
すごいすごい。
先輩たちがまたやらかした時は、相談に来ますね!」

愛され後輩としてユーファリア学園の生活を満喫中。闇鍋に林檎をいれたのはパネ子さんだったとつきとめたが「高級食材」による中毒死を防ぐためだったと言われ、ぐぬぬとなった。

# ラプチュア
(ネフェルトゥム)
「人間に心を許す気などなかったが、お前ちゃ
んには特別大サービスじゃ。
これからも余の傍にいることを許そう。
いつか「輝き」を手にする日まで、どこまでも連れ回してやるから覚悟するのじゃ!」

部下の猫たちを引き連れ、「輝き」を求めて新たな世界へと向かう。彼女たちはいつも幸せだ。猫はどこでも猫だから。

# リコリカ
(リヴィア・ボイラー)
「無事神獣討伐は終わったけど、指揮官はこれからどうするんだ?
もしよければ、私のグルメハントに同行しないか?
楽しいし、美味しいし、絶対に後悔させないよ。」

グルメハントの旅を再開する。その傍ら、絶滅危惧種の保護活動も行う。生態系を脅かす悪いグルメハンターたちをハントしてアシカトラズ監獄に送る活動も行っている。

# リリエル
(リリー・エデルシュタイン)
「神獣相手に大暴れできてスカッとしたなー!
アイコとラッチに頼れる先輩の姿も見せられたし、ほう、アタシたち英雄じゃん?ノエミの悔しがる顔が目に浮かぶわ!指揮官もおつかれさま。
ありがとね!」

ユーファリア学園に戻され、後輩たちと学園生活を謳歌している。委員長のノエミとの戦いは終わらず、今日も学園に騒動をまき散らしている。

# レインブリンガー
(茶谷部あめり)
「私も神獣と同じ世界をめちゃくちゃにしたいと思っていた。
でも、今はもうそんなこと思わないよ。指揮官やみんなと会えたからだね。ありがとう。」

ダークエンジェルに誘われ、ヒーロー活動を行う。市民の人気はダークエンジェルよりも上。

# ローズ
(モリー・ブライアー)
「もう神獣の悪夢を見ることもありません。
ふふ、あなたもこれからはたっぷり眠れますね。
おやすみなさい、指揮官さん。」

故郷に戻り、実家の宿屋の営業を再開した。「極上の眠りを提供する宿」として大繁盛している。不眠に悩む旅人には生演奏で安眠を提供しつつ、自分も一日十四時間眠っている。

新たな旅芸人一座を旗揚げ。露出度の高い踊り子としてユーファリアで大人気になり、世界中にギャル好きを増やした。王族から求婚されるが「ドレスとか暑苦しーしパス!」と断り自由を謳歌している。
