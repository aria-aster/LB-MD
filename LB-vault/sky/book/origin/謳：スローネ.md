# Chapter 1
深更奶
## Page 1-1
ぱさん。
ドッグタグを折り取る音が、
夜の闇に吸いこまれていく。
凍てつく地面に横たわり、
二度と目覚めることの無い部下たち。 頬に積もる雪を払い、
ドッグタグを一枚ずつ回収する。
集めたドッグタグが、ずっしりと重い 今日もこれだけの部下を失った。 千人いた部下も今や十分の一だ。
## Page 1-2
「キベーレ様。 斥候が戻りました」
塹壕内の指揮所に戻ると、
副官のナッシュが告げた。
冷え切った兵士が、
寒さに震えながら私に敬礼する。
「ビルに熱いコーヒーを頼む」
## Page 1-3
ビル
兵士はコーヒーを受け取ると、
見てきたものを話し始めた。
「敵の増援が到着しました。 陣地に収まらないほどの数です。 煮炊きの煙から見て、
三千はくだらないかと」
報告を聞いて、 副官が顔を曇らせた。 「敵の総数は万に達するでしょうな」
「我ら百人を陥落とせぬと見て、 その百倍もの戦力を集めるとは、
臆病にもほどがあるな」
私はつとめて明るく言った。
## Page 1-4
「副官。 司令部は何と言っている?」
「陣地を死守せよの一点張りです」
「兵と弾薬の補充は?」
「手配中との事ですが、口だけでしょう」
つまり司令部は我々に
ここで死ね
と言っているのだ。
## Page 1-5
「話は簡単だ。
我々ひとりが百人を討てば
良いだけのこと」
スローン
「我ら玉座中隊は、
ベテラン
帝国最強、 選りすぐりの古参である。
有象無象をどれだけ集めようが
敵ではない」
## Page 1-6
私の言葉にあてられ、
兵たちの顔に血の気が戻る。
「では、そのように伝達します」 副官が意気揚々と指揮所を
出て行った。
ここは守る価値など無い土地だ。
スローン
帝都防衛を任とする親衛隊玉座中隊が
北の涯てに追いやられ、
百倍の敵に包囲される事になったのは
私 キベーレ・エーテルブラッドのせいだ。
## Page 1-7
皇帝家は近親婚を繰り返し、 絡み合う蔦の
ように複雑な家系図となっているが、 失帝の実子、 直系の血筋は私だけだ。
皇 「弟」 アレクルストが皇位を継いだ
現在も、先帝への忠心を持つ者も多い。
副官のナッシュもそのひとり。
だから、
皇陛下殿は私が邪魔なのだ。
## Page 1-8
夜明けと共に敵の砲撃が始まった。 やはり補給は来なかった。
銃弾は手持ちの弾倉のみ。
これが尽きれば終わりだ。
塹壕の中で、爆音が空気を切り裂きながら
頭上を通過するのを聞く。
これでパニックを起こすような兵は誰もいない。
やがて、砲撃が止むと、
敵兵の叫び声が聞こえた。
突撃が、 始まったのだ。

# Chapter 2
＊
## Page 2-1
「弾を無駄にするな。 引きつけて撃て! 撃つのは敵の白目が見えてからだ!」 副官が絶叫する。
一方の敵兵が、奥季の叫び声をあげ、 この塹壕陣地目がけて殺到してくる。
地面が揺れ、大気が震える。
指揮官が恐怖を見せれば兵が動揺する。
口角をあげ、不敵な笑顔をつくり、
敵を睨みつけた。
## Page 2-2
雪原に赤い花が咲く。
こちらの選抜射手が射撃を始めたのだ。 銃声がするたび、 敵兵が倒れる。
それでも全く敵の勢いは衰えない。
私は、祈るべき神を持たない。
神に祈り、事態が好転した事が無いからだ。 目の前の現実を受け容れ、
それに対処するしかないのだ。
敵兵の中央に、 光の柱が立った。
数瞬後、 敵兵が宙に弾け飛ぶ。
誤射か?
何が起こった?
## Page 2-3
「キペーレ様! 上を!」
想像を絶するものが、上空にいた。
朝焼けに照らされ、燃えるように輝く
巨大な物体。
その物体から無数の光の柱が、
大地に降り注いだ。
その度に、人が、 土砂が舞い上がる。
この破片が、 四壕の中にまで落ちてきた。
## Page 2-4
「............ 神獣、なのか?」
この目で見るのは初めてだった。
じゅうりん
神獣が敵を蹂躙している。
私も部下り、呆然とその光景を
見つめていた。
人の戦争が子供だましに思えるような
圧倒的な暴力。
壊滅していく敵を見ても、
喜ぶ者は誰もいなかった。
次は我々の番だから。
## Page 2-5
だが突然、 神獣はその姿を消した。
「奇跡です陛下。 キベーレ様が持つ
現れた時と同様、 何の前触れもなく
いなくなってしまった。
神獣が消えてたっぷり半時間ほど経つと、 ようやく副官が口を開いた。
神聖な皇帝の血が、 もたらした奇跡・・・・・・ と、 言う事にしてはいかがでしょう。 兵の士気を上げ、敵を恐れさせます」
「それで良い」
そう言うだけで精一杯だった。
## Page 2-6
皇帝の血云々の宣伝が、 味方はともかく
敵に効いたとは思えないが、 この日、 敵の攻勢は無かった。
時的に神獣に救われた結果になったが、
戦争は続いている。
翌朝になれば、 敵は再編成をすませ。 総攻撃を開始するだろう。
それでも我々は今日を生き延びたのだ。
## Page 2-7
日が暮れると、ようやく補給が到着した。 武器も弾薬も無く、わずかな食料と酒だけ。 最後の晩餐というわけだ。
「皇帝陛下からの陣中見舞いです。
ぜひとも皇女殿下に 召し上がって頂くよう、
言付かっております」
## Page 2-8
補給に付き添った使者は、
虹色の林檎を差し出し、 そう告げた。
この林檎の噂は聞いたことがあった。
かじれば天使の力を得るが、
運が悪ければ死ぬ。
「かくも貴重で運頼みな戦略物資を賜り、
恐悦至極。どちらに転んでも」
「 陛下には好都合なのでしょうな」
憎まれ口のひとつも叩かねば気が済まない。
## Page 2-9
だが既に策は尽きていた。
司令部が、我々を救うつもりがない
のはよく分かった。
「キペーレ様、 お止しください」
私の意図を察したのだろう。
ナッシュが青ざめた顔を向ける。
「ナッシュ、 有事の際には
貴公が指揮を執れ」
副官の制止を無視し、
私は林檎を手に取ると、 かじりついた。

# Chapter 3
黎明
## Page 3-1
[ページ種別：青]
アザラシの旗が無数にはためいている。 大地を埋め尽くす魔王軍の軍勢により
王都は完全に包囲されていた。
やれやれ・・・...。 夢の中でも戦争か・・・・・
私は敗色濃厚な側の指揮官であるらしい。
玉座に腰掛け、部下たちの
気が滅入る報告を聞いていた。
## Page 3-2
[ページ種別：青]
城の中で何か騒動が起こった。
怒声と剣敦の音が近づいてくる。
けんげき
「陛下、避難をなさってください」
部下は言うが、どこへ逃げるというのだ。
やがて、玉座のある広間に、
ひとりの女が姿を現した。
それは紛れもなく、 敵軍の総大将
魔王
その人だった。
## Page 3-3
[ページ種別：青]
「人の王よ。 魔族の王が
決着をつけに来てやったぞ」
こいつ
魔王はアホなのか?
魔王軍は我が城を完全に包囲しており
勝利は目前。 こんな危険を冒す必要は無い。
なのに魔王は、単身乗り込んできた。
私に決闘を申し込むために。
その意気や良し!
## Page 3-4
[ページ種別：青]
魔王が静かに武器を構える。
「謹んでお受けいたそう」
巨大な鎌と剣の二刀流。
私は玉座から立ち上がり、剣を抜く
剣はレガシーアームズ。 業物だ。
「手出しは無用」
私が女王となったのは、
背後の部下たちにそう言い添えておく。
場で戦い続け、勝ち続けたからだ。
まだ剣の腕は衰えていない。
## Page 3-5
[ページ種別：青]
正面から魔王の喉笛目がけて剣を走らせる。
魔王は躱すことなく、武器で受けた。
「良い太刀筋だ!」
魔王の振ろう鎌を避け、剣と剣を打ち合わせる。
## Page 3-6
[ページ種別：青]
一度、二度、三度。
切り結ぶうちに、魔王の意図に気付いた。
この城はヒトにとって最後の砦だ。 総力戦は避けられず、
大量の血が流れるだろう。
だが、
総大将同士の決闘で、
私が敗れれば、流れる血は最少で済む。
魔王のくせに、余計な気を回すものだ。
## Page 3-7
[ページ種別：青]
降参するべきなのだろう。
だが、負けを認めたくない。
何より、ここまで打ち合える相手は
今までいなかった。
あまたの戦を重ねてきたが、
魔王との一騎打ちほど愉快な戦は無い。
私は心の底から悦びを感じていた。
## Page 3-8
[ページ種別：青]
どんな戦も、いずれは終わりが来る。
魔王の剣が私の胸を貫き、私は敗れた。
「許せ。 本気で挑んでくるものだから、
本気を出さざるを得なかった」
薄れゆく意識の中、 魔王はそう呟いた
## Page 3-9
「一様。 キペーレ様!」 副官の声で目覚めると、塹壕の中だった。
私は玉座に腰かけ、
その玉座からは翼が生えている。 天使になれたのだろうか。
## Page 3-10
玉座の翼が羽ばたくと、宙に舞い上がった。
「キベーレ様だ! 天使のお姿だぞ!」 「皇女殿下、 万歳!」
部下たちが私を見て、歓声を上げる。
夜が明けようとしていた。
朝陽の下、空から戦場を一望すると
敵陣地の様子が手に取るように分かった。
敵は総攻撃を行う寸前だ。
## Page 3-11
「神獣の次は天使だと!?」
「終わりだ!ありえない事ばかりだ!」 士気の高い部隊では無かったのだろう
神獣による踝の傷が癒えぬまま
天使を目撃した敵兵は、恐慌状態に陥った。
一人逃げ出す兵が出ると、
恐慌は拡大し、兵の逃亡が止まらなくなる。
やがて隊列を維持できなくなると
一万の軍勢が今や烏合の衆だ。
やがて、踏みとどまった
わずかな敵兵も退却を始めた。 敵の追撃と掃討は我々の仕事ではない。 陣地防衛の任務は終わったのだ。
敵部隊は瓦解した。
## Page 3-12
玉座中隊は帰国が許された。
私を除いて。
「良いのですかキベーレ様!?」 副官だけでない、部下たちは皆、 司令部への怒りに燃えてる。
良い部下を持ち、私は本当に幸せだった。
「天使が戦う相手は人ではない一 神獣だ」
天使は、 神獣と戦うための部隊に
所属しなければならない。
誰であろうと。
「私は必ず、 諸君らの守る 「玉座」
に帰ってくる。 それまで玉座は任せたぞ」
## Page 3-13
部下たちに見送られ、 私は飛び立つ。
れいめい
黎明の光を浴びながら、
私の胸に希望が芽生えるのを感じた。
これからは、誰に邪魔されることもなく、 人の敵と思う存分戦えるのだから。
