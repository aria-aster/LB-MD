# Chapter 1
無の始まり
## Page 1-1
[ページ種別：青]
腐った肉の臭いが漂っていた。
素肌が湿った空気に晒され、
背中に銀髪が流れ落ちる。
少女は重たいまぶたを持ち上げた。
地下室らしき部屋。 裸電球しか灯りはない。
少女はぼうっと立ち尽くしたまま、
自身の足元を見つめる。
そこに転がっているのは、
血の池に沈む若い男の死体と
皮膚も内臓も腐り落ちた女の死体だった。
## Page 1-2
[ページ種別：青]
「死体を見ても何も感じないか」
しゃがれた声に問いかけられ、
少女はゆっくりと顔を上げる。
そこにいたのは初老の男だった。 男は目を醒ましたばかりの少女を 頭から爪先まで眺め、値踏みする。
男の視線が、 少女の左手に注がれた。 「お前をどうこうするつもりはない。 私の目的は「銀のヤドリギ」だけだ」 少女は銀製のヤドリギの枝を握っていた。
## Page 1-3
[ページ種別：青]
初老の男は血の池を革靴で踏んで
やってくると、少女の持つヤドリギに
手を延ばす。
ヤドリギは身を引くように、
少女の左手の中に溶け込んで消えた。
不可解な現象を見てもなお、
少女は無言のままだった。
## Page 1-4
[ページ種別：青]
「面倒だが、
お前ごと買い受けるしかないようだな」
初老の男は眉をしかめる。
「ついてこい、ヘルミナ」
呼ばれて初めて、少女は自分の名が
「ヘルミナ」 なのだと分かった。
少女は転がるふたつの死体のことも、
体の中に溶け込んだヤドリギのことも、 自分が何者なのかさえわからない。
何も覚えていない。
## Page 1-5
[ページ種別：青]
「あなたは？」
「それも覚えてないのか？
ヨシュアだ。 ヨシュア・ヨアヒム」
「ヨシュア……」
ヘルミナは、腐った女をまたぎ、
血の池を素足で踏んで、
ヨシュアの後を追った。
## Page 1-6
[ページ種別：青]
豪奢な屋敷の一室にヘルミナはいた。
人形のように着飾り、行儀よく座っている。
ヨシュアは家の主らしき男と話をしていた。
ヘルミナは目の前のテーブルを見つめる。
そこには客をもてなすご馳走ではなく、 子供の死体が乗せられていた。 また死体だとヘルミナは思った。
## Page 1-7
[ページ種別：青]
「本当にできるのでしょうね」
家の主がヨシュアに言う。
「カネさえ払えば」
ヨシュアが端的に言うと、
男の顔が卑屈に歪んだ。
「父の遺産はすべてコイツが相続するのです。
コイツが生き返れば、そんな端金
いくらでも払って差し上げますよ」
ヨシュアが差しだした契約書に、
男は走り書きでサインをした。
ヨシュアは満足げにうなずき、
ヘルミナに命じる。
「やれ」

# Chapter 2
月の合図
## Page 2-1
[ページ種別：青]
ヘルミナは子供の死体に近づくと、
左手で死体の鼻と口を覆った。
ヘルミナの左手から、とろりと白い粘液が 流れ出て、鼻と口から死体の内部へと
注ぎ込まれていく。
白い粘液が、死体の内部に満ちていく。 やがて、死体の皮膚の弱い部分を
食い破るように、 白い粘液が溢れ出た
「ひぃいーッ」
あまりの不気味な光景に、
家の主が悲鳴を上げる。
## Page 2-2
[ページ種別：青]
死体からあふれ出た白い粘液が、
ボロボロになった死体のそばに集まると、 死体と同じ大きさの物体を形づくっていく。
粘液は、死体の子供と
瓜ふたつの姿になった。
「いいぞ、じきにホムンクルスが目覚める」
ヨシュアが微笑んだ。
ホムンクルスの純白の肌に、
赤みが差した。 心臓の鼓動が始まる。 胸が上下して呼吸を始め、ついに
上半身を起こした。
## Page 2-3
[ページ種別：青]
「デニケンおじさん……？」
子供が家の主を見上げて言う。
「うぁあ！」
呼びかけられた男は泡を吹いて卒倒した。
「やれやれ……」
ヨシュアが肩をすくめる。
「おじさん、 デニケンおじさん!」
懸命に呼びかける子供を眺めながら、
ヘルミナは考える。
## Page 2-4
[ページ種別：青]
このホムンクルスは、
どうやら記憶を持っているようだ。
だが、ヘルミナは何も覚えていない
私は何者なのだ？
## Page 2-5
[ページ種別：青]
ある夜、ヘルミナは窓辺に椅子を寄せ
丸い月を見上げていた。
ここはヨシュアの宝物庫。
彼女は眠らない監視者でもあった。
窓が開き、 外から一人の男が姿を
現したからだ。 ヨシュアの部下
エランと呼ばれていた男だ。
眠る必要がない身体は夜を持て余す。 だがその夜は少し違った。
エランはヘルミナに手を差し出す。
## Page 2-6
[ページ種別：青]
「俺と来てくれ、 ヘルミナ。
君が必要なんだ」
「私じゃなくて、
私の力が必要なんでしょう？」
だがエランは間髪入れずに
「どちらもだ」
と、力強く答えた。
「俺と来れば、君が何か教えてやれる」
ヘルミナの瞳がわずかに揺れる。
それは、
ヘルミナが唯一求めるものだった。
戸惑いも期待も無かった。
ヘルミナにとってこの男もヨシュアも
変わらない。
## Page 2-7
[ページ種別：青]
「……勝手にすればいい」
ヘルミナの素っ気ない返事にうなずくと、
エランはヘルミナを屋敷から連れ出した。
## Page 2-8
[ページ種別：青]
「「銀のヤドリギ」は、
ホムンクルスを造り出すオーパーツだ」
夜の荒野に車を走らせながら、 エランは語る。
「俺の友人が亡き妹を
ホムンクルスとして複製しようとして、
君を造り出した。
だけど……」
「そのときに何かしらのアクシデントが
あって君はヤドリギと一体化
しちまったらしい」
エランの態度は飄々としていたが、
ハンドルを握る手には力がこもっている。
「なるほど」 とヘルミナは呟く。
その友人と妹というのは、ヘルミナが
目醒めたとき、地下室に転がっていた
ふたつの死体のことだろう。
## Page 2-9
[ページ種別：青]
ヘルミナは複製元の妹のことも、
その兄だというエランの友人のことも
覚えていない。
「ふたりの死を悲しいと思うべきなので しょうね。 でも、私は喜びを感じている」
「喜び？」
エランはちらりとヘルミナに目を向けた。
## Page 2-10
[ページ種別：青]
「私がどこから来たか分かったから」
ヘルミナの声にわずかな熱が乗る。 あるはずのない鼓動が、
やっと動き出したかのように感じた。
エランは 「そりゃよかった」と
機嫌良く前に向き直る。
車はヘッドライトに照らされた道路を
淡々と進み続ける。
## Page 2-11
[ページ種別：青]
「私の由来は分かったわ。
でも「銀のヤドリギ」はいったい何？」
ヘルミナが続きを促すが、
エランは 「それは分からない」と答えた。
オーパーツとは謎だらけのものらしい。
ヘルミナは「ふぅん」と気のない返事をし、
助手席のシートに身を沈める。
見下ろした左手は夜に光るように白く
ヤドリギを隠したままだった。
「銀のヤドリギ」は、私に何をさせたいのかしら？

# Chapter 3
林檎の後押し
## Page 3-1
[ページ種別：青]
エランとの旅は長く続いた。
ヘルミナはエランの助手として過ごし、
それなりに平穏に暮らしていた。
だがある日、 エランは仕事に出かけ
そのまま帰ってこなかった。
おそらく殺されたのだろう。
もう、誰もヘルミナを知るものはいない。
ヘルミナが何をすべきか、言ってくれる人はいない。
ヘルミナは、長い眠りについた。
## Page 3-2
目を醒ますと、
お姫様のように着飾った少女が
食い入るようにヘルミナを見ていた。
「ねえ、あなたってとってもステキ!
わたしの集めたオーパーツの中でも とっておきのお気に入りよ！」
ヘルミナと彼女の間にはガラス板があった。 彼女はまるでヘルミナを抱きしめるように
そのガラス板にすがりついている。
鼻息は荒く、目は爛々と輝いていた。
この人間は……なに？
## Page 3-3
ペタペタとガラスに触れる少女の奥には、
大量のオーパーツが並んでいる。
それらはヘルミナと同じように
ガラス板に覆われ、飾られていた。
どうやらヘルミナは博物館ミュージアムのような場所で
展示されているようだった。
「ああ……いつまでも見ていたい。
でもそれも叶わぬ夢……。
ああ、信じられない。 信じたくない。
明日には人の手に渡ってしまうなんて」
どういうこと？
## Page 3-4
ヘルミナは目醒めたばかりの頭で 必死に現状を把握しようと努める。 おそらくヘルミナは彼女の手に渡り、
展示され…… 手放されようとしている。
自分が今いつの時代にいて、
何をすべきなのかもわからないまま。
「冒険も始められず、
オーパーツすら奪われていく。
そうして夢から醒めるくらいなら――
少女が、 虹色の林檎を手に取るのが見えた。 勢いよく林檎をかじり、
その場に崩れるように倒れ込んだ。
## Page 3-5
林檎をかじった少女は謎の光に絡め取られ、
まるでサナギのような姿になり、動かなくなった。
ヘルミナは失望した。
この少女は面白かったけど……。
白い粘液は小さな槍を無数に象り、
ヘルミナを囲うガラスケースを割った。 裸足の足がぺたりと博物館の床に着く。
「さようなら、 人間」
他の知らない人間のものになるのは嫌ね。
ヘルミナはサナギとなった少女に告げ、 博物館から飛び出し、 駆け出す。
ヘルミナが左手を上げると、
手のひらから白い粘液が溢れ出す。
## Page 3-6
ヘルミナが自分の意志で
何かを始めたのは
これが初めてだった。
夜空には丸い月が浮かんでいる。
それはヘルミナにとって、 旅立ちの合図だ。
結局、 自分が何者なのか、
何をすべきなのかはわからなかった。
だがそれでいい。
これから、見つければいいのだから

Fin.
