# Chapter 1
一族の教え
## Page 1-1
らしくない事をしてしまった。
息を切らし、追っ手から逃げながら、
そんなことを思う。
何の利益もない人助けなど、
私の一族には相応しくない選択だ。
みじめに帝都の旧市街を駆け回っていても
その選択に後悔はなかった。
## Page 1-2
私の一族は、古い一族だ。
その歴史は帝国分裂以前、
神聖帝国の時代にまで遡ることができる。
私の一族の血筋は、 現皇帝アレクルストの
血筋よりもはるかに古く、 それに見合う 力を持っている。 帝位を揺るがす程の力を
権力を求める者にしてみれば、
目障り極まりない存在だったはずだ。
## Page 1-3
そんな私の一族が現在まで
生き延びてこられたのは、
あるやり方を貫いてきたからだ。
すなわち「最も強い者に従う」こと。
最も強い者とは、平たく言えば 「皇帝」だ。 いかに高貴な血が流れていようとも、 帝位に就かなければ誰もが、 有象無象。
最大の権力を持つ者に従い、
その権力の維持に尽力する。
それが一族を連綿と生かした方法だった。
## Page 1-4
そこに、忠誠心はない。
皇帝が最大の権力を持つ間は
敵となる者が強大な権力を持つ前に
失脚させ、排除する。
しかし、皇帝となった者が必ずしも
強力な権力を持つに足る器だとは限らない。
帝位を巡る争いは熾烈だが、
生まれだけで帝位を得る者がいるのも
ままあることだ。
## Page 1-5
例えば、 先代の皇帝がいい例だ。 先代はよき人格者ではあったが、 皇帝であるにはあまりにも優しすぎた。
強権を振るうことをせず、
その下で虎視眈々と牙を磨いていた
義弟のことも実に厚遇した。
我が一族が、 皇帝をも超える権力へと 成長した義弟を帝位に就けたのは
必然だった。
それに与したのが私の祖父母だと
聞き及んでいる。
## Page 1-6
時の権力者に媚びへつらい、
生き延びてきたのが私の一族だ。
私も、生まれたときから
すべきことが決まっていた。
愛情を与えられた覚えはない。
物心ついたときから叩き込まれたのは、
一族の教えだった。
その教えを守っていれば、
私の人生は安泰のはずだった。
## Page 1-7
旧市街のゴミ溜めの中で息を殺し、
追跡者が立ち去るのを待つ。
今となっては、
なぜそんなことをしたのか分からない。 魔が差したとしか言いようがない。
エディナ様。皇帝の長子にして、 皇后殺害の犯人。
私は、彼女の逃亡の手助けをしたのだ。
## Page 1-8
人間は四種類に分けられるという。
有能な者と、無能な者。 勤勉な者と、怠惰な者。
己の分もわきまえず余計な手出しをして
事態を悪化させる。
この手合いは殺すしかない。
最も害悪となり得る者は、
無能でありながら勤勉な人間だ。
まさに、私がそれだった。
無能な働き者
## Page 1-9
私のせいで一族は、長きにわたり
築き上げた信用を一瞬にして失った。
私を殺せと命じたのは実の両親だ。 冷淡に、冷徹に、手下に命じたに違いない。
母親殺しの少女を救った私が
実の親に殺されようとしているとは
全く、笑えるじゃないか。

# Chapter 2
忠実なる遵法者
## Page 2-1
誰も信用するな。
一族で最初に叩き込まれる教えだ。
他人はもちろん、 親兄弟でも信じるなという 
教えを忠実に守ってきた果てに残ったのは、 無力で孤独な小娘ひとり。
信用できる者もおらず、頼れる先もない。 一族は互いに信用せずとも
裏切らないことで結束を固めてきたのだと、 追われる身となってようやく理解した。
## Page 2-2
これまで鼻薬を嗅がせて操ってきた連中、
私に味方などしようはずもない。
金は裏切らないが、金で動く者は容易く裏切る。
（このままでは、もう……） 今日は逃げ切ったが、 明日は逃げ切れるか。 明日逃げ切って、 明後日は？ その先は？
一生逃げ続けることなど、到底不可能だ。
## Page 2-3
もはや、逃げ場はない。 追い詰められた私は、
グレゴールの林檎を取り出す。
天使になるためのオーパーツ。 運が良ければ天使になれるが、
悪ければ死ぬ。
過去の仕事で偶然手に入れた代物だ。
いつか何かの役に立つのではと
懐に忍ばせていた。
一族の手の及ばない場所が、 ひとつだけあると聞いたことがある。
## Page 2-4
神獣と戦うことのみを目的として
編成された天使部隊だ。
天使になることができれば、
その部隊に入ることができる。
もしもなれなければ――
私は林檎をかじった。
天使になれなかったなら、
それが私の運命なのだ。
## Page 2-5
暗号化によるノイズが入った映像に
「私」は目を細める。
無数のモニターに、さまざまな角度から
演奏会のステージが映し出されていた。
中央には枯れ木のような年寄りが、
小刻みに震えながらバイオリンを
抱えている姿が映し出されていた。
再びノイズが走る。
潜入させている虫型カメラとの通信状態が
悪いのだろうか。
## Page 2-6
[ページ種別：青]
ジャン
老人がバイオリンを構える。
その瞬間、曲がっていた老人の背は伸びて、
震えも止まった。
老人は静かに音楽を奏で始める。
伸びやかなバイオリンの音色。
モニターは聞き惚れる聴衆を映している、
## Page 2-7
[ページ種別：青]
「未登録音楽の可能性」
機械知性がアラートを鳴らす。
演奏が下手なだけなのか、 未登録なのか。 最終判断は機械知性ではなく、
人間――つまり私が
下すことになっていた。
（下手であればよかったのに……）
感傷は、ノイズのように一瞬だった。 法を犯しているのはあの老人であり、
違法の地下演奏会へと足を向けた聴衆だ。
## Page 2-8
[ページ種別：青]
「突入しろ」
私の指示で、火炎放射器を持った
警備ドローンが会場に突入していく。
「消防に連絡しておけ」
別の指示を出して席を立つ。
残された画面には「No Signal」 の文字が
映し出されていた。
## Page 2-9
[ページ種別：青]
「某雑居ビル地下で、
火災が発生しました」
街頭の巨大モニターを私は見上げた。
夜にもかかわらず、街は眠りとはほど遠い。
ネオンの明かりが降ってくるようだ。
「死者26人。
被害者の中にネフィリムはいませんでした」
モニターに流れるニュースから目をそらす。
この世界では、ネフィリム以外の命など
ただの数字に過ぎない。
(――けれど、これが私の仕事だ)
## Page 2-10
[ページ種別：青]
音楽管理機構「A*」 エースターの検閲官。
それが、 私の仕事だ。
機械知性と共に、 未登録の楽曲と
その演奏者を排除する。
世界には、見つかってはいけない音楽、 決して演奏してはいけない音楽がある
それを排除するためなら、 どんな犠牲も許容される。

# Chapter 3
教えからの解放
## Page 3-1
[ページ種別：青]
薄汚れた靴先を朦朧とした頭で見ていた。
空は晴れ渡っているというのに心は重い。
空になった缶が、 手から滑り落ちた。
地面に転がる音で我に返る。
足下には空き缶が幾つも転がっている。
## Page 3-2
[ページ種別：青]
音楽が聞こえる。 私はのろのろと顔を上げた。
ここは公園だ。
老若男女の行き交う真昼の公園は、音楽で満ちている。
## Page 3-3
[ページ種別：青]
公園の野外音楽堂で、
若い男女が演奏をしていた。
技巧はない。 素人の手習いだ。
それでも、客席にはまばらながらも
聴衆が腰を下ろして音楽を楽しんでいる
私は、何のために・・・・・・。
傍らに置いた新しい缶を開けて、
ぐいっとあおった。
## Page 3-4
[ページ種別：青]
音楽管理機構「A*」エースターは解体された。
私のしてきたことは何だったんだろう。
未登録楽曲が
自由に演奏できる時代になったのだ。
当然「A*」エースターの職員であった私は職を失った。
元検閲官という肩書きは、
「A*」エースターの教えに従い、 それが正しいと信じて
違反者を排除してきた。
それなのに……
今や嫌悪と侮蔑の対象だ。
ただ、大勢の犠牲者を出しただけだった。
## Page 3-5
[ページ種別：青]
「ブラボー！」
演奏を聴いていた中年男が
立ち上がって賞賛を送る。
人々の拍手に、演奏していた若い男女が
照れたようにはにかんだ。
（ああ――あの老人だって）
地下で焼き払われた老人も、
バイオリンも、聴衆たちも、
ただ音楽を楽しんでいただけなのに。
それなのに、
どうして私が音楽に感動できる？
## Page 3-6
[ページ種別：青]
迫り上がってきたのは罪悪感か
それともただのアルコールによる吐き気か。
腕時計型のデバイスが振動を伝え、
アラートを出す。
血中アルコール濃度が高いとの警告だ。
私はデバイスを投げ捨てた。
こんなもの、もういらない。
再び聞こえてきた軽快な音楽に目を閉じて
私は酒をあおり続けた。
## Page 3-7
[ページ種別：青]
こんなわたしは
こんな命、なくなってしまえばいい。
みじめに しんでいく のが
みじめであれば、 あるだけいい。
おにあいだから――
## Page 3-8
「う……」
頭の中をハンマーで殴られるような痛みに
思わずうめく。
最悪な気分だった。 酒も飲んでいないのに
二日酔いになったようだ。
視界の端にちらつく黒いものに目をやる。 黒い翼と、夢で見た警備ドローンだ。
ならば、今見た夢は？
ただの夢なのか、それとも別の可能性か。
## Page 3-9
（――どちらでも同じか） 結局、 私はどこでも
同じようなことをしているのだ。
教えに盲目的に従って、誰かの命を奪って、
そうして、孤独になって――
けれど、これからはどうなるだろう？
天使という新たな可能性を
与えられた私は。
## Page 3-10
「まずは天使部隊を探さなければ」
まだ一族の脅威は去っていない。
一刻も早く天使部隊へと合流する
必要がある。
生まれたばかりの翼を羽ばたかせ、
大空へと飛び立つ。
一族から解放されて、心が軽かった。
誰か、信用できる人を見つけられたらいいな。
そんなあどけない願いが心に生まれて 私は生まれて初めて、 小さく笑った。

Fin.
