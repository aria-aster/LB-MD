# Chapter 1
Taboo 
## Page 1-1
東の果てに浮かぶ島ーー邑原（オウハラ）。 
山深くの獣道を、ふたつの影が 
踏みしめていた。 
「はぁ、はぁ。 ルーシーさん、 
ちょっと待って。休憩しましょうよ」 
役人のハバヤマが、汗だくの額を 
ぬぐいながら言う。 
## Page 1-2
「ンモー、日が暮れるデスよ。 
ヒトリで行くから、ココで待っててネ 」
「そういうワケにはいきません。 
文化財保護のため、学術調査には局員が 
立ち会う決まり・・・・・・。 
って、待ってくださいよぉ！」 
やがて、ふたりの行く手が開けた。 
幾重ものしめ縄が張られた広場だ。 
縄には無数の腐った草鞋が 
かけられている。 
## Page 1-3
「ワォ! やっと着きましたネ! 
この先は禁足地 神の住まう場所デース」 
「そんなところ入っちゃダメでしょ。 
呪われますよ!」 
「作法を守れば大丈夫デス。 
ここで履き物を脱いで、 
縄にかけて入るのがマナー」 
「ええ••・・・・ 僕の革靴、 高級品なのに・・・・・・」 
「そうしないと、 禁足地から 
出られませんヨ?」 
「うう・・・・・・わかりました。 裸足キモ・・・・・・」 
## Page 1-4
素足が触れる苔むした地面が心地良い。 
ルーシーは期待に胸を膨らませ。 
歩を進めた。後ろからハパヤマが文句を 
言いながらついてくる。 
留学生であるルーシーの研究テーマは、 
東方への文化の伝播だ。 
暗黒時代より前の記録はほぼ失われているが 
秘境の島「邑原」 ならば帝国成立以前の 
時代を生きた旅人の痕跡が 
残っているかも知れない。 
## Page 1-5
邑原は現在、無人の島だ。 
帝国軍の管理下にあり、軍人以外が
立ち入ることは禁止されている。 
ルーシーは粘り強く交渉を重ね、 
ようやく今回の調査が実現したのだ。 
この機会を逃せば、次はいつ邑原に
来ることができるか分からない。 
行けるところは、どこにでも行きたかった。 
## Page 1-6
やがて、古い石積みの社があらわれた。 
「ンソー! 興味深いデース! 
この様式は、ユーファリア西部の 
女神信仰の影響があるカモ!」 
## Page 1-7
「ワタシ、 大陸西部から邑原に 
漂着した者がいたという仮説を 
提唱しているのデス。 
大発見デス、論文にしたら大騒ぎ―」 
「もう勘弁してくださいよ、 ルーシーさん」
背後のハバヤマが、うんざりした様子で 
ルーシーに拳銃を向けた。 
「ハバヤマさん? 
ど、どういうことデス・・・・・・?!」 
## Page 1-8
「私、実は機密局の人間だと言えば 
おわかりになりますかね?」 
「機密局? ワタシ、スパイじゃないよ!」 
「そっちじゃなくて······。 
「存在してはならないもの」を回収、
または秘匿する事が私の役目です」 
ハバヤマの視線は、小さな石積みの社に 
注がれている。 
「貴女がそんな論文を発表すれば、 
連合王国が領有権を主張する可能性がある」 
「んなバカな! だって、大昔の歴史の 
話なんデスよ?」 
「歴史でも何でも、他国を攻撃する手段に 
なるなら使うんです。 それに・・・・・・」 
## Page 1-9
「戦争犯罪が、 バレたら困る・・・・・・。 
デスカ?」 
ハバヤマの手前、口にはしなかったが、 
軍人による過酷な統治の痕跡は邑原の 
あちこちに転がっていた。 
「こちらの用意した、 無害なシロモノだけ 
調査して帰ってくれれば・・・・・・。 
こんなことしなくてすんだのですが」 
「タマゴとは言え、研究者が、 
そんなもので満足するわけないでショ?」 
「残念です。 ルーシーさん」 
神域に、銃声が響き渡った。 
## Page 1-10
「やばいやばい、 ハバヤマが射撃下手クソで 
助かったデス」 
ルーシーは、 禁足地を裸足で駆ける。 
ハバヤマの気配が追ってくるのを感じる。 
古木のうろ穴に、輝くものが見えた。 
「アレ...... もしかして・・・・・・」 
それは、虹色に輝く林檎だった。 
天使になれるという。 グレゴールの林檎。 
「ルーシーさん!」 
ハバヤマが追いついてきた。 
銃弾が頬をかすめる。 
## Page 1-11
ルーシーは林檎をつかんだ。 林檎をかじり、
運が悪ければ天使になれず、 死ぬ。 
「・・・・・・ このままでも遅かれ早かれデース」 
「ワタシに論文発表のチャンスを 
くだサーイ!」 
思いきり林檎をかじると、甘酸っぱい味が、 
口の中に広がった。 
同時に、視界が真っ暗になる。 体が痛い。 
意識が遠のいていくーー

# Chapter 2
Stranding 
## Page 2-1
[ページ種別：青] 
今日も船着き場はにぎわっていた。 
「YOISHO!」 
ルーシーは、魚でいっぱいの大きなカゴを 
肩に担いだ。 
「さっすがマロウドさん、 力持ちだねえ」 
ほっかむりのおばさんが、 ルーシーの 
盛り上がった筋肉をぴしゃぴしゃと叩く。
## Page 2-2
[ページ種別：青] 
ルーシーが、この島に漂着してから 
およそひと月。 
言葉も通じない、 目の色も髪の色も違う、
小柄な人々と一緒に、ルーシーは賢明に 
生きていた。 
## Page 2-3
[ページ種別：青] 
「マロウドさん、 これ持っていきな」 
おばさんから、 干物をもたされ 
ルーシーは深々と頭を下げる。 
おばさんの後ろで、 若い男がルーシーを 
にらみつけていた。 
理由は分からない。 問いただすための言葉も 
知らない。 
ルーシーは、男に近寄らないよう、 
そそくさとその場を後にした。 
## Page 2-4
[ページ種別：青] 
ルーシーは、浜辺の小屋で横になった。 
さすがに故郷のフカフカペッドが懐かしく
なったが、見慣れない土地での生活は 
エキサイティングだ。 
全財産をはたいて冒険の船旅に出ただけの 
価値はあった。 
ーー片道切符になるとは思わなかったけど。
もっと言葉を覚えないとデース・・・・・・。
そう思いながらまどろんでいると、
突然、小屋の戸が蹴破られた。 
## Page 2-5
[ページ種別：青] 
「ヒャア! なんデスか?!」 
飛び起きると、 小屋にドカドカ 
殺気立った男たちが押し入ってきた。 
先頭にいるのは、昼間ルーシーを 
にらんでいた男だ。 手に鎌を持っている。 
彼だけではない。男たちは皆、斧や農具を 
手にしている。 
## Page 2-6
[ページ種別: 青] 
男たちは口々に何かをわめいていた。 
聞き取れたのは、 「おに」 という言葉。 
意味は分からなくても感情は伝わる。 
男たちは青ざめ、手が震えている。 
彼らが突き動かされているのは、怒り 
ではなく、恐怖だ。 
## Page 2-7
[ページ種別：青] 
例の男が鎌を振り上げ、 ルーシーに 
襲いかかってきた。 
無我夢中だった。 
ルーシーが男を突き飛ばすと、 
男は柱に頭を打ち付け 
ずるずると座り込んで、 
そのまま動かなくなった。 
柱に血の跡が伸びている。 
「ーーうわぁああ!」 
僅かな沈黙のあと 男たちが一斉に
逃げ出した。 
「おにだ!」「おに!」 「ころされる!」 
## Page 2-8
[ページ種別: 青] 
静かな夜が戻ってきた。 
頭を打った男に恐る恐る触れると、 
すでに息はなかった。 
「ひいっ……!」 
ルーシーもまた、 小屋を飛び出した。 
あてもなく走り出す。 
人を殺してしまった。 
取り返しのつかないことをした。 
でも、他にどうすれば良かった? 
どうしてこんなことにーー
## Page 2-9
異邦の地で、 
彼女は独りきりになってしまった。

# Chapter 3
Demon 
## Page 3-1
[ページ種別：青] 
あれから何度、月が満ちて欠けただろうか。 
沢水をすすり、草の根をかじって、 
ルーシーはどうにか生き延びていた。 
あの男を殺してしまった罪悪感と、 
仕方なかったという言い訳と、 
村に戻りたいという気持ちがせめぎ合う。 
## Page 3-2
[ページ種別: 青] 
深い溜息をついたとき 
離れた場所の茂みががさりと揺れた。 
そこから、女が顔を覗かせる。この山奥で 
漆黒の着物をまとい、 
顔には不気味な仮面をつけていた。 
この世のものとは思えない。 
女は、驚くルーシーを一瞥し、 
長々とした溜息をついた。 
## Page 3-3
[ページ種別：青] 
「強い鬼がいると耳にして来てみれば・・・・・・。 
Nothing but a human 
ただの人間ではないですか」 
「ワタシの国の言葉、 喋れるデスか!? 
今、 『おに』 って言いましたよネ!? 
教えてくだサイ! 
『おに』って、なんデスか!?」 
ルーシーは黒い着物の女にすがりついた。 
異国の地で、初めて出会う 
言葉の通じる相手だった。 
## Page 3-4
[ページ種別: 青] 
「鬼とは人ならざるもの。 人を超えた存在。 
だから人は鬼に憧れ、畏怖し、 恐れる」 
自分が鬼であれば、 
他人に助けてもらわずとも生きられた。 
自分を警戒し、畏れる者がいても 
漁村に居続けたのは、ひとりでは 
生きられないと思ったからだ。 
弱い、ただの人間であるからこそ、 
彼女は罪を背負ってしまった。 
## Page 3-5
[ページ種別：青] 
「いっそのこと、 鬼ならよかった・・・・・・」 
「鬼になりたいの?」 
「なれるデスか?」 
「あなたに、鬼となる価値があれば、 
鬼にしてあげる」 
「それはどう証明するデス・・・・・・?」 
「そうね おいちという浪人を殺せば 
あなたを鬼にしてあげましょう」 
女は、ルーシーの瞳をまっすぐに見つめた。 
## Page 3-6
[ページ種別：青] 
ルーシーは、女の言葉に、ふつふつと 
暗い感情が湧き上がるのを感じた。 
もう、ひとり殺している。 
他に寄る辺りない。 
生きるには人を超える。 「ちから」 が 
必要なのだ 
「……やるデス」 
ルーシーの言葉を聞くと女は紅い唇を 
歪めて自らを禍津姫迪子と名乗った。 
## Page 3-7
「アレッ・・・・・・」 
はたと目を覚ますと、 古木のそばに 
ルーシーは倒れていた。 
体を起こすと、気を失う前とは違う、 
見慣れない衣装や装備を身に着けていた。 
細かい石や砂が、 背中の羽から零れ落ちる。 
## Page 3-8
「羽? ワタシ天使になったデスネ!」 
どうやら林檎の賭けには勝ったらしい。 
ハパヤマの姿は見えない。 
ルーシーが死んだと思って退散して 
くれたならいいのだけど。 
## Page 3-9
背中に力を入れると、羽が動いて、 
ふわりと浮かび上がった。 
「ワォ!これでどこへでも行けマス!」 
一鬼とは人ならざるもの。 
人を超えた存在。 
夢の中で会った女の言葉が蘇る。 
天使ではなく、鬼になったということか。 
ルーシーは邑原の空に舞い上がった。
「鬼の力、存分に生かしてやりマスコ! 
でも、まずは論文デース!」
