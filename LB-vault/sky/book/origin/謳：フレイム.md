# Chapter 1
退役の日
## Page 1-1
抜けるような青空の下、地平線まで
不毛の荒野が広がっている。
帝国の西端。 荒野の向こうは
連合王国の領土だ。
エルドラ・マイバッハが西方国境警備隊の
一員となったのは十六の時だった。
それから三十年以上が経ち、 気づけば、
上官も含めエルドラが最年長になっていた。
## Page 1-2
五十歳の誕生日を迎え、 エルドラは
惜しまれながらも退役することになった。 あとは恩給で悠々自適の生活を送るのだ。
この年までつとめあげることができたのは
エルドラひとりだった。
他は皆、激務に耐えかねて逃げ出すか、 任務中の怪我で引退を余儀なくされた。
## Page 1-3
エルドラが警備隊を去る日、
ささやかな宴が催された。
集まった人数を見て、エルドラは自分が
思っていたより慕われていたのだと知った。
それだけではない。
辺境のこの地に、帝都から皇帝の使者が
訪れ、エルドラに「竜火勲章」を授与した。
## Page 1-4
竜火勲章は、指揮官ではない軍人が
受け取れる勲章の中では、
上から二番目の勲章だ。
所持しているだけで、階級にかかわらず
敬礼の対象となる。
思いがけない栄誉にエルドラは恐縮したが、
無事につとめあげることがどれほど勇猛で名誉であるか、若い部下たちが
口々にエルドラを褒めそやした。
## Page 1-5
国境警備隊の任務は多岐にわたる。
荒野を徘徊する蛮族の襲撃を退け 連合王国軍の怪しい動きを牽制し、 禁制品を運ぶ闇商人を縛り上げる。
どれも危険な任務だ。
自分が生き残ったのは運が良かったからだ。
と、エルドラは思う。
地道に仕事を続けてきた。
報われないことも多かったが、
この日、これまでのすべてが
報われたとエルドラは思った。
## Page 1-6
エルドラは長年身につけた胸甲と武器を置き 竜火勲章だけを身につけると、国境警備隊の
駐屯地を後にした。
国境に近い、古都に家を買った。 結局、家族をもつことはなかった。
これからもないだろう。
静かな生活は、
突然の恐ろしい報せに破られた。
## Page 1-7
国境警備隊が神獣と交戦したというのだ。
かつて勤務していた土地の周辺で
神獣が暴れ回り、 大きな被害が出たという。
かつての部下たちの身を案じ、
エルドラは国境へと急いだ。
そこで見たものは、激戦の痕跡だった。
地をえぐる砲弾痕と、大地に墜ちた巨大な鯨のような神獣の骸。
かつての部下たちが、 神獣を殺したのだ。
## Page 1-8
兵士が得られる勲章で、 竜火勲章よりも
上の勲章はただひとつしかない。
「神獣殺し」 の勲章だ。
かつての部下たちは、エルドラに
できなかったことをやってのけた。
今や国境警備隊の中心はエルドラではなく、 神獣を倒した若い兵士たちだった。
## Page 1-9
エルドラは自分の持つ竜火勲章が
色褪せた気がした。
嫉妬だ。
エルドラの胸中に激しい嫉妬がわきあがる。
任期中に、 神獣があらわれていれば、
神獣殺しの名誉を手に入れることが
できたものを……。
勝利を喜ぶ兵士たちに、 エルドラは
加わることができなかった。

# Chapter 2
嫉妬の火
## Page 2-1
エルドラは白の女神の神殿で、
祈りを捧げていた。
部下たちが神獣を倒したと知った時から
心がざわめいていた。
良からぬ感情がこみあげる。
また――。
神獣があらわれてくれないだろうか。
## Page 2-2
自分も神獣との戦いに加わりたい。
エルドラは、自分の指揮で 部下と共に神獣を倒すのだ。
竜火勲章と神獣殺しの両方を得た英雄!
そう呼ばれる様子を夢想しながら、 嫉妬の感情をエルドラはもてあましていた。
## Page 2-3
国境警備隊が、 神獣により壊滅した。
神獣は死んでいなかったのだ。
再び動き出した神獣によって
国境警備隊は蹂躙された。
その報せを聞くなり、 エルドラは国境へ向かった。
## Page 2-4
既に神獣の姿はなかった。
神獣がまき散らした瓦礫の中に、
火と毒に焼かれた部下たちの屍が転がっていた。
## Page 2-5
私のせいだ――。
私の、良からぬ願いを、
白の女神は聞き届けてしまった。
## Page 2-6
瓦礫と死体の間に、
瑞々しく輝く林檎が落ちていた。
これが噂に聞く「グレゴールの林檎」だ、と
エルドラは直感した。
## Page 2-7
林檎をかじれば、資格のある者は
天使になる。その資格がなければ死ぬ。
――そう聞いたことがある。
エルドラは林檎をかじった。

# Chapter 3
竜の約束
## Page 3-1
[ページ種別：青]
わたしは、むかし、ちいさなトカゲだった。
赤い素敵な宝石を、虫と間違えて飲み込んで
不思議な力で、強い竜になった。
## Page 3-2
[ページ種別：青]
わたしは仲良くなった人間と一緒に、
悪いやつらをやっつけた。
最初の相棒の人間は、
名前も忘れてしまったけど
それはもう、いいコンビだった。
でも人間はとても寿命が短いので、
すぐに年老いて死んでしまう。
私だけがすくすく大きくなった。
## Page 3-3
[ページ種別：青]
わたしの暮らす場所に、
人間が集まってきて、国ができた。
強く、勇敢な王様がわたしの相棒になった。
王様もやがて年老いて死んでしまった。
「竜よ。 私が死んでも、
この国を守り続けてくれ……」
それが王様の最後の言葉だった。
わかったよ。
わたしは約束した。
多分、その王様のことが好きだったのだ。
## Page 3-4
[ページ種別：青]
わたしは何度も相棒を変えながら、
神獣や、軍隊や、 反乱者から、 災害から、 国を守り続けた。
やがて、わたしは大きくなりすぎた。
年老いて、身体を動かすのも
おっくうになってしまった。
ある日、 わたしのお腹から 小さな赤い宝石が出てきた。
わたしが大昔に呑み込んだ、
あの宝石のかけらだ。
## Page 3-5
[ページ種別：青]
わたしは、赤い宝石のかけらを
相棒の額に埋め込んであげた。
大昔のわたしが宝石の力で
強い竜になったように
相棒も宝石の力で竜の力を身につけた
そして、相棒はひとりでも
神獣と戦うようになり、寿命も長くなった。
わたしは寂しくなくなった。
## Page 3-6
[ページ種別：青]
相棒がある日、こう言った。
「竜よ、もう私は十分に生きた」
そして相棒は、私に命を捧げた。
わたしは相棒からもらった生命で
生き続けた。 古い約束を守るために。
わたしはいつしか
古竜（エルダードラゴン）と
呼ばれるようになっていた。
## Page 3-7
[ページ種別：青]
相棒だけではなく、いろんな人間が わたしに生命を捧げ、わたしは生き続けた。
神殿の奥の、 居心地のよいねぐらで
寝そべりながら、 昔のことを考える時間が
多くなった。
たまに人間が生命を捧げるのを忘れることが
あったので、仕方なくそのあたりの人間から
生命をもらった。 すると、 また人間は
生命を捧げてくれるようになった。
わたしはどれだけ生きたのだろう?
いつまで生きるのだろう?
## Page 3-8
[ページ種別：青]
ある日。
相棒が連れてきた小さな娘がわたしの生命を終わらせた。
そうしてはじめて、わたしは人間の敵になっていたことに気づいた。
## Page 3-9
[ページ種別：青]
わたしにとって生きるとは
わたしはただ
大昔の、あの約束を守ること。
約束を守りたかっただけなのに・・・
## Page 3-10
どれくらい時間が経ったのだろう。 エルドラは瓦礫の中で目覚めた。 長い夢を見ていた気がする。
生き延びたようだ。
若返ったように身体が軽い。 身体の芯から力が湧き出す。
額に手を触れると、
固い石の感覚があった。
夢で見た、あの赤い宝石に違いない。
## Page 3-11
背中に意識をやると、 折り畳まれた翼が
広がった。 天使の白い翼ではない。
あの竜の翼だ。
あの林檎は、夢で見た竜の力で
私に教えと言うのだ。
## Page 3-12
エルドラは竜の翼をはためかせると、 青い空の彼方へ駆け上っていった。

Fin.
