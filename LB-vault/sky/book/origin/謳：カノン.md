# Chapter 1
私の故郷
## Page 1-1
息を吹き込むたびに、 楽器が歌う。
スーザフォンは私の半身だ。
故郷の劇場で帝立交響楽団の
団員として演奏するのは私の夢だった。
夢が叶ったのは、
親友のティーナのおかげ。
彼女の言葉があったから、
このステージに立つことができた。
## Page 1-2
私の両親は名の知れた音楽家で、
私もまた、 音楽の道に進むことを
期待されて育った。
音楽を奏でることは楽しい。
でも、それを仕事にすることは別だ。
毎日、朝から晩まで 休みなく行われるレッスン。 有形無形のプレッシャー。
もうやめてしまいたい。
弱音を吐く度に、 両親は言った。
「音楽をやめたら、
あなたに何が残るの?」
## Page 1-3
そう。
だから、泣きながらでも
私には音楽しかない。
練習するしかなかった。
そんなとき一
音楽のことしか知らない。
他にできることなんてない。
私の前にティーナが現れた。
## Page 1-4
「素敵な音! あなたは楽器を
吹くんじゃなくて、歌わせるのね!」
ティーナはそう言ってくれた。
私の音楽が届いたんだ······。 それから、 練習が苦ではなくなった。
ティーナの言葉が勇気をくれたから。
帝都の音楽学校に進学できたのも、 帝立交響楽団の一員になれたのも、 ティーナと出会えたおかげだ。
ティーナとの出会いが、
私の演奏を作り上げ、支えている。
## Page 1-5
故郷を離れ、
帝都で生活するようになってからも、 ティーナとはずっと文通を続けていた。
だから、故郷の街ティーナがいる街で
演奏できることになって、 胸が躍った。
ティーナに、私の演奏を聞いてもらえる!
ティーナには、
番良い席のチケットを送った。 再会が楽しみでたまらない。
## Page 1-6
演奏が終わり、会場が拍手に包まれる。
私は観客の中にティーナの姿を探す。 いた! ティーナは立ち上がり、
足早に会場から出ていこうとしていた。
「ティーナ!」
私は袖に引っ込むと楽器を置き、
ティーナを追いかけた。
劇場の出口でようやくティーナに追いつく。
「ティーナ、 来てくれてありがとう!」
ティーナは目を丸くしたまま。
無言で私を見つめていた。
## Page 1-7
「晩ご飯どうする? またあの店で一
私の言葉をさえぎり、 ティーナは言った。
「アンタ、今でも
間抜けな演奏をしてるのね」
「・・・・・・え?」
何を言われたのか分からなかった。
言葉は分かるけど、意味が分からない。
## Page 1-8
「ごめん。変にがんばりすぎちゃったかな。
またティーナに喜んでほしくて・・・・・・」
「もう、お世辞を言うのはやめる。
つまらない演奏だった」
ティーナは、これまで見たことないような
嘲りの表情を浮かべていた。
## Page 1-9
ティーナ
じゃあね。 と吐き捨て、彼女は去っていく。
追いかけなきゃ。
頭ではそう思うのに、体が震えて動けない。
どうして?
親友だと思ってたのは、私だけだったの? 彼女との想い出が、 頭の中をぐるぐる回る。
どうして、こんなことを
言われなきゃならないの?
こんなことになるなら、
会わなければよかった。

# Chapter 2
私の後悔
## Page 2-1
どんなに落ち込んでも、明日はやってくる。
公演の準備をしていると、劇場主が やってきて、公演は中止だとわめいた。
「何かあったんですか?」
「神獣が近くに現れた!
荷物をまとめて、 すぐに避難するんだ!」
もう一度、 ティーナに会いたかったけど、
それどころではなかった。
## Page 2-2
帝都に戻ってしばらくすると、
故郷の街は、神獣によって
壊滅的な被害が出たという噂が伝わってきた。
両親はもう故郷には暮らしていないが、
あの街にはティーナがいる。
安否を尋ねる手紙を出しても、
「ティーナ・・・・・・」
あのとき、
なぜ追いかけなかったのだろう。
「つまらない」と言った意味を
なぜ聞かなかったのだろう。
返事は戻ってこなかった。
## Page 2-3
気づけばあの夜のことばかり
考えている私がいた。
最悪のことばかり考えてしまう。
後悔で、胸がきりきり痛む。
演奏にも身が入らず、
私の楽器は、もう歌えなくなってしまった。
もう二度と会えなかったらどうしよう。
## Page 2-4
私は休みをもらって、 故郷の街に戻った。
街は瓦礫と土砂に埋もれ、
記憶の中の街とかけ離れた
惨状が広がっていた。
ティーナとよく行った店も、
ティーナと話をした公園、
ティーナの家も瓦礫の下。
ティーナを探し歩いても、
行方を知る人はみつからなかった。
## Page 2-5
歩き疲れた時、白いテントが見えた。
仮設の徴兵事務所だ。
家や仕事を失った者を
軍に引き入れようというのだ。
ティーナが訪れていないか、
私は聞いてみることにした。
## Page 2-6
「徴兵志願者の個人情報は お伝えできませんが・・・・・・」
白い帽子の徴兵官はそう言うと、
虹色に輝く林檎を見せた。
「あなたの言う年格好の女性がひとり
天使隊に志願しました。
結果は、残念でしたが」
## Page 2-7
私は息を飲んだ。 聞いたことがある。
かじれば、天使になれるという林檎だが、 運が悪ければ・・・・・・死ぬ。
「なぜ......?」
林檎をかじったのはティーナだろうか?
そんな思い切ったことをする娘じゃないと 思うけど今のティーナのことは
全然分からない。
私を支えてきた言葉は嘘だったの? もう、何も分からない。
ティーナのことも演奏のことも。
## Page 2-8
今のティーナは、 私の知らないティーナだ。
知らないティーナは、
この林檎をかじったのかもしれない。
だから私も一
受け取った林檎をかじってしまった
## Page 2-9
[ページ種別：青]
白い病院の白い病室のドアの前に立つ。
なんだかどきどきしてきたけど、
会うのは親友の千夏だもん。
平気平気。
## Page 2-10
[ページ種別：青]
「病院に行くことになったんだ」って、
明るく言ってたのが先週のこと。
吹奏楽部での席はいつも隣。
急に入院が決まって、
きっと本人もびっくりしてるだろう
ミスったり怒られたりして落ち込む私を、
千夏はいつも励ましてくれた。
だから今度は私が励ます番だ。
## Page 2-11
[ページ種別：青]
「千夏。お見舞いにきたよ」
「何しにきたの?
わたし、見世物じゃないんだけど」
それは、
今まで聞いたことがないくらい。
厳しい言葉だった。
「帰って。 二度と来ないで」
絶句したままでいる私に、
千夏はさらに追い打ちをかけた。
お見舞いの花も渡せないまま、 私は逃げるように病室を後にした

# Chapter 3
私の親友
## Page 3-1
[ページ種別：青]
あの日から千夏は会ってくれない。
電話 >無視。
部活でやった演奏会の動画を送ったけど、
やっと既読がついたと思ったら
ブロックされてしまった。
悲しくて、やるせなくて。
それでも明日はやってくる。
大会が近くなったこともあって忙しく、
私の意識は徐々に千夏から離れていった。
## Page 3-2
[ページ種別：青]
吹奏楽の大会は無事に入賞できた。
目の前の課題がなくなってようやく
千夏のことを思い出した。
今なら、千夏も落ち着いてるだろう。
前みたいに話ができるかもしれない。
でも――
私は二度と
夏に会うことができなかった。
## Page 3-3
[ページ種別：青]
腫れた目をした千夏ママに促されて
家に上がらせてもらうと、
黒い額縁の中に千夏はいた。
## Page 3-4
[ページ種別：青]
私はぼんやりと
千夏の写真のそばに、
千夏ママが話すのを眺めていた
見覚えのある音楽プレイヤーがあった。
ハンマーで頭を殴られたみたいに
目の前の景色が揺れて、
話す内容が頭に入ってこない。
イヤホンをひとつずつして
よく、千夏と、同じ曲を聴いた。
## Page 3-5
[ページ種別：青]
半ば無意識に、再生ボタンを押す。
小さな液晶の中で、
吹奏楽部の演奏が始まった。
私が送った動画だ。
私のソロが始まる。
「千夏はずっと、それを聞いていたの」
熱いものが頬を伝う。
千夏ママの言葉で、
涙があふれて止まらなくなった。
## Page 3-6
[ページ種別：青]
あのとき、お見舞いに行った私に
千夏があんな態度を取ったのは、 きっと私を悲しませないためだったんだ。
ちょっとしたことですぐに落ち込む私を、
千夏なりに心配してくれていたからなんだ。
千夏はやっぱりとても優しくて、
不器用な演技で私を思いやってくれた。
今、無性に楽器を鳴らしたい。
親友と言ってくれた千夏を忘れないために、
奏で続けたい。
## Page 3-7
目を開けると、歪んだ視界が広がった。
まなじり
それからすぐに、 眺から涙が落ちて 色鮮やかな景色が飛び込んでくる。
「ティーナ。
あなたもそうだったの?」
「つまらない演奏だった」
私が知ってるティーナは、
簡単にあんなことを言う人じゃない。
きっと千夏みたいに、事情があったんだ。 それが本心だとしても、嘘だとしても。 だってあなたは、私の親友でしょ?
## Page 3-8
手に入れた翼を広げ、 私は飛び立つ。
ティーナがどうなったのかは分からない。
でも、この大空の下のどこかに、
ティーナがいる気がする。
不器用で、 優しいティーナ。 彼女に伝えたい想いがある。 彼女のために奏でたい音がある。
私は抱えていた楽器を構え直し、 大きく息を吹き込んだ。

Fin.
