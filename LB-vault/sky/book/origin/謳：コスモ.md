# Chapter 1
広い世界
## Page 1-1
僕たちが女学生だったころ、
真夜中に顔を腫らしたディピカが、 やってきたことがあった。
「彼氏に殴られたの。 生意気だって」
このクソ田舎では、いつもこうだ。
偉いのはいつも男、
それですべてが罷り通る。
## Page 1-2
「いつか絶対、ここを出ていこう。
広い世界を見に行くんだ。 ねえ、ディピカ。 約束しよう」
握り返してくれた彼女の手が、 とても温かったのを覚えてる。
そして、僕らはクソ田舎を抜け出した。
## Page 1-3
灰色の空の下、埃っぽい空気の中、
歩兵装備に身を包んだ僕とディピカは、 陣地の真ん中で見張りの任務についている。
見たことのない場所で、
見たことのないものを見たくて、 僕らは、帝国陸軍へ入った。
入隊すれば、国の金で世界中へ行ける。
そう、徴募官は言っていた。
## Page 1-4
雪がたくさん降る国、
からからに乾いた砂漠が広がる国。
機械や工場がたくさんある最先端の国、
御伽噺（おとぎばなし）の遺跡が残る遠い国。
連れていかれたのは、
確かに見たことのない場所だったけど。 どこも地獄だった。
僕とディピカは帝国南部の
少数民族出身だ。
どこでも公然と差別され、 常に激戦地へ送られた。
僕たちは知らない土地で、
知らない大人のために、 命がけで陣地を確保し続けた。
## Page 1-5
辛くて、怖くて、悲しくて、
どうにかなってしまいそうな日々。
それでも、
ディピカと一緒だったから
耐えられた。
戦争が終わったらお洒落をしよう。美味しいものをたくさん食べよう。
ふたりでいれば夢を語れた。
ディピカと一緒なら 希望を失わずにいられた。
## Page 1-6
何が、 運命を分けたのか分からない。
隣にいたディピカは吹き飛ばされ、
突然の轟音（ごうおん）と閃光が炸裂し、
気づけば僕だけが立っていて――
血まみれになっていた。
## Page 1-7
僕はディピカに駆け寄った。
「ディピカ!」
ディピカの胴には、大きな穴が開いていた。
「プリヤンカ」
彼女は僕の名前を呼んだ。
一目で分かった。
ディピカの傷は、助かるような傷じゃない。
それでも・・・・・
「待ってて、 必ず助けるから」

# Chapter 2
新天地
## Page 2-1
重傷を負ったディピカを救う方法。 たったひとつ心当たりがあった。
戦死した上官が持っていた。
グレゴールの林檎だ。
天使部隊への志願者を出せと言われ、
持ち込まれたものだが、全員が断っていた。
当然だ、死ぬかもしれないのに、
志願できるわけがない。
国家に対する忠誠心は
とっくに失われていたから。
## Page 2-2
砲撃に右往左往する兵士たちに紛れ、
上官の遺品の中から林檎を拾い上げると、 ディピカの元へとって返した。
「ディピカ、食べて!」
でも。 そうはならなかった。
林檎を無理矢理ディピカの口に入れる。
林檎をかじったディピカは身体が
砂のように崩れだした。
このまま何もしなければ、 彼女は死ぬ 一か八か。 天使になれば、
ディピカは生き返るかもしれない。
## Page 2-3
「そんな……」
やがてディピカは塵となって風に吹かれ、消えてしまった。
僕のせいだ。
## Page 2-4
翌日。
ディピカが塵となって消えた場所に
僕はやってきた。
ひとりで見張りをするために。
そこには、グレゴールの林檎が
転がっていた。
彼女がかじった跡は、ない。
僕は林檎を拾い上げた。 土を払う。
## Page 2-5
ディピカを殺して、 元の形に戻ったのか。
そう思ったら、胸がむかむかしてきた。
かけがえのない親友を失った僕は、
もうここで戦う理由がない。
もう、見たことのない国へ行って、
見たことのないものを見る必要はない。 ここに存在する意味がない。
僕は、思いきり林檎をかじった。
## Page 2-6
[ページ種別：青]
「おめでとう! 手術は成功した」
目を覚ますと、医者が満足げに笑っていた。
まるでスポットライトのような、
天井の白いライトが刺すように眩しい。
「君は太陽系外へと旅立つ初の人類となる。
英雄の誕生だ!」
ああ、そうだった。
僕は、ライフライトリソース社の
人体改造を受けたのだ。
## Page 2-7
[ページ種別：青]
地球は今、行き詰まっている。
僕は人類を救うため、新天地を探して
旅に出るのだ。
100万人にひとりのエリート。 厳しい選抜試験をくぐり抜け、
深宇宙探査のための
宇宙飛行士に抜擢された僕は、 皆にそう呼ばれた。
6ヵ月後、
有人深宇宙探査計画が中止になり、 機械知性だけで行われることになった。
僕は 「元宇宙飛行士」になった。 一度も、宇宙に出ていないのに。

# Chapter 3
もっと広い世界
## Page 3-1
[ページ種別：青]
「残念だったね。 元気出してよ」
モニター越しに、友達が話しかけてくる。
彼女も、かつて一緒に
宇宙飛行士を目指した仲間だ。
「新天地（フロンティア）は宇宙だけじゃないよ。
私、事故のせいで宇宙飛行士を諦めたけど、
「方舟」のおかげで
今はなにもかもが自由。
ここにこそ、無限の可能性があるわ」
## Page 3-2
[ページ種別：青]
訓練中の事故が原因で
重い障害が残った彼女は、
ネットワーク上の仮想世界に意識を移す実験に参加していた。
元々優秀な彼女だから、きっとさまざまな成果を
出しているのだろう。
「あなたも 「方舟」 にいらっしゃいよ」
「そうだね、考えとく。 またね」
僕は笑って、通信を切った。
彼女が言うことは、きっと正しい。
だけど。
## Page 3-3
[ページ種別：青]
僕は宇宙服を着て、無人の格納庫に
侵入していた。 発射台に収まっているのは
赤い軌道機（オービター）だ。
深宇宙探査計画が中止になってから、
僕は改めて考えた。
どうして宇宙飛行士を希望したのかって。
答えは簡単。
見たことのない世界を見たかったからだ。
だから、機械知性たちの船に密航する。
僕は手動で軌道機のハッチを開けた。
## Page 3-4
目を開けると、灰色の空が見えた。
厚い雲の切れ間から光が差している。
奇妙な夢だった。
見たことも想像したこともない世界。
けれど、圧倒的な現実感に満ちていた。 あの世界が、 本当に存在するみたいに。
「なんだ、 あれは……夢？」
いや。
きっとあの夢の世界は、 どこかに実在する。 そんな確信が、僕にはあった。
## Page 3-5
「羽……!？」
気付くと、僕の背中に翼が生えていた。
左右違う、不揃いな羽が
僕の意志でばさばさと動く。
ああ、そうか。
僕は生き残ってしまったんだ。
ディピカとは違って。
## Page 3-6
けれど、不思議と絶望感はなかった。
夢の中の僕が、
簡単に夢を諦めなかったからかもしれない。
いつの間にか雲の切れ間が広がり
青い空が顔を覗かせていた。
「ここを出ていこう。
広い世界を見に行くんだ。
ねえ、ディピカ」
君の分まで、見たことのないものを見ろよ。
僕は大きく息を吸って、
不揃いな翼をはためかせた。

Fin.
