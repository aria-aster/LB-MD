# Chapter 1
餞別
## Page 1-1
遠くで雷鳴が轟いた。
ホテルの一室。 バルコニーの窓は
開け放たれ、カーテンが揺れている。
雨の匂いがする。
ゆったりと椅子に腰掛けた中年の女が、
酒の入ったグラスを傾けた。
稲妻が室内を照らす。
女の指で、銀色の指輪が輝いた。
飢えた獣のように空が唸っている。 女が気怠い視線を窓に向けると、 雷光に人影が浮かび上がった。
## Page 1-2
「ニキータかい?」
女が問うと、バルコニーの人影が
無言で何かを放り投げた。 床に落ちて
湿った音を立てる。
古傷だらけの無骨な男の手だ。
指には女と同じ指輪がはめられている。
女は物怖じせず、冷たい手を拾い上げると
愛おしげに撫でた。
ミゲロを殺ったんだね」
## Page 1-3
「この一ヶ月は、 幸せだったよ」
ミゲロの手を握り微笑んだ。
「ミゲロとふたりでアンタから逃げ回って、 色んな所に行って…………いい思い出ができた」 感謝してるよと、女は目元を緩ませる。
「ミゲロはよく言ってたんだ。
ニキータが一番出来のいい生徒だったって。 先生を超えたってわけだ」
ニキータはひとつ動かさず、 女の言葉を聞いていた。
## Page 1-4
「わたしもミゲロも、
殺されても仕方のない人生を送ってきた。
いまさら命乞いなんてしやしない」
「むしろ、 アンタでよかった。 ニキータ」 
答えぬニキータに、女は小さく苦笑した。
「最後にアンタの顔を見られて嬉しいよ」
女はニキータを刺激しないよう
ゆっくりと机の上の紙袋を持ち上げた。
## Page 1-5
「ほら、これを持っていきな 差し出された紙袋をちらと見て
ニキータは女の顔を見返した。
「わたしたちからの最後の贈り物だ。
きっと、アンタの役に立つ」
ニキータが紙袋を受け取ると、
女は血と、雨の匂いのする少女の身体を
そっと抱き締める。
「さよなら。 ニキータ」
## Page 1-6
始まりの一粒がバルコニーを叩いた。
雨粒はやがて激しく降りしきる豪雨となり、
全ての音をかき消していく。
「…………」
頬にかかった温かい血を ニキータは無造作に拭った。
その手には血の滴る短剣が
握り締められている。
血溜まりが広がる。
事切れた女の姿を、
感情のない冷たい双降が見下ろした。
## Page 1-7
女は笑っていた。
生前と同じように、 ミゲロの手を握り、 幸せそうな笑顔を浮かべていた。
「―――なぜ」
ニキータの感情が、わずかに波立つ。
意味のある感情がわき上がる前に
けたたましくホテルの電話のベルが鳴った。
ニキータは小さく頭を振り、
受話器を取り上げた。

# Chapter 2
火膠
## Page 2-1
激しく雨が降っていた。
噎せ返るような血の臭いに
雨のにおいが絡みつく。
「任務完了」
死体の転がるホテルの一室で、
ニキータが無感情な声で囁く。
わずかな間を置いて
握り締めた受話器の向こうから
くぐもった声が返ってくる。
「では、最後の命令だ」
## Page 2-2
ニキータは静かに受話器を置いた。
命令を胸の内で反芻しながら、
血に濡れた短剣を見下ろす。
「自壊しろ。
これで“猟犬”部隊はこの世から消える」
ニキータは最後の“猟犬”だ。 命令に反して逃げたところで、
ニキータを追う"犬はいない。
だが――ニキータは短剣の切っ先を
自分の喉にひたりと当てた。
## Page 2-3
ニキータは昔から感情に乏しい子供だった。
笑うことも泣くこともない子供を、 親は気味が悪いと捨てた。
他人の痛みが分からなかった。 同情心など持ち合わせていなかった。 良心がどこにあるのかも知らない。
暗殺者の才能があると見出されたときも
そんなモノかと思うだけ。
自分には何かが欠けている。
それが分かっても、 ニキータは
何とも思わなかった。
## Page 2-4
誰を殺しても何も感じなかった。 見知らぬ他人も、部隊の仲間も。
ミゲロたちを殺す機会は何度でもあった。
それでもこの一ヶ月、 ニキータは
ミゲロとその妻は仲間であり、師であり、 育ての親だった。 彼らを殺したくなかったの だろうか? それも分からない。
彼らをただ監視するだけだった。
ただひとつ確かなことは、
ミゲロを殺しても、その妻を殺しても やはり何も感じなかったということだけだ。
## Page 2-5
自らの首に切っ先を突きつけるニキータは、
不意に呼ばれた気がして
視線を巡らせた。
ミゲロの妻に渡された紙袋が目に入った。
何が入っているのか確かめてから死んでも
遅くはないだろう。
ニキータは短剣を置き、 紙袋を開けた。
中には虹色の林檎と。
メッセージカードが入っていた。
"愛するニキータへ"
## Page 2-6
この林檎が何か、 ニキータは知っていた。
天使になるための林檎。
多くの者が天使になれずに命を落とす。 死の林檎でもあった。
天使は、神の違い。
愛情深く、我らをお守りくださる。 ミゲロがそう言っていた覚えがある。
ニキータは林檎をまじまじと見つめた。 これを食べて天使になれば、愛が何か
分かるのだろうか。
失敗しても死ぬだけだ。
ニキータは林檎をかじった。

[ページ種別：青]
赤いロープが翻る。
フードを目深に被った怪しげな魔術師が
薄ら笑いを浮かべて彼女に言った。
「力を授けよう。 だが、感情と引き換えた それでいい、と彼女は同髪を入れず答えた。
彼女には故郷を守るための力が必要だった。 非情に戦い抜く強さが必要だった。
そのためには感情などいうない。
情を捧げることで力が手に入るなら、 いくらだって差し出す覚悟はできている。
## Page 2-8
[ページ種別：青]
彼女の覚悟の言葉を聞いて
赤いローブの魔術師は喋った。
「汝が名はラプンツェル。 鋼の肉体持つ無敵の魔法戦車なり
汝の敵すべてを滅ぼす力を授けよう。
誰もお前を止められない」
バラバラに引き裂かれるような痛みを
最後に、彼女は何も恐れず、
何も感じない、無敵の存在となった。

# Chapter 3
再生
## Page 3-1
[ページ種別：青]
"それ"は戦場を課する。
チャリオット
土煙を巻き上げて、疾駆する戦車
長い鋼の髪をなびかせた巨人ラプンツェルは、
全ての敵を薙ぎ払う。
敵も味方も存在しない。
故郷を守りたいという彼女の願いと尊厳は
とうの昔に彼女自身が踏み潰した。
兵器に感情など必要ない。
ただ命じられるがままに、 戦場を駆け巡る。
誰にも、彼女を止められない
## Page 3-2
[ページ種別：青]
ある戦場で、 赤い薔薇の紋章が刻まれた
巨大な魔法戦車と対峙した。
自分と同じ兵器に遭遇したのは初めて
だったが恐怖はなかった。 高揚しなかった。
教え、滅ぼせ、殲滅せよ。
ぶつかり、傷つき、破壊されて
うしてようやく、彼女は止まった。
壊れた彼女を振り返る者はいない。
ただ、降り注ぐ冷たい雨だけが
彼女の死を哀れんでいた。
## Page 3-3
「っは!」
まるで水中から顔を出したように息をして、 ニキータは跳ね起きた。
パクパクと心臓が鳴っている。 体中に嫌な汗を掻いていた。
ニキータは両手を見下ろした。 確かに“私”は死んだはずだ。 戦場で、破壊されて一
いや、とニキータは頭を振った。
この雨音のせいだ。
夢と現実が混ざり合って混乱している。
## Page 3-4
強烈な血の臭いが鼻をついた。 女の死体と、血に濡れた短剣。
(ああ…………そうだ。 ここはホテルだ。
私は、死のうとして、林檎をかじって..............)
ニキータは両手で顔を覆った。
結局、 生き延びたのか。
生き延びてしまったのか
## Page 3-5
羽化したばかりの軋む身体を動かして
ニキータは立ち上がった。
大きな姿見に人影が映り込む。
轟音と共に雷が室内を白く染め上げた。
ニキータの背に生えた白銀の翼が
鈍く光を反射する。
ニキータは悲鳴を呑み込んだ。
彼女の背に生えた翼は、触れるもの
すべてを切り裂く刃でできていた。
## Page 3-6
思わず目を背けた視線の先には、 血溜まりに沈む女の姿があった。
女が固く握った、 その手の先に、
殺した男（ミグロ）の姿が浮かんだ。
## Page 3-7
「ああ…………」
ニキータは思わず自分の身体を抱き締めた。
最後にそっと優しく抱き締めてくれた。
女の温もりを思い出した。
## Page 3-8
「ああああああ!」
何だこの胸の痛みは一 どうして涙が流れる。
荒れ狂うような感情に彼女は喘いだ。
夢の中で感情を失った時のような
いや、それよりも激しい痛みに鳴咽を漏らす。
心の奥底から湧き上がる
痛みを理解できないまま。
暗殺者だった天使は雷雨のただ中へ
飛び込んでいった。
