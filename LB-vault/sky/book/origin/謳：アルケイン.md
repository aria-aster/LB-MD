身近な冒険は本のページをめくること。
物語の中の冒険譚に想いを馳せること
「夢」でしかなかった。
それ以上は決して許されなかった。

父から莫大な遺産を継承したイェニーは、
私財を惜しみなく注ぎ込み
オーパーツの美術館を作り上げたのだ。
胸高鳴り心踊る冒険ができないなら、

どんなものでも美味しく食べられるという
これは殺人鬼（カトラリー）の家で見つかったものだ。
怪物すら魅了する音を奏でる虹色の円盤。
これはある国の宮殿に隠されていた。
そしてまるで生きているような、 人間そっくりの可愛らしい人形。
――すべて、イェニーのもの！
## Page 1-7
「ああ、信じられない。 信じたくない。 これがすべて……明日には人の手に
渡ってしまうなんて」
イェニーの手は力なく落ちた。 夢を見ていた目は、
いつの間にか現実を映している。
手元にあるのは借用書だった。 連なる名前を見ると自然と手に力が入る。
その時は刻一刻と近づいている。
「欲張ったわたくしが間抜けで
……世間知らずでしたわ」
冒険心は誰にも止められない。
イェニーは冒険に出ようとしていたのだ。 止められても構わない。
父がいない今ならできるかもしれない、と。
## Page 1-8
イェニーは勇気を出して探検隊を結成し、 出資を募った。
ついに夢を叶えられる！
だがイェニーを待ち受けていたものは
宝探しの大冒険ではなく、裏切りだった。

気づけば、到底返済など不可能なほどの
借金を背負わされていた。

# Chapter 3
冒険はこれからだ
## Page 3-1
「何が書いてあるんですのー！」
目覚めたイェニーは悲痛な叫びを上げた。 見下ろした手に奇怪な本はない。
「今のは夢だったのかしら……。 まったく、いいところで
目覚めないでくださいまし！」
怒りに拳を握りながら立ち上がる。
どうやら知らぬ間に寝転がっていたらしい。
イェニーは林檎を展示台に置き、
スカートの埃をぱっぱと払う。
すると、ひらりと一枚の羽が舞い落ちた。
## Page 3-2
「……って、あら？ あらまあ……」
落ちた羽を拾い上げ、
イェニーはやっと気がついた。
暗かったはずの窓の外には陽が昇り、 林檎をかじったはずのイェニーには
天使の羽が生えている。
「わたくし、死んでない!?」
イェニーは天使になっていた。
夢で見た、あの冒険家の女性の姿になって。
## Page 3-3
夢の中の女性は、イェニーがやりたかった ことをしていた。 コレクターとして
世界中を冒険していたのだ。 わたくしも負けない冒険がしたい。
ドンッ、ドン！ ドン！ ふいに荒々しいノック音がした。
「世界には、 まだまだすんごいお宝、 オーパーツがあるはずですわ!
かすかに話し声も聞こえる。 借金のカタにオーパーツをせしめに
来た債権者たちだろう。
こんなところで死んでたまるかって
ことですわー！」
## Page 3-4
イェニーは特別展示室から顔を出し、 展示された数々のオーパーツを見つめる。
父から譲り受けた遺産に物を言わせ 様々な方法で買いあさったオーパーツ。 どれも魅惑的で、輝かしい宝物。
けれどきっと、自分の足で探し求め、 自分の手で掴みとったオーパーツのほうが
よっぽど価値があるものだろう。
## Page 3-5
イェニーは顔中に笑みを浮かべ胸を張る。
「ここにあるすべてのものより、もーっと
素敵なオーパーツを見つけてやりますわ！」
## Page 3-6
決意はすぐに 「夢」 となり、
目の前に広がる冒険の地図となる。
「まずは、あの万物の書からですわ！
待っていてくださいまし！」
両手を合わせ陶酔するイェニーは、 希望に満ちた目で空を見上げた。 そして窓を大きく開き、
たっぷり装飾された翼を広げる。
かくして。
イェニーの冒険は始まった。
