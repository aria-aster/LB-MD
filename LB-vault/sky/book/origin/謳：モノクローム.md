# Chapter 1
つまらない絵
## Page 1-1
目を開けると、
部屋に朝陽が差し込んでいた。
見飽きた天井が視界に広がっている。
どうにか首を動かし、
そばの机に置かれた筆と絵具を眺める。
私の商売道具だ。
隣に積まれているのは、依頼の手紙の束。
眠る前よりも増えているのは、
身の回りの手伝いを頼んでいる人の仕業だ。
見えないところに置いてと言ったのに······ もう肖像画の依頼は受けられないのだから。
## Page 1-2
私、スミエ・アジムは肖像画家だ。
正しくは肖像画家だった。
全身の力を使い。
時間をかけてどうにか体を起こす。
やっとの思いで筆を手に取り、
画帳に向かったけれど、
手が震え、思うような線が描けない。
少しずつ全身の筋肉が衰えていく病気だ。
最終的には呼吸もできなくなり死に至る。
この病に、治療法はない
## Page 1-3
死ぬよりも、絵が描けなくなることのほうが
つらかった。
私はこれまで描いてきた絵のことを
思い、激しく後悔した。
なんてつまらないものばかり
描いてきたのだろう。
## Page 1-4
頼まれて描くことが悪いわけじゃない。
絵を描くのは得意だったし、好きだった。 喜んでもらえるのも嬉しかった。
でも、私が本当に
描きたかったものはなんだろう?
けれどいつの間にか、
私は絵を 「金を得る手段」 にしてしまった。
病気になってから考えるのは、 そのことばかりだった。
## Page 1-5
病気が進行してからは、
食事もままならない。
おっくう
近頃は水を飲むのも億劫だ。
それでも喉は渇くし、腹も減る。
みずみず
林檎が食べたいな。
爽やかな香り。
瑞々しく、甘酸っぱい果汁が喉を潤す。
美味しい林檎が食べたい。
私はもう一度筆をとった。
## Page 1-6
震える手で線を引く。
久しぷりに筆が乗り、 思い通りに描けた。
まるで誰かが、私の手を取ったみたいに。
パレットの上で固まった水彩絵の具を
水で溶き、心のままに、色をつける。
気付くと、紙の上に林檎が乗っていた。
ひゅ
比喩ではない。
虹色の林檎が、実際に目の前にあった。
## Page 1-7
幻覚だろうか。
林檎に触れ、持ち上げてみる。
確かな重さを感じる。
私が描いた林檎は、
どんな味がするんだろう。
私はその林檎に、
ロをつけた。

# Chapter 3
藥含心食
## Page 3-1
[ページ種別：青]
虎が私ににじり寄る。
その口は老人の血に濡れている。
私が描いた絵であっても、
私の言うことを
聞いてくれるわけではない。
血塗れで床に臥す老人を 恨めしげに睨みつける。
自分が描いた絵に殺されるなんて、
一体どこの洒落本だろう?
ぎゅっと拳を握りしめたとき
## Page 3-2
[ページ種別：青]
虎の背後に、刀を持った女がいた。
どこから現れたのか、 全く気付かなかった。
女は刀を振り上げ、
一刀のもとに虎を斬り捨てる。
虎は掻き消え、
大きな刀傷のある屏風だけが残った。
## Page 3-3
[ページ種別：青]
まがつき
「禍津姫とお呼びくださいませ」
女はそう言って、私に笑顔を見せた。
「あなた様の鬼の力・・・・・・。
お見事でございました」
「鬼の力?」
「ええ、ええ。 生命を具現化する力は 鬼の力に他なりません」
## Page 3-4
[ページ種別：青]
きけつしゅう
「我々、 鬼傑衆に加わりなさいませ。
手つから、鬼の世を作るのです」 禍津姫と名乗った女は私に手を差しだした。
ひと
体この女は、何を言っているのだろう。
そう思いながらも、
私はおずおずと手を伸ばし
## Page 3-5
目を開けると、
部屋の中は薄暗かった。
見飽きた天井が視界に広がっている。
どうやら眠ってしまったらしい。
妙な夢だった。
私は慌てて起き上がった。
ベッドの上を見回し、
出しっ放しの絵具を探しつつうと気付く。
自分が苦もなく起き上がり、
手足が自由に動いていることに。
## Page 3-6
信じられない。 どうして? あの病気が治ったのだろうか? また、絵が描けるのだろうか?
そう思ったとき
ばさりと音を立てて、
背中で異が広がった。
しばし呆然として、私は気付いた。
原因は私が描いた絵の林檎だと。 オーパーツの林檎によって、 天使となった
者がいると聞いたことがある。
同時にもうひとつ気付いた。
私の目が、 色を失っていることに。
## Page 3-7
赤青黄色、濃淡しかわからない。
真っ白の画帳の周りに散らばる絵具と筆が、
確かに絵を描いたと示しているのに。
「代償か......」
私は思わず呟いた。
それでも、また絵は描けるのだ。
筆を持ち、 窓を開けて空へ舞い上がる。
世界の色が失われようと
私はこうして生きている。
再び筆を持つことができた、 それで十分だ。
## Page 3-8
これまでは。
他人が欲しいものを描いてきた。
これからは、私が描きたいものを描こう
でも、それは一体何だろう。 描きたいものがわからない。 欲しいもの、好きなもの一
「わからなければ、探せばいい」
そうだ。 私はそれができる。
どこまでも羽ばたける翼を
手に入れたのだから。
