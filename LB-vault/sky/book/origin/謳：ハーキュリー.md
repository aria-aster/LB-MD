# Chapter 1
荒野の女
## Page 1-1
帝国の軍用列車が乾いた不毛の大地を進む。
列車は軍需物資と、 護衛の兵士を満載していた。
岩山の間を縫うように列車が進んでいるとき、 前方で爆発が起きた。
列車は急ブレーキをかけて停車し、
兵士たちの間に緊張が走る。
## Page 1-2
岩山の上から女の声が雷鳴の如く響いた。
「かかれぇっ!」
無数のエンジン音が、谷間に轟く。
急斜面をバイクで駆け降りてきたのは、
申し訳程度の服を身に着けた女盗賊の群れだ。 エンジンの爆音をもかき消す鬨（とき）の声をあげ、 彼女らは一斉に列車に襲い掛かる。
## Page 1-3
「出たな盗賊ども! 応戦しろ!」
隊長の号令を受け、列車内で待機していた
護衛の兵士たちが銃を構えて飛び出す。 しかし――
「うおお!」 「でけぇ!」「揺れてるゥ!」 露出度の高すぎる女盗賊たちの衣装に
兵士たちの目は釘付けになった。
「何をボーッとしている! 撃て撃て!」 「いや、でも隊長！ うへへへへへ……」
兵士たちは、 隊長の命令より 目の前の絶景に夢中だ。 兵士たちの前に何かが投げ込まれる。
「ゴホゴホゴホッ! なんだこれは!
「え、 煙幕です!
巨乳が見えません!」
煙に巻かれた兵士たちは混乱に陥った。
## Page 1-4
煙幕に乗じて、女盗賊たちは手早く兵士を
縛り上げる。 やがて煙が晴れると、
女盗賊たちが積み荷をトラックに
移し替えているところだった。
「ぐぐぐぐ……おのれおのれ……」
歯噛みする隊長に、巨大な釘バットを
持った女が近づいてきた。
## Page 1-5
「セロン! またしても貴様……!」
「悪く思うなよ。
こっちも生活がかかってんだ」
セロンと呼ばれた女はニヤリと笑い
仲間たちに口笛を吹いた。撤収の合図だ。
## Page 1-6
荷物を満載したトラックと共に、 女盗賊団のバイクが走り出す。 行く先は、荒野の谷間の小さな村。 セロンたちの故郷だ。
彼女らはここで静かに暮らす農民だった。 だが村の男たちが兵隊に取られると、 人手が足りず農作業ができなくなった。
彼女たちが耕作をやめ、
盗賊団に転じたのは ただただ、生きる糧を得るためだった。
村へ到着し、 荷降ろしをしていると、 ひとりの女が大声でセロンを呼んだ。
「お頭ぁ! 大変だ!」
## Page 1-7
「弾薬の箱から美少年が!」
「幻覚でも見てんのか……ってマジ!？」
列車から奪った積み荷のひとつから
美少年が出てきた。
「へっへへへへ……·これはまた……」
「えらいお宝を見つけやしたね、 お頭......」
「やめねえか、お前ら!」セロンは、
目をギラつかせる女たちを一喝した。
## Page 1-8
「あたしらの狙いは武器と食い物。 美少年はトラブルの元だ」
「じゃあ、どうするんで……？」
「ふん縛って、 そこらに転がしときな」
「ええええええ～！ かわいそ～！」 女たちが一斉に抗議の声を上げた。
美少年も、ここぞとばかりに目に涙を浮かべ、
自分の哀れな境遇を訴える。
「ふんふん……あの兵隊たちに捕まって? 国境の娼館に売り飛ばされそうに!？」
「こんな子があんなむさい連中の相手を させられるなんてひどすぎる!」
話を聞いて手下の女たちばかりか、 さすがのセロンも美少年に同情する。 「しかたねえ、当分村においてやる。で、でもしばらくの間だけだかんな！」
## Page 1-9
トムと名乗った美少年は、 セロンに感謝し、
何度も何度も頭を下げる。
しかし、セロンたちは気づかなかった。
トムが密かに笑みを浮かべたことに。

# Chapter 2
## Page 2-1
数日後——
セロンたちの村は、帝国軍に包囲されていた。
「くそっ なんで奴らがここに......」
セロンはひとつの可能性に思い当たった。
## Page 2-2
「トムはどこに行った!?」
「トムきゅん?そ、そういえば姿が……」
その言葉を聞いて、 セロンは確信する。
「とんだ食わせモンだったな!」
「うまく行ったよパパ…… いえ、 隊長殿!」
帝国軍陣地でトムを出迎えたのは、
セロンたちが襲った列車に乗っていた隊長だ。
盗賊の根城を探るため、 親子で共謀したのだ。
## Page 2-3
「セロ～ン！ これで貴様も終わりだ！
おとなしく投降しろ~!」
勝ち誇った隊長の声が響く中、セロンは、 抜け道から手下たちを逃がす。 そして――
セロンはひとり、白旗をあげ投降した。
## Page 2-4
「これで中央に戻れば、俺は昇進、お前は死刑確定！わはははは!」
セロンをとらえた隊長は有頂天だ。
## Page 2-5
「待ってパパ、いえ隊長！ お話が！」
現れたトムをセロンがにらみつける。
「この人を釈放してください」
トムの言葉に隊長は眉をひそめた。
「彼女はパーシヴァル司令の娘さんです!」 トムの言葉に隊長は愕然とする。
「戦死された司令閣下の……!?」 「そうです! 隊長殿の恩人ですよ!」
「本当なのか……？」
隊長がセロンにたずねる。
「知らねえよ 親父のことなんか。
ろくに顔も覚えちゃいねえ」
「村で、 ボクの世話をしてくれたお婆さんが 教えてくれました。 間違いなさそうです」 「アンジェラ婆さんが? なら確かだな」
セロンは他人事のようにうなずく。
## Page 2-6
「むうう……」 隊長は頭を抱えた。 セロンを捕縛せよとの命令には背けない。 しかし彼女を連れて戻れば、
恩人の娘をむざむざ死なせることになる。
わからん! こうなりゃ運試しだ!」
隊長はさんざん悩んだあげく。 奇妙な林檎を、セロンに手渡した。
「これは「グレゴールの林檎」だ。 こいつを食べると、運が良ければ
天使になるが…… 悪ければ死ぬ」
## Page 2-7
「死刑を待つよりよっぽどマシだ。
それに……あたしは運が良いんでね」
セロンはニヤリと笑い、
林檎にかじりついた。

# Chapter 3
## Page 3-1
[ページ種別：青]
そこは、人も、 森も、家も、山も、
何もかもが巨大な世界。
セロンはそこの世界でもとりわけ大きく
力強く、皆の尊敬を集める戦士だった。
## Page 3-2
[ページ種別：青]
誰よりも強い彼女も、自然には敵わない。
ある日、村の水源が枯れ、畑の作物が
まったく育たなくなってしまった。
村の人々は飢え、 弱っていく。
そればかりか、同様の事態に見舞われた
近隣の村が共謀してセロンの村を
作物を奪い去っていく。
## Page 3-3
[ページ種別：青]
さすがのセロンも多勢に無勢、
わずかに残った食料を守り抜けなかった。
彼女は悲嘆にくれ、 うめいた。 「わたしにもっと力があれば……」
だが、 そこでくじける彼女ではない。 力がなければ、自らを鍛えればいい。 ここで惨めに死ぬくらいなら、
できるところまでやってやる。
セロンは神の力が宿るという、 水晶洞窟へと向かった。 常人なら耐えられぬ過酷な鍛錬を修め さらに強い力を手に入れるために。
## Page 3-4
[ページ種別：青]
水晶の結晶の上での受け身千回
スクワット千回、小指立て伏せ千回など、 想像を絶する鍛錬を黙々と続けたセロンは、 ある日、神の声を聞く。
「あなたの望みは何ですか？」
神の問いかけに、セロンは躊躇なく答える。
「何者にも支配されない、力が欲しい！」
すると水晶から光が放たれ、セロンを包んだ。
## Page 3-5
[ページ種別：青]
まばゆい光が薄れたとき、
セロンの体躯は山ほども大きく
その力は巨大な水晶の結晶を 片手で砕くほどになっていた。
「あなたを超える身体、 あなたを超える
力を持つものは地上に存在しません......」
と、神の声が天から響く。
セロンは満足げにうなずいた。
## Page 3-6
[ページ種別：青]
この世界は、 力がなければ生きられない。
ならば私の力ですべてを支配し、 平穏な世界をつかみ取ってみせる。 セロンはそう決意したのだった。
その後セロンは「女帝」を名乗り、
巨大な体躯と力を武器に
荒野の支配へと乗り出すのだが、
その顛末はまた別の話……。
## Page 3-7
「へへへ……なかなか面白ぇ夢じゃねえか」
目覚めたセロンが周囲を見回すと、
隊長、 トム、 兵士たちが周りを取り囲み、
呆然と見つめていた。
「なんだ？ どうした……おおう!?」 セロンは、兵士たちを見下ろしていることに 気がついた。 身体が大きくなっているのだ。
手はデカい物を掴んでいる。 水晶に覆われた
ブーメランのようだが、恐ろしく大きい。
「こいつで殴れば、誰でも地獄行きだぜ!」
## Page 3-8
「てっきり死んだと思ったが...」
「でも、天使って翼があるんじゃ……？」
「いや、めっちゃセクシーでいい感じっす」
男たちは口々に勝手なことを言う。
「しかし翼がないということは、
天使にはなれなかったようだな。
やはり悪党は天使にはなれないのか」
「グチャグチャうっせえな!
羽根がなくても、
こいつがあるんだよ!」
セロンがブーメランを大きく振り回すと、 腕からすっぽ抜け、宙に放たれる。
「やべ！ ……んん？」
そんな隊長の言葉に、 セロンはカチンときた。
## Page 3-9
[ページ種別：青]
やがて、 ブーメランが戻ってきた。
「これで飛べるじゃねえか!」
セロンはブーメランに飛び乗ると、そのままの勢いで飛び去っていく。
## Page 3-10
「ああいう飛び方ありなのか？」
「翼がないから腕力で飛ぶって......」 トムは飛び去るセロンを見つめる。 「格好いい~!」
「中央には死亡したと報告しておこう。
セロン、お前はもう自由だ」 隊長は飛び去るセロンに向けて呟いた。
## Page 3-11
一方、ブーメランに乗って飛びながら
セロンは考えた。
「この力、 あたしはどう使おう......
巨人のセロンはどうしたんだっけ……」
ブーメランの上に座り込み、
ひとしきり考えた後。
セロンはニカッと笑って立ち上がる。
「まあいっか!」
## Page 3-12
「グチャグチャ考えてたってしょうがねえ!
まずはあいつうのところに帰るか!」
セロンは笑顔でブーメランの進路を変え、 盗賊団の仲間を探しに向かうのだった。

Fin.
