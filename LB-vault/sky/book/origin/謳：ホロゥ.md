# Chapter 1
跳躍
## Page 1-1
息を吸い、リズムに乗って、跳躍
鏡に映った着地姿を確認してから
私は息を吐いた。
大丈夫。
世界を相手にしても私は戦える。
## Page 1-2
明日は国際競技会だ。
「国際」 とは言っても、 参加する国は
帝国の同盟国と属国に限られるけど
優勝は私の夢であり――
私は体操の帝国代表として出場する。 ここで優勝し、世界の頂点に立つことが、
私に課せられた使命だ。
同じ体操選手だった母の夢でもある。
## Page 1-3
練習場の入り口から、にぎやかな声がした。
「ユー、やっぱり練習してた！」
同じ体操クラブの子供たちと、 コーチだ。
「頑張るのはいいが、根を詰め過ぎるなよ」
コーチが苦笑する。
「いつも通りにやればいい。 いつも通りの演技をやれば、
金メダルは間違いないんだ」
## Page 1-4
コーチの言うとおり、今の私は競技人生で 最高の仕上がりだ。 最高難度の技も手に
入れている。あとは本番でやるだけ。
絶対に金メダルを手に入れる。 金メダルを手に入れてママに見せれば
私は解放される。
## Page 1-5
私は金メダルを獲るために生まれ、 金メダルを獲るために生きてきた。
金メダルを獲る。
それが、ママの夢なのか、私の夢なのか。そこから、私の人生が始まるんだ。
もう区別できない。
## Page 1-6
競技会当日。
危なげなく私は勝ち進み、
残るは、得意の床運動のみ。
これを落とさなければ金メダルは確実だ
控え室のドアがノックされた。
コーチではない。 誰も入れるなど
言っておいたからだ。
私の返事を待たずドアが開く。
香水の匂い。 ママだ。
## Page 1-7
「ユーちゃんに良いものを持ってきたの」
ママが、 鞄の中から、
虹色の林檎を取り出した。
「これね、すごい林檎なの。
ユーちゃんが強くなる、
魔法の林檎なんですって」
「手に入れるのは苦労したのよ~。
好きでもない政府の偉い方と、お付き合い
までして... でもね、ユーちゃんのために
ママがんばったの」
## Page 1-8
ママの掌で、 林檎が輝いている。 「ユーちゃんの夢は、ママの夢だから」
ママの目は、私を見ているようで
見ていない。 ママの目を見ていると、
私は無言で、 林檎を受け取った。 どうせ、何を言っても、この人には
通じないだろう。
私は、本番を台無しにしてやりたくなる。
## Page 1-9
その時。
突然、競技場の建物が大きく揺れた。
ママと一緒に控室を出ると、 廊下は 逃げようとする人であふれていた。
「神獣だ！ 早く避難しろ！」
いきなり壁と天井が崩れた。
衝撃で地面へ叩きつけられ、 息が詰まる。
崩れた天井の向こうに見えたのは、 空を覆う巨大な神獣だった。 私は目の前が真っ暗になった。

# Chapter 2
連帯
## Page 2-1
激痛が走った。
神獣に破壊され、崩れた壁が、
私の上に乗っている。
膝から下が、ありえない方向に
曲がっているのが見えた。
血の気が引く。
こんな脚じゃ、跳べない……。
金メダルが、 手に入らない。
## Page 2-2
「助けて……誰か……」 私の声は誰にも届かない。
みんな逃げ出してしまったのだろう。
ママの姿も見えない。
私を置いて逃げたんだ。
身体をよじっても苦痛が増すばかりだ。
金メダルどころか、逃げることさえ
できない。
出血しているのだろう。
身体が震え、嫌な汗がどっと噴き出す。
## Page 2-3
私の手は、まだ虹色の林檎を握っている。
「強くなる魔法の林檎」 と、
ママは言っていた。
喉が渇く。 血が足りない。
この脚じゃ歩けない。 体操ができない。
金メダルが獲れない……。
混乱する頭のまま。 私は林檎に口をつけ、
かじった。
強くなりたい。
夢を叶えるために私は、強くなりたい。
## Page 2-4
[ページ種別：青]
雑居ビルの屋上に吹く生ぬるい風が、人混みの雑音を運んでくる。
屋上の端で踏み切って跳躍。
となりのビルの非常階段に着地。
## Page 2-5
[ページ種別：青]
階段を駆け上がり、雨どいからジャンプ
古いマンションのルーフバルコニーへ
着地する。
「来たね、 ユー」
バルコニーに居たふたりとハイタッチ。 私の「仕事仲間」 ヒズ兄とミー。 何度も 一緒に仕事をしてきた。 信頼できる仲間だ。
「今夜の盗みは、同業者が相手だ」
リーダー格のヒズ兄が言うとミーがうなずく。
「時計専門で強盗やってる連中だろ?」
## Page 2-6
[ページ種別：青]
「時計とカネの取引には、貸しオフィスの 宅配ボックスが使われる。 ミーが60秒だけ 監視カメラを止めて、その間にポスティング バイトのフリをした俺がカネを引く」
「で、 ユーがブツを運ぶってわけ」
ミーの差しだした拳に、 私の拳をぶつける。
「楽勝」
ほんの数ヵ月前まで 私はひとりだった。
仲間ができるなんて思ってなかった。
ましてや、こんな危険な仕事をするなんて。
## Page 2-7
[ページ種別：青]
パパが突然いなくなったのは、一年前
それが借金のせいだとわかるのに
時間はかからなかった。
借金取りから脅迫まがいの催促を受けて
ママは働きづくめ、 私は体操どころか、
どうしようもなくて、街をぶらついていた
時、ミーに声をかけられ……
そこから、ミーとヒズ兄と組んで、
「仕事」をするようになった。
ろくに学校にも行けなくなった。
## Page 2-8
[ページ種別：青]
詐欺、窃盗、 運び屋、 エトセトラ。
体操で培った身体能力を生かして、 私は 「運び」をやる。 屋上から屋上
点検口や、 路地裏、 都市の裏側、 普通の人は
気にもとめない場所を、私は移動できる。
はじめは、パパの借金を返すために 「仕方なく」 やっていた仕事だった。 でも、いつしか、ヒズ兄やミーが 私の居場所になっていた。
## Page 2-9
[ページ種別：青]
「ヤバいと思ったら、 すぐに引くこと。
死んだら何の意味もないぞ」
ヒズ兄が念を押す。
「うっす」 「分かった」
ミーと私は、同時に返事をする。
ぐっと拳を握って、気合を入れる。
頑張って稼いで、 パパの借金を返すんだ。

# Chapter 3
飛翔
## Page 3-1
[ページ種別：青]
「ぐあああっ」
ワイヤレス・イヤフォンから、 ヒズ兄の悲鳴が聞こえた。
私は路地裏で身を潜め、拷問される ヒズ兄の声を聞いている。
ヒズ兄から、封筒に入ったカネを 受け取るまでは順調だった。 私と別れた 直後、ヒズ兄が時計強盗に捕まったのだ。
## Page 3-2
[ページ種別：青]
「カネを持って指定の場所に来い。 逃げたら
こいつらの手、カニみたいにするからな」」
粘ついた男の声がして、 通話が切れた。
ミーとも連絡がつかない。 きっと、ミーも捕まったのだろう。
どうすれば、仲間を助けられる？
途方に暮れたまま動けずにいると、 スマホがブルッと震えた。
「パパの遺体が見つかりました。 借金は保険で何とかなりそうです」
ママからのメッセージだった。
## Page 3-3
[ページ種別：青]
こんな時に……。
借金がなくなるなら、
もう、こんな危険な仕事をする必要はない。
だったら、もう家に帰ろうか。
帰って、ママが淹れてくれる
温かくて甘い紅茶を飲みたい。
今なら。
強盗に存在を気付かれていない私だけなら。
逃げることができる。
何もなかったことにして、
日常に戻ることができる――
## Page 3-4
[ページ種別：青]
私は歩き始めた。
スマホに着信が届く。
カネの受け渡し場所の連絡だろう。
私はスマホに触れもせず、
雑踏に紛れ、 駅に向かう。
駅のホームで電車を待つ。
ヒズ兄とミーは、私を待っているだろうか。
## Page 3-5
[ページ種別：青]
あのふたりでも、私の立場になれば、
きっとカネを持ってばっくれるだろう
――ミーはそんなことしないな。
あの日、ミーはどこにも居場所のなかった 私に声をかけてくれた。 知り合いでも
何でもない私に。
## Page 3-6
[ページ種別：青]
学校に行けなくなったのは、
パパの借金が原因だ。
でも元から学校に居場所はなかった。
体操ができるからと推薦で入ったけど、 他人と上手く付き合えなかった。
自分の殻に閉じこもっていた私に
最初に優しくしてくれたのは、ミーで、 次にヒズ兄だった。
## Page 3-7
[ページ種別：青]
そんな仲間たちを置いて、
私だけ逃げるなんて、できない。
私は時計強盗からのメッセージを確認した。 私が、ふたりを助けるんだ。
## Page 3-8
目を覚ますと、
剥き出しのひしゃげた鉄骨に、
夕日が当たって輝いていた。
あれからどうなったんだろう。 競技大会の会場に神獣が現れて、 私はママにもらった林檎を食べて
神獣の気配はもうない。
ゆっくりと体を起こす。 身体の上の瓦礫も、
足の怪我も消えていた。
体はどこも痛くない。
## Page 3-9
神獣の襲撃も怪我も、
「ママ......?」
見覚えのある服を見つけた。
ママは、上半身が瓦礫に潰されていた。
ママだけじゃない。 体操着の選手。 大勢の観客。 コーチ、体操クラブの
こどもたち。みんな、変わり果てた姿に
なっていた。
夢の中の出来事のように思える。
競技場があった場所は、 廃墟になっていた。
生きている人の気配はどこにもない。
## Page 3-10
ママは――
夢を叶えても、
私に夢を押しつけた人は、いなくなった。
夢を叶える場所も消えた。 夢を応援してくれた人たちも、 いなくなった。
一緒に喜んだり、笑ったりしてくれる人も
いなくなってしまった。
私は、どうすればいいのか分からない。
## Page 3-11
夢から解き放たれるのは、 夢を叶えたとき。
ずっとそう思っていた。
こんなかたちで、夢から解放されるなんて
望んでいなかった。
夢で見た女は、 借金から解放されても
やるべき事があった。
私には何もない。
夕目が、長い影をつくる。
私の背に生えた翼の髪が伸びる。 林檎があたえてくれた力だ。
## Page 3-12
この力は、 何のためにあるのだろう。
私は地面を叩くように蹴ると、 空へ飛びあがった。 くるりと宙を舞う
何度も何度も。
見せるはずだった床運動の演技。 どんな高難度の技も、この翼があれば
易々と行える。
ならもう体操を続ける意味も無い。
## Page 3-13
当てもなく私は空へ舞い上がった。 いつかどこかで、
新しい夢がつかめるだろうか――

Fin.
