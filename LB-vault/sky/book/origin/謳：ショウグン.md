# Chapter 1

エキゾチック
帝都の片隅に、異国情緒趣味を売りにした
高級店があった。 東国風衣装の娘が
異国の旋律を歌い踊るのが売りだ。

レイ・カーニハンという女将軍だった。

貴族たちは気に入らないのだ。

「よっ女たらし!」「黒腹の間違いだろう」
貴族たちが下品な笑い声をあげていると、 先ほどまで舞台で可憐な歌声を

そう言った貴族を無視して、 歌姫は 自称黒薔薇の貴公子に顔を寄せた。

「な、なんだお前は」
「まぁだ分かりませんのん？」

白塗りの歌姫を見つめていた自称貴公子が
椅子ごとひっくり返った。
「しょ、 将軍ンン!」
それは東国風衣装を着て変装した
レイ・カーニハン将軍その人だった。
「悪巧みは許しまへんえー」
レイは心底嬉しそうな笑みを浮かべた。
## Page 1-6

やったわ! 愉快愉快!」
満面の笑みで昨夜の武勇伝を語るレイに、
メイドのカーラは微笑みながら
「趣味悪いっすねぇ」 と毒舌を吐いた。

レイにとって苦痛極まるものだった。
身分を隠し、変装姿で弾き語りや歌を
披露していたのも、刺激を求めての事だ。 「うーむ。 また戦争が始まらんもんかのう」
戦争こそがレイの存在意義であり、 唯一、レイの心を満たしてくれる物だった。
「そんな不謹慎な事言っちゃダメですよぅ」
カーラのとがった口をレイが指先でつまむ。
「分かった分かった。 そうだ今夜は お前もつきあえ! 一緒に踊るぞ!」
「マジですかー」
## Page 1-8

レイは嬉しそうに笑った。

# Chapter 2
ドゥー・オア・ダイ
## Page 2-1
「むむ、なんだこの林檎は？」
不気味な色の林檎が厨房のテーブルに
ふたつ並んでいる。
## Page 2-2
レイが林檎を手に取り眺めていると、
「ご主人さま、食べちゃダメですぅ!」
メイドのカーラがびしっとはたき落とした。
「それは皇帝陛下からの賜りものです。
後できちんと飾っておくです」
武勲への褒賞が林檎ふたつとはケチくさい。
「白い変な帽子をかぶった人が
持ってきたんですけど…… なんか貴重な林檎らしいですう。
これをかじると天使になるとか」
## Page 2-3
「天使い?ふん! そんな怪しい林檎、
わしが喰うわけなかろう」
レイは再度伸ばした手を引っ込める。
「そうですか? ならいいですけど……」 信用度ゼロの目でカーラはレイを見つめる。
「心清き人が食べると、天使たちを統べる 大天使ガブリンチョ ラファミカエルに
なれる……って嘘くさいこと言ってました。
そんなの信じるやつはおらんですよね」
「なんだと」
面白いではないか。
カーラが喋っている途中でレイは もう一度不気味な林檎に手をのばした。
## Page 2-4
「ガブリムシャバタンキューッ!」
即断即決即実行がレイの信条である。
レイは迷わず林檎をかじり即座に昏倒した。
「い、いやぁ〜っ! ご主人さまぁ~っ!」
意識が遠ざかっていく中
カーラの悲鳴がかすかに聞こえた。
## Page 2-5
[ページ種別：青]
鏡に、知らない娘が映っている。
東国風の豪奢な着物を着て紅を引いていた。
やがて娘は立ち上がると優雅に舞を踊り、 芝居のものらしい台詞をつぶやく。
彼女は大名と呼ばれる権力者のひとり娘の
ようだった。 自分が登場しない夢のように、
レイはただ、 彼女の生活を眺めている。
## Page 2-6
[ページ種別：青]
彼女は、歌と芝居、芸事にしか興味がない。 日々ぼんやりと遊んで暮らしていた。
一方、双子の兄である太郎丸は 勇猛果敢な武将として名を馳せており、 
彼女はそんな兄をずいぶんと慕っていた。
## Page 2-7
[ページ種別：青]
ある日の事。
彼女が大名である父親に呼ばれ大きな木造の
屋敷に出向くと、そこには布団に寝かされた
兄、 太郎丸の亡骸があった。
自分と同じ顔の兄の死顔を見つめ、
彼女は絶句した。 大名は告げる。 「太郎丸は死んだ。 だがこのことは 他国には決して知られてはならぬ」
「女であることを隠せ。
今からお前は太郎丸じゃ。 この先は太郎丸として生きよ」
何も知らぬ小娘が武将として振る舞うなど
できるはずもない。 だが、 それを口に出来ぬ
ほど、 彼女は大名である父を恐れていた。
## Page 2-8
[ページ種別：青]
「上様。 あまりにご無体にございます」 大名を恐れ、臣下が口をつぐむ中、 侍女の

身分の低い女が大名に進言するなど、 無礼極まる事である。
この侍女、ただものではないな。 娘の中でレイはそう感じた。
いりすは、兄の太郎丸がよこした侍女だ。
心を開いて話ができるのは兄の他には
いりすだけだった。

[ページ種別：青]
大名は腰に差した刀を、自分の娘に 向けて放ると、娘を太郎丸と呼んだ。

この端女を斬ってみよ」
いりすは青ざめたまま微動だにしない。 娘は畳の刀を見つめたまま、何もできず、
ただ立ちすくんでいた。

パーフェクト・デシジョン
## Page 3-1
[ページ種別：青]
大名の娘は、兄の骸と刀、平伏する侍女を 順番に眺め、何もできずただ震えていた。
## Page 3-2
[ページ種別：青]
「太郎丸は我が手足も同じ。
造作もなくやってのけるはず……。
侍女を斬れ、斬って太郎丸となれ!」 大名の怒声が響く。
「太郎丸さま」
侍女は、娘に兄の名で呼びかけた。
その声に突かれたように娘は刀を手にした
その重量によろける。
「私（いりす）をお斬りくださいませ」
## Page 3-3
[ページ種別：青]
「私ごときが主君にもの申すなど
許されざることでございます故。 さあ……」
侍女は白いうなじを差しだす。
どうすればいいの……。 その言葉が
娘の頭の中をぐるぐると回る。
娘は人を斬るどころか、
真剣を手にしたのも
これが初めてだった。
大名は薄い笑みを浮かべ、娘を見下ろす。
これまで何もかも、自分の思い通りに
してきた男特有の嫌らしい笑みだ。
## Page 3-4
[ページ種別：青]
「早うせい!」
怒りの形相で、大名が娘の肩を揺する。 娘は身をすくませたまま動けない。
すべてを解決する冴えたやり方が
あるではないか。
「太郎丸の名、謹んで頂戴いたします 娘は大名の目を見て言う。

[ページ種別：青]
直後、娘は鞘から刀を抜き放った。切っ先が弧を描き、再び鞘に戻る。
大名は糸の切れた人形のように崩れ落ちた。やがて首が胴から離れ、転がる
自分が斬られたことも分からぬのだろう。大名の顔は下卑た笑みを浮かべたままだ。
## Page 3-6
[ページ種別：青]
居合いによる生首両断の業を目撃し
臣下たちは戦慄した。 腰を抜かす者もいる
「お美事でございます。 太郎丸さま」
侍女はさらに深く、頭を垂れた。
「父上は病を得て身罷られた。
傲慢という病じゃ。 たった今より この国の大名はこの太郎丸である」
娘を咎めるものはひとりもいなかった。
## Page 3-7
[ページ種別：青]
太郎丸となった娘を畏れる臣下たちの中で、
いりすだけが柔和に笑っていた。その瞳は 娘を目覚めさせた悦びの光が宿っていた。
## Page 3-8
[ページ種別：青]
父は国を獲るために、何百、何千の兵を
殺したというが、 娘はたったひとりを

なんと愉快なことか!
我が物となった城下町を見下ろし、 わしは娘と共に心の底から笑った。
本当の楽しみはここからだ。 戦争ができる。 ただ戦争の事だけを

レイは自分の笑い声で目が覚めた。 厨房の床に倒れていたようだ。
「あの林檎は妙な成分でも入っていたのか?

カーラに教えてやらねば。 レイは厨房を
出ると、 姿見の前で足を止めた。
## Page 3-10
「な、なんじゃこれはー!」
大きな姿見にレイの全身が映っていた。
夢で見た娘と同じ着物。
その背中には大きな羽根が生えている。
## Page 3-11
「すごいぞ! おい、カーラ! カーラ!」
カーラを呼んでも返事はない。
その上屋敷からは金目のものがことごとく 消えていた。 そういえば、もし自分が
死んだら屋敷のものは好きにして良いと 言った覚えがあるが、 ごっそりいくとは。
「さすがは我がメイド、天晴じゃ!」 カーラの大胆な行動力が痛快だった。 もとより地位にも財産にも未練はない。
レイは屋敷の外に出た。 背中の翼 羽ばたかせると、 身体が浮き上がった。
## Page 3-12
大空に舞い上がり、眼下の街を見下ろす。
平時にこれほど気持ちがあるのは、
まだ戦争を知らない少女だった時以来だ。
「面白くなってきたぞ!」
未知の力を手にした興奮と、 この先に広がる戦いの予感に、 レイは歓喜の声をあげた。
